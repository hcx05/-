# 《補天錄》

武俠長篇的完整企劃:序卷 + 三部,共 478 個事件、155 章(含楔子)、章節預計字數合計約 292 萬字。本分支只收小說本身的文件(故事、角色、勢力、世界、武學、狀態與設計規則),不含開發流程文件與檢查工具。

| 資料夾 | 內容 |
|---|---|
| [故事大綱](故事大綱/) | 全書宏觀走向、占比與分線 |
| [故事線](故事線/) | 各卷大綱、時間線、年齡表、事件描述、章節大綱(序卷、第一部、第二部、第三部) |
| [角色](角色/) | 男女主與主要角色的設定與成長紀錄(記憶、武學、感情、個性) |
| [勢力](勢力/) | 組織與群體 |
| [世界設定](世界設定/) | 世界觀與場景設定 |
| [武學設定](武學設定/) | 武學、靈能、戰力基準、招式錄 |
| [設計規範](設計規範/) | 事實登錄、設計決定、術語表、ID 對照 |
| [狀態](狀態/) | 各卷結束時的狀態快照、秘密知情矩陣、伏筆登記簿 |
