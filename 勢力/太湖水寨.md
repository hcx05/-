# 太湖水寨

- **ID**:ORG-013
- **性質**:水上盜匪(十二連環塢)
- **所在**:太湖湖心島嶼
- **領導與主要成員**:水寨寨主(姓名待 C1 事件描述)。
- **目標**:替鹽梟護送私鹽,盤踞太湖水道收取買路錢。

## 第一部中的角色
第一部中:五人入湖,太湖水戰後水寨被拔除,鹽工與商船獲救(P1-031 至 P1-034)。
