# 工具

## 檢查.py
專案一致性檢查,於專案根目錄執行:

```
python3 工具/檢查.py
```

有問題時列出清單並以結束碼 1 結束;全部通過則輸出「全部檢查通過」。

| 檢查項目 | 內容 |
|---|---|
| 連結 | 所有 Markdown 相對連結是否有效 |
| 感情對稱 | A 對 B 有紀錄,B 對 A 也要有;對方已故者不需對稱;標「尚未接觸」者略過 |
| 戰力 | `角色/`、`狀態/` 內不得出現超過 L25 的戰力;狀態表 L 與第一部設定一致 |
| 事件 | 事件 ID 連號;出場角色必有角色資料夾 |
| 事件覆蓋 | 事件的出場者,其記憶檔必須列出該事件 ID |
| 已故 | 已故角色不得出現在死亡事件之後的事件(以最新狀態快照的「已故(PRO-xxx)」為準;同卷以時間線的序比較先後,後加入的事件編號不依時間) |
| 本卷內死亡 | 年齡表標「已故(本卷事件)」者,不得出現在晚於死亡事件的出場名單(序卷、第一部、第二部、第三部皆檢查) |
| 伏筆 | 伏筆登記簿引用的事件必須存在 |
| 占比 | 各部大綱的同行占比須在 30%–40% |
| ID | `設計規範/ID對照.md` 的 ID 唯一、路徑存在、檔案內的 ID 一致;角色、勢力、場景資料夾皆已登記 |
| 術語 | 術語表「避免寫法」不得出現在其他文件 |
| 年齡 | 年齡表與角色狀態的年齡一致 |
| 戰力 | 戰力基準人物表與狀態表的 L 一致 |
| 個性 | 個性轉變的觸發事件必須存在且角色為出場者;狀態表須有「當前個性」欄 |
| 完成度 | 已開發的卷(有事件描述者)必備檔案齊全:卷大綱、時間線、節奏檢視、吸引力分析、年齡表、章節索引;卷末快照四份、知情矩陣、伏筆登記簿只在該卷已開始收尾(有 `狀態/{卷}結束/`)時要求 |
| 章節 | 章節大綱的「對應事件」與事件描述的「章節」欄一致,每個事件都被某章涵蓋(已有事件描述的卷皆檢查,含第一部) |
| 章節(三種去向) | 事件描述的章節欄可為「第 N 章」(演出,須列在該章大綱的「對應事件」)、「第 N 章(提及)」(須列在該章大綱的「提及事件」)、「背景」(不得被任何章節大綱列入);用於序卷三章版(DEC-073) |
| 正文 | `正文/{卷}/第N章_標題.md` 的章號、標題、對應事件須與章節大綱一致,且列入 `正文/README.md` 的進度表(階段 G 關卡) |
| 事件描述 | 已有事件描述的卷:每個事件與時間線的序號、時間、章節、標題一致;描述不超過 120 字;出場角色、勢力與場景須與凍結紀錄一致 |
| 招式錄 | `武學設定/招式/{卷}招式錄.md` 每列的事件 ID 須在凍結紀錄、出場者須在該事件的出場名單、事件章節須落在所屬小節的章節區間;`套路錄.md` 標「已出場」的事件 ID 須出現在招式錄 |
| 年齡(第一部) | 第一部年齡表起點須等於序卷年齡表結束;各角色 `設定/第一部.md` 的年齡須等於年齡表起點;時間線男女主歲數須等於「起點 + 初遇後滿年數」 |
| 缺口 | 已結案的卷(缺口掃描標「狀態:已結案」):凍結紀錄的出場角色、勢力、場景都必須有檔案,或登記為待建 |
| 凍結 | 已有凍結紀錄(`凍結.md`)的卷:時間線每個事件須在凍結紀錄中,且相對時間與章節一致;事件 ID 不得刪除 |
| 時間線 | 已建立時間線的卷:事件 ID 前綴正確且連號,卷大綱每一章至少有一個事件,時間線不得引用卷大綱沒有的章 |
| 大綱 | 卷大綱(`故事線/{卷}/大綱.md`)每章的線別須與宏觀大綱(`故事大綱/`)一致,章數相同 |

| 標籤 | 時間線的事件標籤與感情線必須在標籤表登錄;感情線只填狀態詞;節奏檢視須為最新(標籤仍含「待填」的卷不檢查) |

## 標籤檢視.py
依時間線產生節奏檢視(`故事線/{卷}/節奏檢視.md`),提供兩個視角:事件標籤節奏、男女主感情線弧線,並列出提醒(連續重事件缺緩衝、爭執或分離缺收束、緩衝占比過低)。

```
python3 工具/標籤檢視.py [卷資料夾,預設 故事線/序卷]   # 例:python3 工具/標籤檢視.py 故事線/第一部
```

## 正文節奏檢視.py
正文初稿完成後的輔助診斷,只讀不改,只用標準函式庫。不屬於結構檢查,**不設合格線,結束碼恆為 0**(檔案不存在回 2);輸出是給編輯時參考的提示,哪些值得修由閱讀判斷。

```
python3 工具/正文節奏檢視.py 正文/序卷/第1章_斷碑村.md            # 單章
python3 工具/正文節奏檢視.py 正文/序卷/第2章_風雪訣別.md 正文/序卷/第3章_劍門秋雨.md   # 多章,附跨章重複
python3 工具/正文節奏檢視.py 正文/序卷                           # 資料夾:依檔名順序讀 第*.md
```

選項:`--short N` 短段的漢字上限(預設 30)、`--limit N` 每項最多列出幾筆(預設 25)、`--all` 一併列出夾在對白之間的短敘述段(預設只提示數量)。

排除標題、章節註記(`>` 開頭)、場景分隔(`＊`),並把含引號的段落歸為對白,不當作短段計算。輸出依檔案分節:

| 項目 | 內容 |
|---|---|
| 段落統計 | 敘述段、含對白段、單句敘述段、短敘述段(其中夾在對白間者通常是正常的動作停頓,預設不逐條列) |
| 單句/短敘述段 | 行號、句數與字數、開頭文字 |
| 疑似連續短段區 | 連續 ≥3 個短段,或 6 段內 ≥4 個;附前後各一段作上下文(▸ 為短段,「白」對白、「短」短段、「敘」其他敘述) |
| 對白標籤 | 含說話動詞的對白段數;連續 ≥4 段都帶標籤的位置(可能是機械插入,也可能只是對答密集) |
| 句型計數 | 「不是…而是」「沒有…也沒有」「直到…才」「彷彿」「忽然」「只見」、破折號與省略號等的出現次數 |
| 敘述句首高頻 | 重複的句子開頭(人名與代詞居多,看「他想」「他把」之類的慣性) |
| 跨章重複措辭 | 多於一章時,列出出現 ≥2 處、≥6 字的相同片段,先列跨章者。不判斷是否有意呼應,例如「別偷馬」的反覆出現是設計好的 |

已知限制:段落是否碎片化取決於場面,工具只看長度與句數;一場緊張的戲、單獨強調的重大變故,出現短段連續是合理的;「說話動詞」以關鍵字判斷,會有誤判與漏判;重複片段只比對字面,不認得換了說法的同一件事。

## 擴充到其他卷
- 第一部以後的事件前綴為 `P1-`、`P2-`、`P3-`,呼叫 `check_events(volume='第一部', volume_dir='故事線/第一部', prefix='P1')`。
- 每卷完成後新增 `狀態/{卷}結束/`,檢查腳本會以最新一份快照為準;快照的先後依卷序(序卷、第一部、第二部、第三部),不用字串排序(「二」的碼點大於「三」,曾使第三部快照被略過,見 DEC-067)。

## 缺口掃描.py
依 `故事線/{卷}/凍結.md` 的出場者表列出缺口(缺角色資料夾、缺該卷設定、缺勢力檔、缺場景建模),已登記於場景設定 README「待建」的場景不算缺口。階段 B1 使用。

```
python3 工具/缺口掃描.py [卷名,預設 第一部]
```

## 出場順序
| 檢查 | 說明 |
|---|---|
| 出場順序 | `python3 工具/出場順序.py 故事線/{卷}` 產生 `出場順序.md`。護欄:單一事件首次登場的新名字 ≤ 2、單章 ≤ 4;相隔 12 章以上再出現者,中間章節的「群像補充」須有「回頭提示」;檔案過期即報錯。男女主與前卷已出場者不計入新名字 |

## 單次出場角色
| 檢查 | 說明 |
|---|---|
| 單次出場 | 某卷事件描述中只在一個事件出場的角色(男女主除外),不得有該卷的記憶、武學、個性、感情紀錄 |

## 階段 D 閘門
`故事線/{卷}/紀錄對照.md` 標「狀態:已結案」後啟用:事件覆蓋(事件出場者的記憶檔須列出該事件 ID)、感情對稱、個性轉變(觸發事件存在且角色為出場者)、成長檔不得殘留「(待填)」。已故檢查亦涵蓋跨卷:前一卷已故者不得出現在本卷任何事件。

# 寫作工具鏈(給寫正文用)

流程見 [生成手冊](../手冊/生成手冊.md)。以下皆只用 Python 標準庫,於專案根目錄執行。`寫作庫.py` 是共用函式庫,不直接執行。

| 工具 | 用途 | 例 |
|---|---|---|
| `寫作包.py` | 為指定章產生自足的寫作輸入檔(大綱、章前狀態、在場人物卡、場景、稱呼與禁區、前文結尾、風格樣本、交付格式),各節有字數預算,包頭有輸入雜湊;同一倉庫狀態重跑結果相同。資料取「截至本章」,不讀未來卷 | `python3 工具/寫作包.py 第一部 2`(加 `--精簡` 給小上下文模型;`--stdout` 不寫檔) |
| `查詢.py` | 查某名稱(角色、勢力、場景、術語、物件、專名)在「截至某章」時的資料,自動排除未來卷與未來章;勢力檔、場景檔不分卷,會標註「未依章過濾」 | `python3 工具/查詢.py 阿古 --至 一2` |
| `落稿.py` | 存場景稿、組成整章、存帳本、存待決單、檢查場景卡是否涵蓋全部情節要點 | `python3 工具/落稿.py 場景 第一部 2 1 輸出.txt` |
| `正文檢查.py` | 對正文做事實與格式層檢查(見下) | `python3 工具/正文檢查.py --全部` |
| `帳本合併.py` | 折疊所有帳本,導出 `正文/帳本/累積狀態.md`;`--檢查` 驗證是否最新 | `python3 工具/帳本合併.py` |
| `建索引.py` | 導出 `索引/*.json`(章節、事件、人物、術語、伏筆);`--檢查` 驗證是否最新 | `python3 工具/建索引.py` |
| `進度.py` | 各卷進度、下一章、阻礙(待決單、待回補、大綱補丁、導出檔過期)與建議的下一步指令;接手任務的第一步 | `python3 工具/進度.py`(加卷名逐章列出階段) |
| `帳本草稿.py` | 依成稿與大綱產生預填一半的帳本草稿(出場者、數字候選、疑似新人名、要點對照骨架);`(待填)` 沒補完會被 E14 擋下 | `python3 工具/帳本草稿.py 第一部 2 --寫入` |
| `回補清單.py` | 列出帳本中「待回補」的新增事實與建議寫入位置 | `python3 工具/回補清單.py` |
| `影響掃描.py` | 正文確立新事實後,掃描**之後章節的大綱與事件描述**是否提到同一物件、專名、稱呼(正文版變更傳播) | `python3 工具/影響掃描.py 序卷 3` |
| `債務掃描.py` | 未決標記、場景待建(依事件換算用到的章)、大綱補丁段落、待回補、暫定名;唯讀 | `python3 工具/債務掃描.py --接下來 10` |
| `聲口萃取.py` | 從定稿正文抽出各角色對白,供補聲口卡 | `python3 工具/聲口萃取.py 阿古` |
| `盲測比對.py` | 比較兩份獨立產出(兩份帳本或兩份成稿)的事實層差異與一致率,方法見[盲測](../手冊/盲測.md) | `python3 工具/盲測比對.py A.帳本.md B.帳本.md` |
| `測試.py` | 工具回歸測試:植入錯誤能被抓到、定稿零錯誤、寫作包可重現且不洩漏未來、導出檔最新 | `python3 工具/測試.py` |

**每章寫完後**:帳本或正文有變動,就重建導出檔(`落稿.py 帳本` 會自動做;手動編輯時執行 `帳本合併.py` 與 `建索引.py`)。`檢查.py` 會報告導出檔過期。

## 正文檢查.py 的項目

| 代碼 | 級別 | 內容 |
|---|---|---|
| E01 E02 | 錯誤 | 標題、引言行格式,對應事件須與章節大綱一致 |
| E03 E04 | 錯誤 | 正文含 Markdown 標記;場景分隔不是單獨一行「＊」 |
| E05 | 錯誤 | 規劃用語外洩:「男主」「女主」、事件與規則編號、戰力等級數字 |
| E06 | 錯誤 | 命中術語表「避免寫法」 |
| E07 | 錯誤 | 現代用詞(公里、分鐘、小時…) |
| E08 | 錯誤 | 違反稱謂表(此階段禁用的名字) |
| E09 | 錯誤 | 揭露節點:詞出現得比最早章還早(強度為「硬」者) |
| E10 | 錯誤 | 場景卡列為禁揭詞 |
| E11 E12 | 錯誤 | 帳本缺失、格式不符、大綱要點未對照、回補路徑或待決單不存在 |
| E13 | 錯誤 | 引言行的男主歲數不在時間線對本章事件給的範圍內 |
| E14 | 錯誤 | 帳本仍有「(待填)」(草稿未補完) |
| W01–W10 | 提示 | 待決稱呼、提示級揭露、帳本專名未見於正文、已故者出現、未在大綱出現的人名、疑似新人名、字數落差、套語密度、連續極短段、名稱早於章節大綱安排的首現 |

提示不判通過或失敗(見[寫作規範](../正文/寫作規範.md)第九節);錯誤須修。**沒有實作**的檢查:人數、天數、金額等數字與前文是否一致、對話是否出自視角外的知識——這些靠獨立的[事實複查](../手冊/提示/事實複查.md)。
