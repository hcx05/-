# 工具

## 檢查.py
專案一致性檢查,於專案根目錄執行:

```
python3 工具/檢查.py
```

有問題時列出清單並以結束碼 1 結束;全部通過則輸出「全部檢查通過」。

| 檢查項目 | 內容 |
|---|---|
| 連結 | 所有 Markdown 相對連結是否有效 |
| 感情對稱 | A 對 B 有紀錄,B 對 A 也要有(預設檢查序卷,換卷時改函式參數) |
| 戰力 | `角色/`、`狀態/` 內不得出現超過 L25 的戰力;狀態表 L 與第一部設定一致 |
| 事件 | 事件 ID 連號;出場角色必有角色資料夾 |
| 事件覆蓋 | 事件的出場者,其記憶檔必須列出該事件 ID |
| 已故 | 已故角色不得出現在死亡事件之後的事件(以最新狀態快照的「已故(PRO-xxx)」為準) |
| 伏筆 | 伏筆登記簿引用的事件必須存在 |
| 占比 | 各部大綱的同行占比須在 30%–40% |

## 擴充到其他卷
- 第一部以後的事件前綴為 `P1-`、`P2-`、`P3-`,呼叫 `check_events(volume='第一部', volume_dir='故事線/第一部', prefix='P1')`。
- 每卷完成後新增 `狀態/{卷}結束/`,檢查腳本會以最新一份快照為準。
