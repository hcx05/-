# 手冊

讓任何大語言模型(不限廠商、不限是否有技能機制)都能依固定流程寫出與既有事實一致的章節。

| 文件 | 用途 |
|---|---|
| [生成手冊](生成手冊.md) | 一章從取包到提交的完整流程、停止條件、常見失敗 |
| [優先序與衝突](優先序與衝突.md) | 資料出入時誰說了算、何時停下開待決單、哪些東西不得自創 |
| [鐵律卡](鐵律卡.md) | 最容易寫錯的規則摘要(每章寫作包第一節) |
| [提示/](提示/) | 可直接貼給對話模型的系統提示、場景生成、事實複查、文學複查、交付格式 |
