# 優先序與衝突處理

資料之間難免出入:大綱與已寫成的正文不一致、設定檔和事實登錄不一致、寫作包裡兩處說法不同。**不要默默擇一,也不要自行發明。** 照下面的順序判斷;高層之間相衝時,停下來開待決單。

## 一、效力排序(高 → 低)

| 層 | 內容 | 說明 |
|---|---|---|
| 1 | [事實登錄](../設計規範/事實登錄.md)(FACT)與[設計決定記錄](../設計規範/設計決定記錄.md)(DEC) | 硬規則與已拍板的設計;改動須新增 DEC |
| 2 | 凍結骨架:事件 ID、相對時間、章節、出場者(`故事線/{卷}/凍結.md`) | 要改走[變更傳播](../設計規範/建檔架構與順序.md) |
| 3 | **已定稿正文確立的事實**(經[帳本](../正文/帳本/README.md)登記者) | 讀者已經讀到的就是既成事實,高於尚未演出的大綱與設定檔 |
| 4 | 本章章節大綱 | 要演出的內容;與第 3 層衝突時,以第 3 層為準並在帳本「與大綱出入」登記 |
| 5 | 角色、勢力、場景、武學設定與成長紀錄 | 衍生資料;與第 3 層衝突時,標為「待回補」 |
| 6 | 作者(模型)補寫的普通細節 | 只能補不矛盾的生活細節,且須登記 |

> 例:序卷正文寫七叔只念了守心訣總訣四句,而男主記憶檔寫「完整口訣」。以正文(第 3 層)為準,記憶檔待回補(見 [Q-003](../正文/待決/Q-003.md))。

## 二、判斷流程

1. 兩處說法不同 → 找出各自所在的層。
2. **一高一低** → 取高層,低層標「待回補」,寫進帳本「與大綱出入」(處置:`接受`)。繼續寫。
3. **同層相衝**,或**第 1、2 層之間相衝**,或**正文已寫的與凍結骨架相衝** → 停止,開[待決單](../正文/待決/README.md),照單上的「暫行做法」寫;沒有暫行做法就不要往下寫該段。
4. **資料不足**(大綱沒寫、設定沒有) → 先看能否用不矛盾的普通細節補足(第 6 層)。涉及能力、毒物、療法、穴位功效、歷史事件、重要人物的,不得自創,開待決單。

## 三、模型不得自行創造的東西

- 新的重要人物(能影響後續劇情者)。路人與一次性配角可以有,但必須登記在帳本「新增專名」。
- 未設定的武功、內功、靈能、毒物、療法、穴位功效、法器。
- 新的歷史事件、朝代制度、重大地理。
- 既有事實的數字、稱呼、傷勢、持物、位置的改動(除非本章情節演出了這個改變)。
- 提前揭露的秘密、提前出現的名字(見[稱謂表](../正文/技法/稱謂表.md)第二節)。

## 四、哪些可以自由補

- 場景的感官細節、生活物件、天氣、飲食、路人的小動作、不影響後續的對白。
- 人物的小習慣與反應(但別和聲口卡衝突,也別在相鄰兩三章重演同一個)。
- 補了之後若後續章節可能用到(例如一個地名、一個物件、一個數字),就登記;拿不準就登記。
