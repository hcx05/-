# 場景生成提示(範本)

把下面的 `{…}` 換成實際內容後貼給模型。系統提示用[系統提示](系統提示.md)。

```
以下是《補天錄》{卷}第 {N} 章〈{標題}〉的寫作包。請先完整讀完,再寫場景 {K}。

【寫作包】
{貼上 正文/包/{卷}/第NN章.包.md 全文}

【場景卡】
{貼上 場景卡 中「## 場景 K」整段;若 K>1,另貼前面各場景的「場景末狀態」}

【上一場景的末段原文】(K=1 時省略)
{貼上前一場景正文最後約 800 字}

【要求】
- 只寫場景 {K},字數約 {預算} 漢字(可上下浮動三成);
- 依場景卡的「對應要點」演出要點,不多加重大事件;
- 場景卡「禁揭」「禁揭詞」所列不得出現;
- 輸出格式:
=====正文=====
(場景正文)
=====場景末狀態=====
- 位置/時間:
- 在場者的傷勢、持物、情緒:
- 本場新出現的專名、數字、稱呼(一行一項):
- 與包內資料的出入(沒有寫「無」):
```

## 場景卡生成(S1)用的提示

```
以下是《補天錄》{卷}第 {N} 章〈{標題}〉的寫作包。請依章節大綱的「情節要點」把本章拆成 4 至 8 個場景,輸出場景卡:
每個場景一個「## 場景 N」區段,欄位:地點、視角、在場、目的與衝突、對應要點(大綱編號)、揭露、禁揭、禁揭詞、入場狀態、出場狀態、字數預算。
要求:每個情節要點必須被某個場景涵蓋;入場狀態取自寫作包 C 節;禁揭詞包含寫作包 F 節所列尚不得出現的詞。只輸出場景卡。
```

## 帳本生成(S7)用的提示

```
以下是《補天錄》{卷}第 {N} 章的成稿、章節大綱與帳本模板。請產出本章帳本。
規則:只記正文裡確立的事實;不知道寫「未載」;「要點對照」把大綱每個情節要點對應到場景編號(以「＊」分場,S1、S2…);新增的專名、數字、稱呼、物件、設定細節都要登記;與大綱或設定有出入者寫入「與大綱出入」。
輸出:
=====帳本=====
(整份帳本)
```
