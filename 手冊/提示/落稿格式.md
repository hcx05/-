# 交付格式

模型的輸出用「區塊」分隔,`python3 工具/落稿.py` 才能解析。區塊標記是獨佔一行的 `=====名稱=====`,區塊之外的文字會被忽略。

**寫一個場景時,輸出**

```
=====正文=====
(只有這一個場景的小說正文,不含標題與場景標記「＊」)
=====場景末狀態=====
- 位置/時間:
- 在場者的傷勢、持物、情緒:
- 本場新出現的專名、數字、稱呼(一行一項):
- 與包內資料的出入(沒有就寫「無」):
```

**寫完全章後,輸出帳本**

```
=====帳本=====
(照 正文/帳本/模板.帳本.md 的格式填寫整份帳本)
```

**遇到無法決定的矛盾或缺漏,輸出**

```
=====待決=====
標題:
影響範圍:
雙方出處:
暫行做法:
建議選項:
```

**規則**
- 場景編號 S1、S2… 依章內以「＊」分場的順序;帳本「要點對照」要把章節大綱的每一個情節要點對應到場景。
- 帳本只記正文裡確立的事實;不知道寫「未載」,不要猜。
- 正文裡不要寫自己守了哪些規則,也不要附註解。
