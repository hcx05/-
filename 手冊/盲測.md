# 盲測:量化「可重現」

整套機制的目標是:**不同模型依同一個寫作包寫同一章,事實層不出現分歧**。這件事只能實測。本文規定怎麼測、怎麼讀結果、差異怎麼回灌成資料修補。

> 盲測寫的是**測試用稿**,放在 `/tmp` 或 `正文/計畫/_盲測/`,**不進正文、不進帳本、不提交**(`正文/計畫/_盲測/` 已列入 `.gitignore`)。

## 一、設計

- **同一份輸入**:同一章、同一個寫作包(`寫作包.py` 的輸出雜湊相同)、同一份場景卡(由其中一方產出後固定,或各自產出再比較——兩種都測)。
- **獨立**:各模型(或同模型不同次)互不看對方的輸出與推理。
- **各自走完流程**:S0 至 S7;每方交出「成稿 + 帳本」。
- **選章**:先選事實密度高、承接前章的章(例如第一部第 2 章:馬債逐項算帳、約法三章、與第 1 章末狀態相接);再選一個戰鬥章與一個群像章。

## 二、比對

```
python3 工具/盲測比對.py A.帳本.md B.帳本.md          # 帳本欄位:時間地點、人物狀態、物件、數字、專名、稱呼、要點對照
python3 工具/盲測比對.py --正文 A.md B.md             # 成稿:出場人名、數字片語、場景數、漢字數
```

「一致率」是**事實欄位相符的比例**(文字欄位用相似度門檻判斷是否在說同一件事),不是文筆相似度。它是下限估計:門檻之下的差異要人看,可能只是措辭不同。

## 三、怎麼讀結果

| 差異類型 | 意義 | 修補方向 |
|---|---|---|
| 一方的人物位置、傷勢、持物與寫作包 C 節不符 | 沒讀或誤讀章前狀態 | 檢查包 C 節是否夠醒目、是否缺欄位 |
| 數字不同(天數、銀兩、人數) | 大綱或設定沒給確定值,模型各自發明 | 在章節大綱或事實登錄補確定值,或登記為待決單 |
| 專名不同(路人、地名) | 大綱留白 | 在大綱列出,或規定「不起專名」 |
| 稱呼不同 | 稱謂表或聲口卡不夠明確 | 補稱謂表與帳本「稱呼」 |
| 要點對照不同 | 大綱要點粒度太粗 | 拆細大綱要點,或在場景卡模板加限制 |
| 一方越界(提前說出名字、秘密) | 禁區不夠明確 | 補稱謂表第二節的揭露節點;檢查器應已抓到,抓不到則補規則 |
| 兩方都沒問題但彼此不同 | 合理的創作差異 | 不處理 |

**每一條「資料不夠確定」的差異,都應該變成一次資料修補**:補到大綱、設定、事實登錄、稱謂表,或開待決單。修補後重產寫作包再測,直到事實層差異只剩合理的創作差異。

## 四、驗收線(建議)

- 帳本事實欄位一致率 ≥ 85%,且所有差異都能歸因(已修補或判為合理創作差異);
- 兩份成稿都通過 `正文檢查.py`(零錯誤);
- 兩份成稿都沒有越界揭露、沒有與寫作包矛盾的傷勢持物位置。

達標一次不代表永遠達標:稱謂表、聲口卡、大綱每有重大修改,抽一章重測。

## 五、紀錄

每次盲測在 `正文/待決/` 外另記一筆(可寫在對應章的帳本「與大綱出入」,或 [盲測紀錄](盲測紀錄.md)):日期、章、參與方式、一致率、差異歸因、做了哪些修補。
