# 鐵律卡

每章寫作包第一節都帶這張卡。完整規範見[正文/寫作規範](../正文/寫作規範.md);這裡只留最容易寫錯的。

**語言與格式**
- 繁體中文,白話為骨、略帶古典氣息;正文不用 Markdown 標記,場景切換用單獨一行「＊」。
- 引文、俗諺、典故只在確定貼切時用;不確定的出處不寫。

**視角與知情**
- 嚴守單一限知視角:只寫視角人物看得到、聽得到、想得到、此刻知道的。別人的內心只能經由行動與言語被推測。
- 角色與讀者此刻不知道的秘密,不說破、不暗示答案(清單見寫作包 F 節)。

**不得出現在正文裡的東西**
- 規劃用語:「男主」「女主」、事件編號(PRO-xxx、P1-xxx)、FACT/DEC/THR/SEC 編號。
- 戰力等級數字(L5、L12……)與遊戲式數值描寫;強弱只用場面表現。
- 現代計量與用語:公里、分鐘、小時、秒鐘等。時間用時辰、更、晝夜、節令;年齡用虛歲;相對時間不寫成年份。
- 術語表列為「避免寫法」的詞一律改用標準寫法(例如「靈氣」「內力」);寫之前對照[術語表](../設計規範/術語表.md)。

**事實以包為準**
- 人物的位置、傷勢、持物、稱呼、已出現的數字,以寫作包 C 節「章前狀態」為準;要改變須在本章用情節交代。
- 不得創造:未設定的能力、毒物、療法、穴位功效、歷史事件、新的重要人物。需要路人與配角時,只用一次性配角,並登記到本章帳本。
- 資料不足以下筆,或包內資料互相矛盾:停下,依[優先序與衝突](優先序與衝突.md)處理並開待決單;不要自行裁決。

**文風(摘要)**
- 場面是持續發生的生活:人物在做什麼、為何如此、旁人怎樣回應。重要處放慢,不重要處概寫;允許平凡的段落。
- 心理描寫是正當手段,但要有過程與依據;情緒已由場面傳達,就不再用旁白重述。
- 自然段落為常態;對白換人就換段;不為了「想停一下」而分段。
- 同一手勢、口頭禪、句式不要在相鄰兩三章反覆重演。
