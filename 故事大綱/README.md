# 《補天錄》故事大綱

以**世界大事件**為主軸的大綱:仙凡秘辛、王朝興亡、江湖格局變遷。
男主、女主只標示「在哪個事件中登場、與事件有何接點」,**個性、戰力、細節設定皆未定,可隨時調整**。

原則:兩人相遇後以並肩為主,三次分離都短(一季、數月、數月)且出於各自的主動選擇;女主是推動事件的人,不是被保護、被擄走或被利用的對象。

規模:序卷 + 三部,對標射鵰三部曲合計(約 280 萬字)。男女主 14 歲相遇,約 30 歲結局。

- [序卷_星墜](序卷_星墜.md):上古與前世代,大局的起因
- [第一部_少年遊](第一部_少年遊.md):盛世將傾
- [第二部_離亂行](第二部_離亂行.md):天下大亂
- [第三部_補天錄](第三部_補天錄.md):真相與補天
- [角色](角色/):男女主的個性、天賦與各階段成長
