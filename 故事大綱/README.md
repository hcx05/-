# 《補天錄》故事大綱總覽

> 暫定總書名:**《補天錄》**(三部曲 + 序卷)
> 類型:古代仙俠江湖 × 王朝興替
> 篇幅目標:約 **280 萬字**(對標射鵰三部曲合計),分序卷 + 三部,共約 **150 章**
> 主角:**陸懷川**(男)、**溫知微**(女),14 歲相遇,至 30 歲結局;序卷補寫兩人 0–14 歲及父輩往事

## 一句話故事

> 千年前天裂,仙人盡去,人間靈氣日衰。一個被滅門的邊軍遺孤與一個身負皇室血脈的青城醫女,在雙星墜落之夜同時降生。他們被操縱的命運推著相遇、相愛、分離、對立,最終發現所謂「仙途」是一場騙局——**補天不靠神器,靠人心**。他們選擇不開天門也不封天門,把天上的靈氣還給人間,讓仙與凡不再有高下。

## 本大綱的定位

粗略走向,供後續逐章細化。每一「篇」(故事弧)給出:時間、地點、核心事件、情感線、武學/世界觀推進、結尾鉤子。具體對白、細節與支線可在寫作時展開。
