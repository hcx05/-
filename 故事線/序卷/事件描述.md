# 序卷 事件描述

> 與 [時間線](時間線.md) 對應,事件 ID 為 `PRO-序號`。每個事件僅簡述,並列出章節、場景與出場角色。
> 角色與群體皆附連結;場景標「待建」者表示 `世界設定/場景設定/` 尚無對應建模。

### PRO-001 天裂之戰
- **序號**:1
- **時間**:千年前
- **章節**:第 2 章
- **場景**:[昆侖天痕](../../世界設定/場景設定/昆侖天痕/建模描述.md)
