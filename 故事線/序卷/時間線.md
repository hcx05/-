### 事件標籤

| 標籤 | 意義 |
|---|---|
| 敘事 | 交代背景、過渡 |
| 傳說 | 神話與古老傳聞 |
| 設定 | 世界規則的建立 |
| 誓約 | 立誓、約定 |
| 權謀 | 朝堂、勢力的算計 |
| 合謀 | 秘密串通、設局 |
| 衝突 | 對立與爭執 |
| 驚魂 | 緊張、危急、追殺 |
| 悲劇 | 失去與哀傷 |
| 死亡 | 角色死亡 |
| 伏筆 | 為後續埋下線索 |
| 懸念 | 留下疑問與期待 |
| 揭露 | 真相或身世被揭開 |
| 宿命 | 命運與預言的牽引 |

| 成長 | 能力或心境的變化 |
