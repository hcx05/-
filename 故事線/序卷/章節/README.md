## 事件的三種去向
- **演出**:在該章正文中發生的事件,事件描述的章節欄寫「第 N 章」。
- **提及**:不演出,由人物對話或回想帶過,章節欄寫「第 N 章(提及)」,並列在該章大綱的「提及事件」。
- **背景**:世界已發生、序卷正文不寫,章節欄寫「背景」;由後續各卷的人物在需要時帶出(例如五人結識、昆侖之變、太子之禍、女主的童年與日記殘頁)。

## 章節與時間順序
