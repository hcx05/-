## 章節與時間順序
- 第 1–36 章大致依時間順行;第 5–6 章、第 38–40 章為男主線與女主線並行異地,相對時間可能重疊,以閱讀順序排列。
- 第 37–41 章為本部唯一的分離段落:第 37 章雙方約定,第 38 章男主線,第 39–40 章女主線,第 41 章重聚。
- 第 11–14 章、第 29–31 章、第 42–43 章為群像章,男女主多為旁觀或配角,章中保留男女主的小拍點。

## 寫作提醒
- 栗子糖只在第 1、37、41 章出現,偷馬與「先吃飯」的回響集中在第 1 章與第 23 章墳前,避免回響過度。
- 懷虛子在第 39–41 章必須是真的慈祥;裂縫只在墨色、字句與女主的隱瞞,不揭穿。
- 宋明遠之死(第 37 章)不渲染過程;重點在男主的「是我」與宋青崖的「給我一點時間」。
- 敘事形式(視角安排、框架、倒敘)屬正文階段,本章節大綱的「視角」僅指焦點人物。
