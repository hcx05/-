## 寫作提醒
- 本卷只有三位新登場者:苗阿婆(第 8 章)、小禾(第 34 章)、胡一口(第 50 章);其餘皆為回頭客,首次出場的章節以「重新登場」立住身份與外貌,相隔久的另有「回頭提示」。
- 第 13–21 章為男女主分離段,女主線(第 15、16 章)與男主線(第 17、18、19 章)在時間上交錯,章序不等於時間序;三日一信的密語寫在藥方裡,最後一行問吃飯。
- 慧淨的偈語拆兩半:第 5 章聽懂「門本無門」,第 42 章聽懂「心自為門」;兩次都只多一半,不寫成宣講。
- 第 25 章柳煙之死:先讓讀者笑一下,再立刻痛;「這回不繞,我直走」與「這張臉,借我用一下」不加長哭戲。
- 第 32 章阿古與男主勢均力敵,是因為阿古在玄朔軍中磨出實力(D 階段記為約 L15)、男主不用內力外放;戰力差須在階段 D 與戰力基準對上。
- 第 15、41、43、50 章是栗子糖的回響:每次只輕提一筆,第 41 章糖回到手裡,第 43 章「糖,別放壞了」,第 50 章她吃下第一顆。
- 懷虛子(第 15、23、41、43 章)的溫柔是真的,不寫偽善,也不替他洗白;第 41 章不出現任何武力。
- 第 38 章的覆鐘要與第二部慧淨的金鐘罩呼應:這次有人撐;第 44 章補天不是特效大戰,重點是兩人放下東西的動作。
- 回響(偷馬、先吃飯、栗子糖)只在指定章節出現,其他章不提;第 50 章不解釋、不總結。
- 敘事形式(視角安排、框架、倒敘)屬正文階段,本章節大綱的「視角」僅指焦點人物。

## 階段 C 吸引力自檢(story-appeal-architect)

> 依 [吸引力分析](../吸引力分析.md) 的回寫清單逐章核對:十八個關鍵場面都有落點章,情緒回報與牽引都寫進各章「吸引力設計」;以下是章節層級的最弱處與四項反證結果,未發現需要改動大綱的缺口。

**最弱的三章(只加小細節,不改走向)**
1. **第 20 章 密約**:密約內容讀者已猜到;已由林棲鶴簽名手抖、鐵無情託柳煙帶話、柳煙提著酒走三條街三個人物細節承擔看點。
2. **第 28 章 渡江**:戰爭開幕易流於陳述;以老兵一句話與龍鎮江「不退一步」立住人,把壓力交給下一章的霍小滿。
3. **第 46 章 大昭終結**:政治收束;以韓戩推辭三次、鐵無情不開口、晏長庚埋璽三個動作承擔情緒,審判不寫成大秀。

**四項反證**
- 無情緒測試:第 25 章把「柳煙」換成「某護法」,替身只剩詭計;因有「這回不繞」的口頭禪與整卷的玩笑才成悲劇。第 38 章覆鐘換成任何防禦招式,慧淨之死的回收就消失;因此該章必須有慧明在背後撐。
- 劇透測試:知道懷虛子崩潰時說「糖,別放壞了」,回看第 15、41 章的粥與栗子糖更令人發冷;知道偷馬少年是誰的兒子,回看第 35 章的婚禮更暖。
- 期待測試:第 41 章前,讀者能說出兩種結果(她揭穿到底、她留一條路);第 43 章前,能說出懷虛子是被救還是崩潰。
- 平淡測試:讀者能指出喜歡的人(柳煙、胡不歸、沈滄溟、阿荷)、期待的場面(大典、江心對決、補天、偷馬)、難忘的抉擇(她站在師父身邊揭穿、兩人爭獨赴、他把劍插回劍冢)。

**需在階段 D 注意**
- 阿古的戰力進程(第 32 章勢均力敵)與胡不歸、慧明在第 38 章的戰力,須在武學紀錄中交代並同步戰力基準(DEC-061)。
- 回響(偷馬、先吃飯、栗子糖)只在指定章節出現,記憶與感情紀錄不要額外再引。
