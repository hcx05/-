## 寫作提醒
- 新登場者集中在第 8、14、19、24、27、34、36 章,每章不超過 2 位;正文首次出場時要立住外貌或口頭禪(見各章「群像補充」)。
- 第 35、41 章是曹無咎與懷虛子的「回頭提示」章:一個帳尾暗記、一包栗子糖,輕輕提一筆就好,不要提前揭曉。
- 慧淨之死(第 29 章)用克制寫法:護人者無法還手是重點;凶手的身分不在章內揭曉,第 48 章懷虛子現身才連上。
- 男主「不拔劍」貫穿第 13–46 章:第 38–39 章是隔布共鳴,第 47 章是請他動手才出鞘;不要在中途破例。
- 第 48 章結尾刻意留下跨卷懸念(分離),由第三部第 1 章「重逢」收束。
- 敘事形式(視角安排、框架、倒敘)屬正文階段,本章節大綱的「視角」僅指焦點人物。
