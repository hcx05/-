## 約定

- **路徑**:`正文/{卷}/第N章_標題.md`。
- **依據**:每章以 [章節大綱](../故事線/序卷/章節/README.md) 為藍本,事件、出場者、視角、資訊揭露不得與凍結骨架衝突;大綱不寫的細節,正文可以補,但要登記在下方「正文補充登記」。
- **文風**:白話為骨,略帶古典氣息;敘述平實,情緒靠動作、神色與語氣承載;比喻、成語、省略號從簡。由 `jinyong-prose-style` 技能約束,只管表達,不增刪內容。
- **視角**:依章節大綱的「視角」欄。序卷三章以懷川(男主)為主視角,第 2 章末短場轉阿古;女主在序卷第 3 章末才登場,不設她的視角(DEC-073)。
- **用詞**:遵守 [術語表](../設計規範/術語表.md);時間用相對時間,年齡用虛歲,戰力不在正文出現數字。
- **段落格式**:標題後附一行引言(視角、時間、對應事件);場景切換用單獨一行「＊」。

### 第 1 章 斷碑村
- **日期與場景**:後 12 年臘月初七(馬賊夜襲)、初八即臘八(黑衣衛入谷)。村口斷碑旁有一間茅草大棚養村裡的馬(老灰寄養此處);七叔的院子在村東最末,院前為夾在兩道土牆間的窄巷(約 60 步),院後為柴棚、荒地與炭窯所在的後山。
- **七叔(秦七)的日常**:對外是燕北軍老伙夫,村人叫「老七」,懷川叫「七叔」;左頰刀疤自眼梢斜拉到嘴角,對外說是「嫌湯鹹被軍爺拿刀鞘敲的」,懷川七歲時問過,被一句「吃飯」擋回。他的湯麵出名的鹹;每年臘八煮羊肉湯麵(蕭婉的做法)。
- **懷川**:每日站樁三刻;守心訣數息到九十幾時腦子裡會冒出「一隻會飛的羊」(小毛病,未告訴七叔)。七歲爬過斷碑,被七叔拎下,是七叔唯一一次動手,手在發抖;七叔夜半在碑前站半個時辰,說是「看雪」。
- **阿古**:念「懷穿」已四年;右門牙缺一角(去年冬天墜馬);棗紅三歲駒追風(十歲生辰他爹所賜);氈襪口金線纏枝(說是「我娘手笨,拿金線蓋破口」);頭頂編細辮;自稱牧人之子,護衛(戴黑貂皮高帽、帽沿銀狼頭的老漢與一人)自稱「放羊的」,以低長號角傳警。
- **賭騎**:懷川以老灰先走兩里,從界碑到歪脖老榆樹;抄蘆葦小徑,贏半個馬身,裁定平手,各洗三天馬槽。
- **民間傳說**(里正齊老爹在村口老樹下講古):天原本一整塊;神仙下凡;天上與天外打起來,天破一條縫;神仙去向三說(回老家、死光了、打輸逃了);留下四件東西(劍、盤、鐘、印),分給四戶人家守;天上不再給靈氣,故今人練武只靠自己那點氣;銀河是縫。不點名守天人與斷天劍。
- **童謠**:孩子跳繩唱「破軍墜北,紫微落西。雙星合,天門開;雙星離,天下亂」;七叔以糖瓜支開,說「最後一個字,臘月裡唱這個招災」。
- **皮貨商**(一次性配角,不另建檔):四十上下,羊皮襖、瘦驢、兔皮五百文一張咬死不降,手掌無繭、看人先看手肩腳下;三天前到村;馬賊事後向南(雁回關方向)離去,翌晨在斷碑前為黑衣衛指路。
- **靖邊槍四式的鄉下名**:點=點豆子,掃=掃雪,挑=挑糞,釘=釘樁子;規矩:村裡人面前不許使,不認識的人旁觀時更不許。「偷什麼都好,就別偷馬」「馬記仇」。
- **馬賊**:九人,灰狼毛皮帽,拖半截狼尾;玄朔「無主之人」;首領瘦高三十餘歲,說玄朔話,認出「靖邊」槍路;兵器為短柄斧、骨刀、釘頭木棒。懷川以榆木牧羊杖(頭彎鉤)點倒一人後杖斷,左肩被棒擊(筋腫,非骨折),肋下受踹;阿古以「絆」「背」摔倒首領;七叔以鋤頭「挑轡頭、掃踝、釘袍角、柄尾撞心窩、掌拍耳根」二十餘息打翻,放人,「馬留下,人帶走,天黑前出谷」。
- **七叔的玄朔話**:說得慢、咬字重,是多年前學的。
- **臘八晨**:七叔刻意切歪麵、湯偏鹹;懷川覺得「喝過這個」(夢中那碗湯);十二個饅頭、新棉襖、鞋底、油布、鹽、火鐮裝成青布包袱,要他去後山炭窯待到天黑;預告午後起白毛風。
- **黑衣衛**:十三騎,黑衣黑甲面巾,腰懸細長微彎、鞘口泛藍光的刀;首領鐵無情四十上下、面如鐵鑄、此時左頰無疤。

### 第 2 章 風雪訣別
- **設局**:七叔昨夜佈置——窄巷中段橫一根塗黑油的麻繩(離地一尺)、浮土下淺坑與三根削尖木樁、牆頭茅草下伏槍;槍為自鍛槍頭配白蠟桿,藏於柴棚地板下。
- **戰況**:鐵無情先遣兩騎探路——前者絆馬落坑而死,後者被牆頭一槍刺喉;其後十人分三隊(四人沿巷推進、三人攀牆、三人繞荒坡抄後)。牆頭一死一被甩下巷內,共四人死;飛刀傷七叔左肩。院內七叔以槍尾、槍尖撂倒三人(傷),懷川以灶上鹹湯潑破窗而入者(傷)——共傷四人。
- **鐵無情的刀法**:刀背貼桿滑行削握槍之手,專剋長兵;七叔鬆後手讓桿被劈成兩截,以半截槍頭與腰刀貼身,刀劃破鐵無情左頰(顴骨至下頜),自己被刀貫穿左腹下三寸。鐵無情見到懷川的臉,說「是他」。
- **白毛風**:自草原卷來;黑衣衛撤出院子,守住巷口與谷口。七叔拄鋤頭、腰後掖半截槍頭,由懷川攙著走鹿道(獵人小徑,去年秋七叔帶懷川閉眼走過一遍)上後山炭窯;炭窯早備柴、稻草、兩床舊被、水罐。
- **秦七遺言**(炭窯夜):他姓秦排行七是真;他是陸驍的兵與親衛,跟了十三年;「懷川」為陸驍所起(「咱們這輩人都在邊關,兒子總得記著水往哪個方向流」);蕭婉拚酒贏過全營校尉;九年前的臘八(滅門夜)陸驍擺了一桌,蕭婉下的羊肉湯麵,懷川吃了半碗、灑在她衣襟;三路人(燕北兵、黑衣衛、披紅斗篷的邪教),帶路的是「姓高的」;陸驍年輕時在京城被偷一匹馬,追三條街到死胡同,賊為給娘抓藥,陸驍付藥錢、兩人坐門檻喝酒(即高承嗣,不點名);「京裡出了大事,太子沒了,緊跟著輪到咱們」;陸驍託付只一句「讓他先吃飽」;逃亡十一天,懷川不吃,七叔學蕭婉說「小子,吃飯」;半枚青銅虎符(另一半在一人手裡,他會來找你;別信穿官衣的、別信自稱認識你爹的、別信自己一時火氣);守心訣總訣、三守、軍中戒;往南走,過白水河一路到蜀;斷碑「不乾淨,往後也別去」(到死不說);「阿古不是尋常牧人的孩子」;最後「記得吃飯」。
- **埋葬**:天亮前七叔斷氣;懷川先燒火融凍土,以鋤頭挖墳於後山荒坡一棵被雷劈過的枯樹下(七叔七歲那年指給他的位置),腰刀陪葬;紅布取自包饅頭的舊布;鋤頭倒插、紅布條繫柄;槍頭另裝新削白蠟桿,歪歪扭扭;背槍、虎符、狼牙南下。
- **阿古後記**:臘月初九午後,阿古夜裡溜出氈帳,老羊倌追在後頭;孫嬸、齊老爹(「我老頭子今兒沒看見你」)說黑衣衛昨日圍村、今日晌午離去;「那個黑臉的官爺在樹底下站了好一會兒」;他以小彎刀(巴掌長,鹿皮鞘,綠松石柄,八歲生辰阿爸所贈)插墳前凍土,以玄朔話立誓:「兄弟的父親就是我的父親,我會替你找到他」,又對南方喊「你欠我一碗麵」。

### 第 3 章 劍門秋雨
- **兩年**:冬季在黃河渡口扛鹽(三四十斤一包),船老大收留,人稱「北佬」;春入馬幫(老楊頭),因看牲口有一手管馬棚,懷川教騾子肚脹「牽著走一個時辰」,被稱「牽馬小子」;第二年臘八困在大散關下柳林鋪,喝甜粥後在雪地裡站樁三刻;秦嶺北麓茶棚婉拒賣餅婦人的餅;騾夫老張唱童謠,說有披紅斗篷的在蜀道打聽北邊來的十四五歲少年,賞銀五十兩;漢中車馬行(掌櫃精瘦、不收紅衣人銀子),懷川藏在閣樓聽見兩個紅衣人以他的特徵打聽,從屋脊翻出,睡亂葬崗。
- **血月教人物**:暗紅斗篷,呼吸如砂紙磨喉;三人用短鉤(一對月牙鉤)、懸梁吊底、鎖鏈月牙刀片;其中一人額頭有新月形血紋。
- **棧道之戰**:懷川以槍「點、挑、掃、釘」,鬆前手讓鉤脫離(學自第 2 章七叔鬆後手);第一人被掃出欄杆墜澗,下方傳來悶響不像落水(生死不明);第二人倒掛於木板下,被「釘」穿手;第三人用鎖鏈月牙刀片劃傷懷川左肩並扯走包袱(十幾個乾餅、鹽、半吊銅錢)落澗;懷川撬掉三塊木板斷路,一丈缺口隔開兩人。
- **山神廟**:半堵牆,供桌兩個乾餅;他磕頭「借一個」,吃半個,另半個放回「留給下一個人」。
- **劍門關**:兩壁石山夾一座城樓;關門夜閉,需路引(他沒有);鏢師閒談「關上盤查緊,抓北邊來的半大小子」。
- **劍門驛**:低矮石屋,簷下褪色破燈籠(「驛」字),旁有茅草頂馬棚(三四匹馬);老馬頭瘸左腳(痛風),拄長拐;黑馬積食躺倒,「怪丫頭」賭「治好歸她、治不好賠三十兩」。懷川在馬幫學過,認得是積食,「牽著走一個時辰就能騎」。追兵火把在三四里外、有騎有步。
- **女主初登場**(僅由他的眼睛看):蹲在黑馬腹後,深青勁裝、袖口束緊、窄皮帶、連鞘的劍靠柱旁,劍柄纏舊布條磨得發灰;比他矮半個頭;布帶束髮;眉目清朗而銳利;以一寸細針抵他左腕內關穴,說「那是我的馬」。序卷不寫她的名字、師父或來歷。
