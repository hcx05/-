# 正文

小說正文。企劃層(大綱、時間線、事件描述、章節大綱、角色與世界設定)完成後,依章節大綱逐章寫成的敘事文字。

## 約定

- **路徑**:`正文/{卷}/第N章_標題.md`。
- **依據**:每章以 [章節大綱](../故事線/序卷/章節/README.md) 為藍本,事件、出場者、視角、資訊揭露不得與凍結骨架衝突;大綱不寫的細節,正文可以補,但要登記在該章的[帳本](帳本/README.md)。
- **文風**:白話為骨,略帶古典氣息;敘述自然而有厚度,人物的心思、身體感受與生活環境與動作、對話並重,直接的心理描寫是正當手段;比喻、成語、省略號從簡,不重複解釋已明白的情緒。文學寫作原則的正本是 [寫作規範](寫作規範.md)。寫作與改稿用 `jinyong-prose-style`;受要求的文學審查與跨章比較用 `prose-quality-review`,兩者職責不同;每章的完整創作流程見[生成手冊](../手冊/生成手冊.md)。技能與規範只管表達:不得擅改既定的重大劇情與規則;新寫時可補足普通場面細節,其中需跨章延續的具體事實,登記在該章的[帳本](帳本/README.md)。
- **視角**:依章節大綱的「視角」欄。序卷三章以懷川(男主)為主視角,第 2 章末短場轉阿古;女主在序卷第 3 章末才登場,不設她的視角(DEC-073)。
- **用詞**:遵守 [術語表](../設計規範/術語表.md);時間用相對時間,年齡用虛歲,戰力不在正文出現數字。
- **段落格式**:標題後附一行引言(視角、時間、對應事件);場景切換用單獨一行「＊」。
