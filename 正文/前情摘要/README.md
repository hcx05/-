# 章末狀態摘要

每寫完一章,在 `正文/前情摘要/{卷}.md` 追加一節,供下一章的上下文包使用(`工具/章節包.py` 會取本章之前最近兩章的摘要)。

## 為什麼需要它

[正文補充登記](../README.md) 只記「新增的事實」;它不回答「這一章結束時,每個人在哪裡、身上帶著什麼、心裡剛剛得知什麼」。下一章要接得上,靠的是這份狀態,不是重讀全文。

## 格式

檔名 `{卷}.md`(例:`第一部.md`)。每章一節,標題固定為 `## 第 N 章 標題`(章節包靠這個標題找)。每節 150 至 300 字,只寫事實,不寫評論:

```
## 第 N 章 標題
- **結束時刻**:時間、地點、天候(影響下一章開頭的部分)
- **在場者與去向**:誰在場、誰離開、往哪裡去
- **身體與隨身物**:傷勢、疲勞、飢渴、手上與身上帶著的東西
- **剛得知**:誰得知了什麼;誰知道「他知道了」
- **懸而未決**:本章留下的承諾、疑問、待辦(可附事件 ID、THR 編號)
- **下一章必須接上**:開頭要延續的動作、對話或物件
```

## 規則

- 摘要是衍生資料:與該章正文不一致時以正文為準;跨章要延續的新增事實,仍登記在 [正文補充登記](../README.md)。
- 不放文學評語,不放對下一章的劇情預測;下一章的內容以章節大綱為準。
- 章節正文移除或重寫時,該章的摘要同步刪除(摘要沒有獨立於正文的價值)。
- 這份檔案不進 `工具/檢查.py`,沒有格式關卡;只有章節包會讀它。
