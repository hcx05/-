# 帳本

每寫完一章,必須產出一份該章的**結構化帳本**(`{卷}/第NN章.帳本.md`)。它取代了過去 [正文 README](../README.md) 裡逐章堆疊的自由文字「正文補充登記」(舊文保留在 [補充登記_舊.md](補充登記_舊.md),僅供查證,不再增補)。

帳本有三個用途:

1. **下一章的起點**:[寫作包](../../手冊/生成手冊.md)的「章前狀態」由前章帳本折疊而來,模型不必重讀前文就知道誰在哪、誰受了傷、誰帶著什麼。
2. **跨章延續的事實清單**:新增的專名、數字、稱呼、物件、設定細節都有 ID,可查、可回補、可檢查。
3. **機器檢查的依據**:`python3 工具/檢查.py` 解析帳本格式、驗證回補路徑、檢查要點覆蓋;`工具/帳本合併.py` 折疊出 [累積狀態](累積狀態.md)。

## 規則

- **只記正文裡確立的事實。** 不知道就寫「未載」,不要猜、不要沿用設定檔的說法。正文與設定檔衝突時,以正文為準並在「與大綱出入」登記(見 [優先序與衝突](../../手冊/優先序與衝突.md))。
- 表格內不要出現直線符號 `|`;無內容的區塊寫「(無)」。
- 人物欄用 [ID對照](../../設計規範/ID對照.md) 的名稱(男主、女主用代號);一次性配角用劇中稱呼。
- `累積狀態.md` 是導出檔,不可手改;帳本改動後執行 `python3 工具/帳本合併.py` 重建。

## 區塊與欄位

| 區塊 | 欄位 | 說明 |
|---|---|---|
| 摘要 | 條列 2 至 4 行 | 供寫作包的「近三章摘要」使用 |
| 時間地點 | 項目、內容 | 必填「起」「迄」兩列,另可記季節天候 |
| 章末人物狀態 | 角色、位置、傷勢、持物、狀態、本章新知、本章新疑 | 本章出場且狀態有變的人;下一章以此為起點 |
| 物件 | ID、名稱、持有者、狀態 | ID 為 `ITM-` 加簡短中文名,同物件全卷同 ID |
| 數字事實 | 項目、值、備註 | 人數、天數、距離、金額、年歲等之後可能被引用的數字 |
| 稱呼 | 誰、稱呼誰、用語、備註 | 人物之間的稱呼,及敘述者對人物的稱呼 |
| 新增專名 | 類型、名稱、登記、備註 | 登記欄:`已建檔` / `一次性` / `待建檔` |
| 新增事實 | ID、事實、回補 | ID 為 `TXT-{卷碼}-{章}-{序}`;回補欄見下 |
| 伏筆動作 | THR、動作、備註 | 設置 / 推進 / 回收 / 未動 |
| 要點對照 | 要點、場景、備註 | 章節大綱「情節要點」每一點都要對應到場景編號(S1、S2…,以「＊」分場) |
| 與大綱出入 | 條目、處置 | 處置:`接受` 或 `待決(Q-xxx)` |

### 回補欄寫法

- `已回補→路徑`:事實已寫入該設定檔(路徑必須存在,檢查腳本驗證);
- `已回補(說明)`:已併入多處(例如序卷 G4),不指定單一路徑;
- `待回補`:尚未寫入設定檔,階段 E 回補後改為已回補;
- `無需回補`:僅屬本章場面,不影響後續。

## ID 規則

| 前綴 | 意義 | 範例 |
|---|---|---|
| `TXT-{卷碼}-{章}-{序}` | 正文新增事實 | `TXT-PRO-03-08`、`TXT-P1-01-02` |
| `ITM-{名}` | 物件 | `ITM-虎符` |
| `Q-{三位數}` | 待決單,見 [待決](../待決/) | `Q-001` |

卷碼同事件 ID 前綴:序卷 `PRO`、第一部 `P1`、第二部 `P2`、第三部 `P3`。
