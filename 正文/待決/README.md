# 待決單

寫作中發現資料矛盾、缺漏,或需要作者/使用者拍板的事項,不要自行發明或默默擇一:在這裡開一張 `Q-xxx.md`,寫作先採用單上的「暫行做法」,並把帳本「與大綱出入」的處置欄寫成 `待決(Q-xxx)`。

## 單的格式

```
# Q-001 標題
- **狀態**:待決 / 已決(決定日期與決定內容)
- **影響範圍**:卷、章、檔案
- **雙方出處**:A 說…(檔案路徑);B 說…(檔案路徑)
- **暫行做法**:在決定前,寫作時怎麼處理
- **建議選項**:1… 2…
```

決定後把「狀態」改為已決,依[變更傳播](../../設計規範/建檔架構與順序.md)同步企劃檔,並在[設計決定記錄](../../設計規範/設計決定記錄.md)登記為 DEC。
