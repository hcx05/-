# 計畫

寫作中的工作檔:場景卡與場景稿。章成稿後它們是過程紀錄,不是正本(正本是 `正文/{卷}/` 與[帳本](../帳本/README.md))。

| 檔案 | 說明 |
|---|---|
| `{卷}/第NN章.場景卡.md` | 流程 S1 的產出:把本章拆成場景,每個情節要點都要被涵蓋;模板見 [模板.場景卡.md](模板.場景卡.md) |
| `{卷}/第NN章/場景NN.md` | 流程 S2 的逐場景生成稿,由 `工具/落稿.py 場景` 存入 |
| `{卷}/第NN章/場景NN.末狀態.md` | 各場景的末狀態,供下一場景與帳本使用 |

檢查場景卡:`python3 工具/落稿.py 場景卡 {卷} {章} {場景卡檔}`。
