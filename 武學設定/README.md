# 武學設定

以中國實際的**古武術、中醫、道術**為根基,發展出本世界獨有的宗派與體系。

## 資料夾
- `總綱/`:設計原則、三源合流的修行理論、境界與戰力天花板
- `宗派/`:各宗派的源流、理念、核心功法、代表人物與戰力層級
- `功法/`:依類型整理的功法總錄(內功、拳掌、兵器、身法、醫術、道術陣法、邪門)
- `超自然/`:仙術(道家)、妖術(民間方術)、佛門神通三套體系,皆為武學的加成,不凌駕武學

## 設計原則
1. **現實為本**:經絡穴位、拳種兵器、內丹周天、本草針灸皆取自真實傳統,不憑空發明新原理。
2. **世界獨有化**:在現實體系上疊加本世界的「靈氣」「天痕」「星命」,產生專屬流派與境界。
3. **三源合流**:武(筋骨與招式)、醫(經絡與藥石)、道(周天與陣符)互相支援也互相克制,沒有單一體系通吃。
4. **戰力天花板**:佛門最高宗師為世界戰力的頂端,任何人最多與之齊平,不可超越(詳見 `總綱/境界與戰力天花板.md`)。
5. **超自然僅為加成**:仙術、妖術、佛門神通皆有嚴格上限與代價,不能取代武學(詳見 `超自然/README.md`)。
