# 典籍

本世界的重要經典與殘卷。正文為文言,說明為白話。

| 典籍 | 類型 | 流傳 |
|---|---|---|
| [封天九章](封天九章.md) | 靈能(仙術、陣法)兼武學心法 | 守天人所傳,原九章,存八章半 |
| [守心訣](守心訣.md) | 武學內功 | 靖邊軍口授的節選本,出自《封天九章·守心章》 |
| [天痕殘卷](天痕殘卷.md) | 古籍殘卷(設定資料) | 岑照於昆侖天痕所得,殘缺 |

## 設計定位
這幾部典籍的定位是「**根基與理念**」,不是「升級捷徑」:
1. **不提升戰力上限**:全文強調「道盡於人,不可問天」,與 L25 的世界天花板一致。習得全部章節,最多是根基穩固、少走彎路,不會因此超過佛門頂端。
2. **有代價**:《封天九章》明言「修之過,則神耗,神耗則壽損」,對應靈能體系中「神」的消耗規則。
3. **不取代悟性**:典籍給的是方法,領悟仍要靠人。男主的悟性曲線(前期普通、第二部開竅)不因典籍而改變。
4. **與主題呼應**:全書主題是補天靠人心、疏導而非封堵,《疏導章》《禁章》是這個主題的古代版本。

## 關係與出處
- 《守心訣》是《封天九章·守心章》的軍中節選,所以男主的守心訣底子,實際上來自守天人的遺訣;這也解釋為何他日後重修迅速、能承受戾氣。
- 懷虛子所竊取的「守天人遺訣」只是《封天九章》的部分內容,他所得的《天痕殘卷》則是另一路資料。
- 《天痕殘卷》中「門後」「無生無死」一類語句語意含糊,可以被誤讀,留給劇情使用。
- 《封天九章》第九章已佚,僅存「歸」字,是後續劇情的未解部分。
