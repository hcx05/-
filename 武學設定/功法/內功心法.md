# 內功心法

| 名稱 | 派別 | 現實對應 | 特點 |
|---|---|---|---|
| 大雲心經 | 大雲寺 | 易筋經、洗髓經 | 深厚綿長,以靜制動 |
| 兩儀心法 | 太初觀 | 太極內功 | 陰陽調和,借力 |
| 觀星引氣訣 | 問天宗 | 道家服氣 + 星象 | 引星辰之力 |
| 青城養氣訣 | 青城 | 道家養生功 | 偏長壽、療傷 |
| 守心訣 | 靖邊軍 | 軍中站樁與呼吸法 | 穩固心神、耐壓;節選自《封天九章·守心章》,見 [典籍](../典籍/守心訣.md) |
| 劍心訣 | 釣鰲島 | 劍術養氣 | 劍意與內功合一 |
| 逆月訣 | 拜月教 | 逆行周天 | 速成、後患大 |
| 封天九章 | 守天人 | 上古遺訣 | 與天痕共鳴;見 [典籍](../典籍/封天九章.md) |
