# 兵器

> 兵器是套路型的載體。每種兵器有自己的**距離、軌跡、受制點**;寫兵器戲先寫距離,再寫招。招式拆解見 [套路錄](../招式/套路錄.md)。

## 一、兵器邏輯

| 兵器 | 距離 | 邏輯 | 受制 |
|---|---|---|---|
| 槍 | 長 | 一寸長一寸強;突刺為主,軍陣與騎戰主力 | 近身後難施展 |
| 橫刀、陌刀 | 中 / 重 | 橫刀近身;陌刀重劈,破陣 | 笨重,不耐持久 |
| 劍 | 中 | 靈活;可刺可擊,技巧為主 | 重兵器與群戰 |
| 彎刀 | 中 | 弧線出刀,騎戰與夜戰 | 近距受限 |
| 針 | 近 | 醫武兩用;點穴封脈 | 近身機會 |
| 棍 | 長 | 守勢棍法,橫掃截擊 | 需空間 |
| 弓馬 | 遠 | 騎射 | 近戰與地形 |

## 二、總錄

| 兵器 | 流派 | 說明 |
|---|---|---|
| 槍 | 靖邊軍 | 靖邊槍,軍中主力;袁破虜的鐵槍、高承嗣的北境槍法同屬長槍 |
| 橫刀、陌刀 | 靖邊軍 | 唐代軍刀,陌刀重劈 |
| 劍 | 太初觀、釣鰲島、棲霞閣、宗室 | 各派劍法:太初劍(圓)、歸墟九劍(點)、棲霞劍(快)、宗室劍術(規矩) |
| 彎刀 | 拜月教、玄朔 | 弧線出刀 |
| 針 | 青城、棲霞 | 醫武兩用 |
| 棍 | 大雲寺 | 伏魔棍 |
| 弓馬 | 靖邊軍、玄朔 | 騎射 |
| 斷天劍 | 補天四器之一 | 神器,與破軍星命共鳴;認主後有效 +1 L,並引動持劍者戾氣 |

## 三、寫法提醒

- 同樣是劍,**太初劍寫圓、歸墟九劍寫點、棲霞劍寫快、宗室劍寫正**;不要全寫成「劍光閃爍」。
- 槍與劍的對照是男主的核心:槍是軍中的粗實,劍是神器的重;他的劍勢中帶槍路(P1-076 高承嗣認出)。
