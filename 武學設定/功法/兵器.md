# 兵器

> 兵器是套路型的載體。每種兵器有自己的**距離、軌跡、受制點**;寫兵器戲先寫距離,再寫招。招式拆解見 [套路錄](../招式/套路錄.md)。暗器與弓弩見 [暗器與遠程](暗器與遠程.md);鑄造與名兵見 [機關與鑄造](機關與鑄造.md)。

## 一、分類

| 類別 | 說明 | 代表 |
|---|---|---|
| 長兵 | 距離長,穿刺與橫掃;軍陣主力 | 槍、矛、戟、棍、棒、陌刀 |
| 短兵 | 近戰靈活,技巧為主 | 劍、刀、匕首、判官筆、峨眉刺 |
| 軟兵 | 可彎曲,出其不意,需要空間與技巧 | 軟鞭、九節鞭、鏈、繩鏢、三節棍 |
| 重兵 | 重劈與重擊,破甲與破陣 | 錘、斧、鉞、鐧、狼牙棒 |
| 奇門兵器 | 以特殊形制取勝 | 鉤、拐、扇、傘、雙刺 |
| 針與細器 | 醫武兩用 | 針、細刃 |
| 遠程 | 弓、弩、投擲 | 見 [暗器與遠程](暗器與遠程.md) |

## 二、兵器邏輯

| 兵器 | 距離 | 邏輯 | 受制 |
|---|---|---|---|
| 槍 | 長 | 一寸長一寸強;突刺為主,軍陣與騎戰主力 | 近身後難施展 |
| 棍、棒 | 長 | 守勢棍法,橫掃截擊;不見血,易降服 | 需空間 |
| 橫刀、陌刀 | 中 / 重 | 橫刀近身;陌刀重劈,破陣 | 笨重,不耐持久 |
| 劍 | 中 | 靈活;可刺可擊,技巧為主 | 重兵器與群戰 |
| 彎刀 | 中 | 弧線出刀,騎戰與夜戰 | 近距受限 |
| 軟鞭、鏈 | 中 | 繞、纏、擊,出其不意 | 空間狹窄、需要熟練 |
| 錘、斧 | 短 / 重 | 重擊破防 | 笨重,耗力 |
| 針 | 近 | 醫武兩用;點穴封脈 | 近身機會 |
| 判官筆、峨眉刺 | 近 | 點穴與刺擊 | 力道小,需準 |

## 四、寫法提醒

- 同樣是劍,**太初劍寫圓、歸墟九劍寫點、棲霞劍寫快、宗室劍寫正**;不要全寫成「劍光閃爍」。
- 槍與劍的對照是男主的核心:槍是軍中的粗實,劍是神器的重;他的劍勢中帶槍路(P1-076 高承嗣認出)。
- 軟兵與奇門兵器宜少量使用,作為特定人物的標誌,而不是每個配角都換一件。
