# 拳掌與外功

> 外功是套路型的主場:最容易寫出具體畫面,也最容易寫成「換個名字的同一場架」。每門外功要有自己的**距離、節奏、受力點**。招式拆解見 [套路錄](../招式/套路錄.md)。體能與硬功的修煉面見 [體術與橫練](體術與橫練.md);兵器見 [兵器](兵器.md)。

## 一、分類

| 方向 | 特徵 | 子類 |
|---|---|---|
| 拳 | 以拳為主,打法剛猛或連綿 | 長拳、短打、形意、洪拳、羅漢拳 |
| 掌 | 以掌為主,化力與擊打並用 | 綿掌、鐵砂掌、八卦掌、大雲手 |
| 腿 | 以腿為主,攻下盤與中距 | 潭腿、戳腳、旋踢 |
| 指爪 | 以指或爪為主,攻要害或點穴 | 一指禪、鷹爪、點穴 |
| 摔拿 | 貼身、制服、摔倒、擒拿 | 玄朔摔跤、擒拿手、大雲手之擒拿 |
| 肘膝靠 | 近身短打 | 八極、通臂 |

## 二、克制與特徵

| 方向 | 特徵 | 克制 |
|---|---|---|
| 硬功類 | 護體與重擊,硬抗 | 點穴、毒、陣法 |
| 柔勁類 | 化力、借力、圓轉 | 突襲、不出力 |
| 摔拿類 | 貼身、制服,節奏慢但不可逆 | 兵器、拉開距離 |
| 點穴類 | 以指或針封脈 | 硬功、金鐘罩 |
| 腿法類 | 長距離、下盤 | 近身貼靠 |

## 四、寫法提醒

- 硬功寫「承受」(聲音、反震、姿勢不動),不寫「打得多重」。
- 柔勁寫「對方的力去了哪」,讓讀者看見轉彎。
- 摔拿寫重心與地面,節奏慢但不可逆。
- 點穴寫「一瞬間的停止」,代價是需要近身,且對方有硬功時失敗。
- 腿法寫距離與下盤,不寫成漫畫式的飛踢。
