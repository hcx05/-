# 易容與潛行

> 易容與潛行是**身份與路線**的武學:靠不被看見、不被認出、不被追上取勝。它是情報、潛入與追逃場面的主工具。型態:技藝型。傳承域:市井江湖(逍遙宮)、朝廷(黑衣衛)。

## 一、分類

| 子類 | 說明 | 現實對應 |
|---|---|---|
| 易容 | 改變面貌與聲音:妝飾、假鬚、墊肩、變聲、步態 | 民間易容、戲班化妝 |
| 潛行 | 屏息、輕步、利用陰影與聲響;夜行 | 夜行術 |
| 追蹤 | 看足跡、氣味、馬蹄、水跡;以犬鷹為輔 | 追蹤術 |
| 反追蹤 | 掩蓋蹤跡、設假線索、繞路 | 反偵察 |
| 情報網 | 驛站、茶肆、碼頭、醫館構成的消息網 | 江湖消息網 |

## 三、規則

- 易容靠細節而非面具:步態、口音、習慣若不對,就會露餡。熟人與識人者難以騙過。
- 潛行與易容不增加戰力,但可使**實際差距縮小**(靠不被對手發現)。
- 情報網的強度取決於**人**:網絡裡的人被捕或叛變,網就斷。

## 四、場面與寫法

- 潛入戲寫路線與時機,而不是寫「很厲害」。
- 易容露餡的瞬間,要比成功更有戲(一個小錯,被一個細心的人看穿)。
- 情報網寫成「誰認識誰」,不寫成萬能的搜索引擎。
