# 機關與鑄造

> 機關與鑄造是**匠作**的武學:靠器物取勝,而不是靠內力。它使故事裡有不依賴武功的解法,也讓兵器與陣地有來歷。型態:技藝型;奇遇器物型(補天四器、名兵)。傳承域:匠作與行會。思想源流:墨家(見 [思想源流](../總綱/思想源流.md))。

## 一、分類

| 子類 | 說明 | 現實對應 |
|---|---|---|
| 機關鎖與暗室 | 銅鎖、複雜暗鎖、暗門 | 古代機關鎖 |
| 陷阱與守衛機關 | 翻板、落石、毒針機簧 | 墓葬與倉庫防盜機關 |
| 守城器械 | 床弩、拋石機、滾木礌石、雲梯、撞車 | 古代攻守城器械 |
| 鑄造與鍛造 | 百煉鋼、淬火、鑄劍 | 古法鍛鋼 |
| 名兵與器物 | 名劍、名刀、有來歷的兵器 | 傳世名兵 |
| 工程與水利 | 橋、渠、水閘、木筏 | 古代土木水利 |

## 三、規則

- 機關是**事先布置**的,屬「陣法、地利、準備」類加成(最多 +2 L,見 [戰力基準](../總綱/戰力基準.md)),一次性,被識破後失效。
- 名兵給的是**+1 L**的契合加成(需契合),並不是越貴越強。
- 補天四器的鑄造年代遠在天裂之後,不屬於一般鑄造體系。

## 四、場面與寫法

- 機關戲是解謎:讓讀者看懂規律,再讓人物先一步看懂。
- 鑄造戲寫火候與等待,不寫成瞬間完成。
- 一件名兵的故事,比它的威力重要。
