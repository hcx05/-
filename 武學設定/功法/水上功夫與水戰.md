# 水上功夫與水戰

> 南方的江河湖海是另一個戰場:站不穩就輸,看不懂水就死。水上功夫與水戰使故事能出現**船、碼頭、水寨、渡江**這些場面。型態:套路型、技藝型。傳承域:市井江湖(漕幫與鏢局)、匠作、釣鰲島。

## 一、分類

| 子類 | 說明 | 現實對應 |
|---|---|---|
| 水性與潛水 | 閉氣、潛行、泅渡 | 漁民與水手技能 |
| 水上樁 | 在船上、浮木上站穩與發力 | 水上功夫(漕運拳師) |
| 船戰 | 接舷、撞、火攻、弓弩 | 古代水戰 |
| 水寨與水域地利 | 迷霧、暗礁、水道 | 水寨與湖寇 |
| 水文與氣象 | 判斷水位、潮汐、風向 | 漕運與航海 |

## 三、規則

- 水上對輕功與地面功夫有折減;**熟水性者有地利**(約 +1 L 等同陣法地利,一次性)。
- 水戰重點是**船與位置**,不是個人武力。
- 渡江是大規模行動,與 [軍陣與兵法](軍陣與兵法.md) 的水師互相配合。

## 四、場面與寫法

- 寫霧、浪、搖晃。不要寫成平地戰換了背景。
- 暈船(胡不歸)這類小事要保留,它讓場面有人味。
