# 禪定與心法

> 禪定與心法修的是**神與心**,不是氣。它決定一個人在壓力下穩不穩、會不會被心魔牽著走。它是男主個人線的核心(守心訣、戾氣、禪定),也是佛門護持的根基。型態:階梯型。與 [內功心法](內功心法.md) 的差別:內功修氣,禪定修神;與 [靈能](../靈能/佛門神通.md) 的差別:禪定是方法,神通是副產品。

## 一、分類

| 子類 | 說明 | 現實對應 |
|---|---|---|
| 守心 | 守念、守息、守志;軍中穩心法 | 站樁、呼吸法 |
| 禪定 | 四禪八定,以靜觀為本 | 佛教禪定 |
| 坐忘與心齋 | 道家虛靜之法 | 莊子「坐忘」「心齋」 |
| 觀想 | 以意象穩定心神、導引氣機 | 道家存想、佛教觀想 |
| 心魔與破除 | 辨認並化解執念、恐懼、殺意 | 禪宗與道家修心 |

## 三、規則

- 心魔、戾氣、執念造成的負面為 −1 至 −2 L,疊加但最多 −4 L(見 [戰力基準](../總綱/戰力基準.md))。
- 禪定可加速內傷癒合、穩定心神(見 [佛門神通](../靈能/佛門神通.md)),但**不能代替**強力的外部壓制。
- 戾氣來自斷天劍與破軍星命,屬於命格層面,禪定能壓,不能根除。
- 守心訣是軍中版;禪定是佛門版;二者目標相近,路徑不同。

## 四、場面與寫法

- 寫禪定:靜止的外表,內部的拉扯。
- 瓶頸多在心,不在力;男主 P1-088 的停滯就是心不安。
