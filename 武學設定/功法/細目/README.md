# 功法細目

> 20 類功法(見 [功法總錄](../README.md))原本只有分類表與總錄,這裡逐類展開到與 [門派武學細目](../../招式/門派武學/README.md) 同等的細度:每項技法寫**姿勢、發力、內力引導、由來**,再加上**限制與破法**與**狀態**。本資料夾是**跨派的類別編**:各派獨有的招式仍以門派武學細目為正本,這裡只連結,不重抄。
> 靈能與音律的細目在 [靈能細目](../../靈能/細目/README.md)(含聲與鐘)。

## 二、約定

| 欄位 | 寫什麼 |
|---|---|
| 姿勢 | 身體與肢體怎麼擺;寫成「別人看得見的」動作 |
| 發力 | 力從哪裡出、怎麼傳;沒有力的技法寫「無」 |
| 內力引導 | 內力走哪裡、用多少;不靠內力者寫「不靠內力」 |
| 由來 | 分兩種:**現實**(取自真實的典籍、史傳、民俗、工藝)與**本世界**(自設,標「設定」) |
| 限制與破法 | 什麼條件下失效;誰、用什麼可以破 |
| 狀態 | 已出場(附事件 ID,與事件描述一致)/ 設定 / 待定 |

- 數字(丈、尺、枚、步)只是**寫作時的對照尺,不進正文**;正文寫的是「差一步」「夠不著」。
- 不新增戰力加成;輕功與暗器都不增加 L,只改變「誰能先到、誰能先手」。
- 現實典故憑記憶寫成,標「相傳」者為傳說或後世附會,不當史實。
