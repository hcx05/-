# 暗器與遠程細目

> 語感:袖、風、一寸之距、看不見從哪裡來。分類與總錄見 [暗器與遠程](../暗器與遠程.md);約定見 [功法細目 README](README.md)。針的醫用部分以 [青城派細目](../../招式/門派武學/青城派.md)、[棲霞閣細目](../../招式/門派武學/棲霞閣.md) 為正本,飛刀與柳葉鏢的使用以 [逍遙宮細目](../../招式/門派武學/逍遙宮.md) 為正本;本檔只做跨派的**器、手法與反制**。
> 現實根基:《史記·刺客列傳》高漸離以鉛灌築擊秦始皇;《史記·留侯世家》張良使力士擲鐵椎於博浪沙;《黃帝內經·靈樞》的九針;《吳越春秋》的彈歌;宋《武經總要》記載的鐵蒺藜、床子弩與神臂弓;西南與東南亞的吹箭;各代軍弩的齊射。
> 本檔的總原則:**暗器是弱者的先手,不是強者的武器**。標誌是「像一滴水落在燙的鍋裡:不大,但所有人都轉頭」。

## 二、暗器的規則

### 暗算與準備

- 暗器的威力來自**距離、時機與出其不意**,不是內力。依 [戰力基準](../../總綱/戰力基準.md) 第五節,**暗算與設局可使實際差距視為縮小 1 至 3 級**,但須準備與代價,且對手警覺後失效。
- 暗器**不加 L**,不進任何加成池。它改變的是「誰先手」,不是「誰更強」。
- 對 L 差距 2 以上的高者,暗器多半被擋或避;要奏效,須配合設局、陣法或毒(毒見 [毒與蠱](../毒與蠱.md))。

### 暗算的成立與失效

| 成立條件 | 失效條件 |
|---|---|
| 對方未察覺 | 對方已警覺或已見識過這一手 |
| 距離近、角度偏 | 對方正對、距離遠 |
| 對方正分心(說話、運功、救人) | 對方護體或披甲 |
| 配合設局(燈滅、人群、聲響) | 對方感知強(化真以上常能聽風辨器) |
| 淬毒 | 對方有解或不怕毒 |

### 準頭與距離(寫作對照尺)

> 一丈約三公尺。只是量級。

| 距離 | 針、鏢、飛刀 | 袖箭、手弩 | 弓弩 |
|---|---|---|---|
| 一丈內 | 精準,可打穴 | 精準 | — |
| 三丈內 | 需功夫,可傷人 | 精準 | — |
| 五丈 | 勉強,多半被避 | 可傷人 | 精準 |
| 十丈以上 | — | — | 可傷人,齊射更準 |

- **針與鏢到了五丈就近乎失效**;若要遠,就換弩弓。
- **疾走時投射準頭降一級**:輕功戲裡的暗器多半是「邊跑邊回頭一撒」,不是準頭。

### 攜帶量與補給

- **針囊**:幾十枚,可多次使用。
- **錢鏢**:十餘枚,銅錢隨手可得。
- **飛刀**:三五把,貴重,多半要回收。
- **袖箭**:一筒六支,射完即空。
- **手弩**:一匣數支,上弦需數息。
- **彈藥有限**:暗器戲裡「射完了」是常態,不許寫成漫天花雨。

## 三、手法

> 同一枚暗器,手法不同,用途就不同。下面七種是跨派共通的。

### 彈〔設定〕

- 姿勢:拇指扣住食指或中指,針或錢夾在指間,手腕微翻。
- 發力:指彈,不靠臂。
- 內力引導:內力從腕到指尖,一瞬送出。
- 由來:現實:銅錢與細針的指彈。本世界:最隱蔽的發射法,動作小。
- 限制與破法:距離短;威力低;只能打近距離的穴位或眼睛。
- 狀態:設定。

### 甩〔設定〕

- 姿勢:手臂自肩後甩出,手腕在出手一瞬翻轉。
- 發力:腕與前臂的鞭打。
- 內力引導:內力走臂至腕,瞬間放。
- 由來:現實:飛鏢與飛刀的投擲。本世界:飛刀與柳葉鏢的標準手法。
- 限制與破法:動作比彈大,對手看得見肩動;刀鏢旋轉,有破空聲。
- 狀態:設定。

### 擲〔設定〕

- 姿勢:跨步前衝,整條手臂過頂擲出。
- 發力:由腿起,經腰、肩、臂。
- 內力引導:內力走全身,出手時集於臂。
- 由來:現實:《史記·留侯世家》記張良使力士擲鐵椎擊秦始皇車駕;擲重物是投擲的原型。本世界:飛蝗石與重器的手法。
- 限制與破法:動作大;只能一擊;失手則暴露。
- 狀態:設定。

### 揚〔設定〕

- 姿勢:手掌兜住粉末或細沙,朝對方面部揚出。
- 發力:前臂一揮。
- 內力引導:無。
- 由來:現實:石灰迷眼粉,古今皆有的下三濫。
- 限制與破法:逆風則反噬;閉眼、掩袖可擋;持盾者免疫。
- 狀態:設定。

### 夾〔設定〕

- 姿勢:兩指夾針,針尖朝外,貼在袖口或掌心。
- 發力:以夾為基,配合彈或甩。
- 內力引導:內力至指尖,針不顫。
- 由來:現實:針灸的捻針手法延伸。本世界:青城與棲霞閣針法的武用形態。
- 限制與破法:女主的針法多用於救人,不當兵器(DEC-071),所以**女主的針在正文裡是醫具與信物,不是暗器**;P1-005 斷索、P1-081 留記號,都是針的「用」,不是「傷」。
- 狀態:設定。

### 吹〔設定〕

- 姿勢:竹管或銅管含於口,朝目標吹出細箭。
- 發力:肺與舌的爆發。
- 內力引導:內力至喉,不求遠。
- 由來:現實:西南與東南亞的吹箭,常配毒藥。本世界:萬毒谷的暗器。
- 限制與破法:射程短,威力靠毒;風大無效;對方有解則空。
- 狀態:設定。

### 發機〔設定〕

- 姿勢:袖中或腕上裝機簧,以手腕特定角度觸發。
- 發力:機簧,不靠腕力。
- 內力引導:不靠內力。
- 由來:現實:袖箭與手弩的機簧原理。本世界:黑衣衛與逍遙宮的裝備。
- 限制與破法:機簧需保養;濕、塵會卡;發射時有輕響;射完需重新裝填。
- 狀態:設定。

## 四、器(逐項)

### 針〔設定;針的醫用已出場〕

- **形制**:毫針細如髮,長針長數寸,九針各異(《靈樞·九針十二原》載九種針具:鑱針、圓針、鍉針、鋒針、鈹針、圓利針、毫針、長針、大針)。
- **持法**:夾於兩指,針囊貼身。
- **用法**:發針(彈或夾)取穴位、關節、眼睛;斷索(P1-005 吊橋);留記號(P1-081);封脈、探機關。
- **限制**:針細,穿透力小,不可破甲;**針不用於殺人**,在青城與棲霞閣是戒條。
- **破法**:衣厚、甲重、護體;對方看得見肩動。
- **由來**:現實:針灸針。本世界:青城、棲霞閣的醫武兩用。
- **狀態**:醫用已出場(P1-005、P1-081、P3-099 等);作為暗器的用法為設定。

### 柳葉鏢〔設定〕

- **形制**:薄而輕,長三寸左右,形如柳葉,可藏袖。
- **持法**:夾於食指與中指。
- **用法**:近距離快射,逼退或釘住衣角。
- **破法**:兵器格擋;袖拂。
- **由來**:現實:柳葉鏢。本世界:逍遙宮暗器。
- **狀態**:設定。

### 飛刀〔設定〕

- **形制**:長五六寸,重心在刀身中段;單刃或雙刃。
- **持法**:捏刃或握柄;出手時旋轉或不轉。
- **用法**:近距離快,三丈內可傷人;逍遙宮的飛刀是寸刃術的延伸。
- **破法**:格擋;側身;袖拂。
- **由來**:現實:飛刀。本世界:逍遙宮技藝。
- **狀態**:設定。

### 錢鏢〔設定〕

- **形制**:銅錢或削邊的銅錢,一面磨薄。
- **持法**:拇指與食指夾住,彈出。
- **用法**:碼頭、酒肆最常見;**不致命,重在引注意、打斷、逼退**。
- **破法**:袖拂;兵器格擋。
- **由來**:現實:錢鏢,江湖鏢局的傳統暗器。本世界:漕幫與鏢局。
- **狀態**:設定。

### 飛蝗石〔設定〕

- **形制**:拇指大小的石子,取材容易。
- **持法**:握在掌心,朝目標擲出。
- **用法**:中距離打穴、打手腕、打燈。
- **破法**:兵器格擋;低頭;遮蔽。
- **由來**:現實:飛蝗石。本世界:逍遙宮與江湖散人。
- **狀態**:設定。

### 彈弓鐵丸〔設定〕

- **形制**:木叉加皮筋,鐵丸如拇指頭大。
- **持法**:一手持弓,一手拉皮筋。
- **用法**:中距離,低調;江湖少年常用。
- **破法**:盾;遮蔽。
- **由來**:現實:《吳越春秋》記「彈歌」——「斷竹,續竹,飛土,逐宍」,是彈弓的古老形象。本世界:民間暗器。
- **狀態**:設定。

### 鐵蒺藜與鐵菱〔設定〕

- **形制**:鐵蒺藜四刺,無論怎麼落地都有一刺朝上;鐵菱較重,水上也不易漂。
- **持法**:撒。
- **用法**:撒在路上、門口、船舷,阻追兵;守撤退之用。
- **破法**:穿厚底靴;先掃;輕功可躍過。
- **由來**:現實:宋《武經總要》記載鐵蒺藜,用以阻騎兵。本世界:漕幫與鏢局、靖邊軍。
- **狀態**:設定。

### 石灰迷眼粉〔設定〕

- **形制**:小紙包或皮囊。
- **持法**:握在掌心。
- **用法**:近距離揚出,逼對手閉眼。
- **破法**:逆風;閉眼;戴面罩。
- **由來**:現實:石灰粉,古今皆有的下三濫。
- **提醒**:**下三濫但有效**,難防;正派不屑用,江湖散人與逃命者常用。
- **狀態**:設定。

### 袖箭〔設定〕

- **形制**:竹或鐵筒,內藏短箭,裝機簧,縛於腕上。
- **持法**:袖內,手腕上扳機。
- **用法**:近距離快射;射出不易察覺。
- **破法**:射完空筒;機簧受潮;對方披甲。
- **由來**:現實:袖箭。本世界:黑衣衛與逍遙宮。
- **狀態**:設定。

### 手弩〔設定〕

- **形制**:短弩,可單手持,弦力靠機簧。
- **持法**:單手端平,另一手上弦。
- **用法**:短距強力,黑衣衛裝備,可連發。
- **破法**:上弦需數息;對方披甲;盾。
- **由來**:現實:手弩與臂張弩。本世界:黑衣衛。
- **狀態**:設定。

### 吹箭〔設定〕

- **形制**:竹管長尺餘,內藏細箭。
- **持法**:含管,吹出。
- **用法**:近距離,配毒;萬毒谷常用。
- **破法**:風大;對方有解;箭細不穿厚衣。
- **由來**:現實:苗疆與東南亞的吹箭。本世界:萬毒谷。
- **狀態**:設定。

### 絆索與撒網〔設定〕

- **形制**:細繩、麻索、漁網。
- **持法**:預先布置或撒出。
- **用法**:追捕、阻騎;黑衣衛與鏢局常用。
- **破法**:看見即斷;輕功躍過。
- **由來**:現實:絆馬索與撒網。
- **狀態**:設定。

### 火箭與火油〔已出場〕

- **形制**:箭頭綁油布,點燃後射出;火油罐朝目標擲出。
- **用法**:縱火焚船、焚糧、焚門。
- **已出場**:P1-033 太湖水寨縱火燒鹽船;P2-079 血月教突襲大雲寺,山門被火箭點燃。
- **破法**:水、沙、濕布;快速撲滅。
- **由來**:現實:火箭,古代攻守皆用。
- **狀態**:已出場。

## 五、弓弩

> 弓弩不是暗器,是軍中遠程。與 [軍陣與兵法](../軍陣與兵法.md)、[騎術與馬上功夫](../騎術與馬上功夫.md) 交界。

### 長弓與硬弓〔設定〕

- **姿勢**:雙足分立,左肩對目標,左臂伸直,右手拉弦至頰。
- **發力**:以背與肩拉,不靠臂。
- **內力引導**:內力集於雙肩與背,放弦時瞬間送。
- **由來**:現實:唐代軍弓,以拉力論高下(古代以「石」「斗」計弓力)。本世界:靖邊軍的基礎。
- **限制與破法**:拉弓時暴露;連射會力竭;有盾與甲則弱。
- **狀態**:設定。

### 騎射短弓〔設定〕

- **姿勢**:雙腿夾馬,上身轉向,左手持弓,右手搭箭。
- **發力**:由腰扭轉帶動臂。
- **內力引導**:內力集於腰與背。
- **由來**:現實:草原騎射。本世界:靖邊軍與玄朔;詳見 [騎術與馬上功夫](../騎術與馬上功夫.md)。
- **限制與破法**:馬不穩則失準;密集的盾陣可擋。
- **狀態**:設定。

### 軍弩與連弩〔設定〕

- **姿勢**:架弩於肩或地,瞄準,扳機。
- **發力**:機簧,不靠人力。
- **內力引導**:不靠內力。
- **由來**:現實:戰國秦弩、漢蹶張弩、宋神臂弓,軍弩是古代最重要的遠程兵器,齊射威力巨大。本世界:靖邊軍的遠程。
- **限制與破法**:上弦慢;雨濕則弦鬆;近身即廢。
- **規則**:**軍弩是例外**:齊射的集體火力可以威脅 L16 左右的單人,但不及通玄以上(見 [暗器與遠程](../暗器與遠程.md) 第三節)。
- **狀態**:設定。雁回關之戰(P2-025 至 P2-033)可用。

### 守城遠程(只列接點)

床弩、拋石機、滾木礌石歸 [機關與鑄造](../機關與鑄造.md)。宋《武經總要》記載的床子弩是守城重器,本世界不逐項展開。

## 六、反制

| 被克者 | 克制者 | 理由 |
|---|---|---|
| 一切暗器 | 警覺與見識 | 對手知道後不再中計 |
| 針、錢鏢 | 袖拂、兵器格擋 | 力小,易被撥開 |
| 針、鏢、飛刀 | 護體橫練、披甲 | 穿透力不足 |
| 飛刀、飛蝗 | 側身、低頭 | 軌跡直 |
| 錢鏢、飛刀 | 聽風辨器 | 破空聲 |
| 暗器 | 以暗器打暗器 | 高階技巧:以針打針、以錢擊錢 |
| 暗器 | 近身 | 暗器怕近,近身後就是肉搏 |
| 吹箭、淬毒暗器 | 醫者與解藥 | 毒可解 |
| 彈弓、飛蝗 | 盾 | 小物不穿 |
| 軍弩 | 盾陣、雨濕、近身 | 見軍陣與兵法 |
| 袖箭、手弩 | 射完後空 | 彈藥有限 |
| 一切 | 暗處、人群 | 找不到對手 |

### 接暗器〔設定〕

- 姿勢:袖或帕在手,迎向暗器,旋轉卸力。
- 發力:卸力,不硬接。
- 內力引導:內力至腕。
- 由來:現實:武術的接暗器技。
- 限制:需高度專注;多枚齊來則漏。
- 狀態:設定。

## 八、寫作提醒

1. **寫「看不見它從哪裡來」的那一瞬**,不逐個列名稱。
2. **一枚暗器是信號。** 常比傷害更重要:引注意、斷索、熄燈、釘住衣角。
3. **暗器戲寫準備,不寫漫天花雨。** 暗算要有鋪墊;射完了就是射完了。
4. **女主的針不是暗器。** 她的針是醫具與信物,斷索與記號是針的「用」。
5. **三不寫:** 不寫暗器追蹤、不寫暗器穿金石、不寫千枚齊發。
6. **毒是故事,不是功夫。** 淬毒的重點是中毒後的人,見 [毒與蠱](../毒與蠱.md)。
7. **軍弩是集體火力,不要寫成一人之力。**
