# 輕功身法細目

> 語感:瓦、牆、風、一步之差。分類與總錄見 [輕功身法](../輕功身法.md);約定見 [功法細目 README](README.md)。各派獨有的身法卡(逍遙步、踏雲步、踏星步、月影步等)仍以 [門派武學細目](../../招式/門派武學/README.md) 為正本,本檔只連結。
> 現實根基:唐傳奇中的聶隱娘、崑崙奴與紅線(裴鉶《傳奇》、袁郊《甘澤謠》,文學,非史實);《水滸傳》戴宗的神行法;《墨子·公輸》與《備城門》的雲梯;百戲中的走索與緣竿;後世武術的樁功、縱躍與走缸訓練;達摩一葦渡江的傳說;北方諸族在雪上踏板而行的生活技藝。
> 本檔的總原則:**輕功不是飛,是路線與時機**。標誌是「像貓走過屋脊:你看不見牠怎麼走,只知道牠沒有踩錯一片瓦」。

## 二、輕功的規則

### 輕功不增加 L

- 輕功**不是加成**,不進戰力基準的任何池子(神器 +1、陣法 +2、合擊 +2、靈能 +1)。它的價值是**誰先到、誰先走、誰能繞到背後**,不是誰更強。
- 輕功卓絕的人,正面對高階仍然輸。逍遙宮「不爭,避其鋒」,就是承認這一點。
- 輕功不靠靈氣、不耗神(耗的是體力與內力),所以補天之後照舊;但修為散盡的人(P3-143 之後的男女主)輕功也跟著沒有,只剩凡人的腳力。

### 境界梯度(寫作對照尺)

> 一丈約三公尺。數字只是量級,**真正的極限在借力、地形與落點**,不是數字。

| 境界 | 縱(水平) | 躍(向上) | 落(安全下落) | 久(持續奔行) | 一句話 |
|---|---|---|---|---|---|
| 煉形 | 半丈 | 三尺 | 一丈 | 一二里 | 腳程快、膽子大,翻牆還得手腳並用 |
| 通脈 | 一丈 | 五尺(上矮牆) | 兩丈 | 三五里 | 翻過一般院牆、掠過窄巷,落地有聲 |
| 開府 | 兩丈 | 一丈(借牆再上) | 三丈 | 十里 | 屋頂上連跑數十丈,落地輕 |
| 凝神 | 三丈 | 一丈半(借力一次) | 五丈 | 數十里 | 能借一根竹、一片瓦,水上借浮物數步 |
| 化真 | 四丈 | 兩丈(借力) | 五丈 | 數十里,可連日 | 路線與落點算得準,省力 |
| 通玄 | 同化真 | 同化真 | 同化真 | 同化真 | **數字不再增加,增加的是無聲、省力與穩** |

- **輕功沒有「凌空」**:空中不能轉向(除非借物),落點必須落在實處。誰寫「一躍數十丈」就是把輕功寫成飛。
- **一次借力,多次接續**:通玄與化真的人也只是把「借力」用得更巧,例如借一根蘆葦、一道簷角,**不是不借**。
- **負重折半**:背一個成人,等於降一個境界。這是追逃戲裡「揹傷者」要付的代價。
- **耗用**:輕功耗的是體力與引到足底的內力;連用則先累後亂,不耗神。

### 環境修正

| 環境 | 修正 | 說明 |
|---|---|---|
| 瓦頂 | 落地有聲 | 瓦片鬆動即暴露;濕瓦則滑 |
| 雨與濕牆 | 縱躍距離減,失足機率增 | 輕功各型都怕;林中型(藤蛇步)與水上型例外 |
| 夜 | 夜行型加強;其餘視燈火 | 無月之夜,星位型與拜月教皆減效 |
| 雪 | 留痕;履雪型不留 | 雪地追蹤很容易,所以履雪是一門專長 |
| 沙 | 下陷、減速 | 沙行型減少下陷 |
| 林 | 枝葉遮視線,不宜縱遠 | 藤蛇步例外 |
| 水 | 無借物則沉 | 水上型靠船與浮物,**不存在「水上漂」** |
| 風 | 逆風減 | 側風影響落點 |
| 霧 | 看不見落點,縱躍必減 | 需熟悉地形 |

## 三、通用身法

> 各派身法的底層動作大同小異,下面七項是跨派共通的。

### 縱〔設定〕

- 姿勢:屈膝半蹲,身微前傾,雙臂自然後擺。
- 發力:足掌蹬地,膝與髖同時伸直,由後向前送。
- 內力引導:內力提至足底湧泉,蹬出時瞬間送出,落地前收回。
- 由來:現實:跑跳訓練與武術的縱躍功。本世界:輕功的起手式。
- 限制與破法:起縱一瞬有「蹲」的預兆,資深追兵看得出方向;縱時雙足離地,中途無法變向。
- 狀態:設定。

### 躍〔設定〕

- 姿勢:面牆,兩步助跑,雙足蹬牆,上身後仰再前傾。
- 發力:蹬牆借反力,單腳先蹬再換腳補一次。
- 內力引導:內力從湧泉送至腿根,蹬第二次時略停。
- 由來:現實:輕身躍牆的訓練。本世界:翻牆與上屋頂的基本動作。
- 限制與破法:牆面光滑、濕滑、有倒刺都不能借;高牆上有人守時,上到頂的一瞬最危險。
- 狀態:設定。

### 落〔設定〕

- 姿勢:自高處落下,雙膝微屈,前腳掌先著地,隨即屈膝、彎腰、翻滾半圈。
- 發力:著地的衝擊由腿、腰、背三處分散。
- 內力引導:內力在腳著地前聚於腿,著地後散開。
- 由來:現實:跳傘與武術的滾翻卸力。本世界:落地無聲是通玄的記號。
- 限制與破法:落在硬石、鬆瓦、水面上都不能卸力;落點被人堵住,等於送上門。
- 狀態:設定。

### 攀〔設定〕

- 姿勢:手指扣牆縫、石縫,雙足踩牆縫,身貼牆,慢慢上移。
- 發力:不靠臂力,靠手足分擔體重;四點三點交替。
- 內力引導:內力走指尖與腳尖,指尖一緊一松。
- 由來:現實:攀岩與城牆攀爬;古代的雲梯與飛梯、鉤索。本世界:攀的基本功;雲梯縱以它為底(第四節)。
- 限制與破法:光牆、濕牆、倒懸的雉堞無法攀;城上人只要有一桶滾水或一塊石,攀者即退。
- 狀態:設定。

### 借力〔設定〕

- 姿勢:縱出後,足尖輕點一個「不會動的點」(簷角、樹梢、牆頭、繩索、槍尖),身再拔高或轉向。
- 發力:借物的反作用力,力小,方向改變大。
- 內力引導:內力在足尖一點即收,不外放。
- 由來:現實:跑酷與武術的借力。本世界:輕功修到凝神以上的標誌——**能借**。
- 限制與破法:借物太細、太脆或太動,即斷;借的點若被拆掉,整套路線作廢。
- 狀態:設定。

### 走高〔設定〕

- 姿勢:在屋樑、繩索、竹竿、牆頭上直立行走,雙臂平伸,視線平視前方。
- 發力:足踝連續微調,重心壓在腳掌前緣。
- 內力引導:內力輕走足底,一步一松。
- 由來:現實:百戲中的走索與緣竿。本世界:潛入戲常用,例如屋樑、橋索與吊橋(P1-005 吊橋之戰的背景)。
- 限制與破法:風、雨、被驚擾都會失衡;細索上無法持物。
- 狀態:設定。

### 卸力與滾落〔設定〕

- 姿勢:從屋頂、馬上或梯上失足時,縮頸、抱頭、側身著地,滾一圈。
- 發力:不抗衝擊,順勢轉為滾動。
- 內力引導:護住頸與背,其餘放鬆。
- 由來:現實:柔道與武術的倒地技。本世界:所有輕功各派的入門第一課。
- 限制與破法:高處(超過安全下落)無法卸;落在尖物上無法卸。
- 狀態:設定。

## 四、本檔補充的身法(各派細目沒有卡的)

### 雲梯縱(靖邊軍)〔設定〕

- **由來**:
  - 現實:《墨子·公輸》記公輸般為楚造雲梯以攻宋;古代攻城用雲梯、飛梯與鉤索。
  - 本世界:靖邊軍的軍中速成攀越術,**專為城牆而設**:不優雅,耗力,但能在雲梯被推倒、鉤索被斬斷時,靠手腳在牆縫裡接著上。
- **內力引導(總)**:內力集於雙手雙足,以「抓」為本,不求輕。
- **弱點**:不是美的輕功,不宜追逃;耗力,攀完一堵牆即疲。

**接梯**〔設定〕
- 姿勢:兩人持梯,一人先上,上到一半用腳勾住梯格,騰出雙手。
- 發力:臂與腿分工,手護頭、腳取穩。
- 內力引導:內力在雙足與前臂交替。
- 由來:軍中攀城的標準動作。
- 狀態:設定。

**抓縫**〔設定〕
- 姿勢:梯斷後,整個人貼在牆上,手指摳牆縫,腳尖找磚縫,一格一格上。
- 發力:四指為鉤,拇指為輔,腳尖為支。
- 內力引導:內力走指尖,每一格一緊一松。
- 由來:守兵砍斷梯子時的救急。
- 狀態:設定。

**翻垛**〔設定〕
- 姿勢:上到垛口,一手扣垛,一手持刃,身子翻過垛口落進城內。
- 發力:臂撐腰翻,落地時屈膝卸力。
- 內力引導:內力從肩至腰,翻過垛口即收。
- 由來:現實:攻城登垛。
- 限制:翻垛一瞬暴露;守兵在垛後以刀迎。
- 狀態:設定。雁回關血戰(P2-025 至 P2-033)寫守城時可用:守軍熟悉這套,所以知道怎麼擋。

### 履雪(問天宗)〔設定〕

- **由來**:
  - 現實:北方與西伯利亞諸族在雪上踏板而行,是古老的生活技藝;雪地行走分「走在雪上」與「走在雪裡」兩種。
  - 本世界:問天宗在昆侖雪線上行走的身法,**不留深痕**,以免被追蹤或驚動雪崩。
- **內力引導(總)**:內力輕走足底,分散體重,不是「變輕」。
- **弱點**:離開雪地則平庸;雪鬆軟時仍會陷。

**分重**〔設定〕
- 姿勢:足掌放平,步幅小,膝微屈,重心在兩足間均分。
- 發力:不蹬,輕壓。
- 內力引導:內力勻布整個足底。
- 由來:現實:雪板與雪鞋的分重原理。
- 狀態:設定。

**踩舊跡**〔設定〕
- 姿勢:盡量踩前人的腳印,或踩已壓實的雪面。
- 發力:無。
- 內力引導:無。
- 由來:現實:雪地追蹤與反追蹤。
- 限制:追蹤者看得出「同一串腳印被踩過兩次」。
- 狀態:設定。昆侖雪線(第三部第 36 至 38 章)可寫。

### 沙行(拜月教、玄朔)〔設定〕

- **由來**:
  - 現實:沙漠行路要「走脊不走谷」「走硬不走軟」,駱駝與嚮導比人更懂沙。
  - 本世界:拜月教與玄朔各自的沙地步法:**減少下陷,節省力氣,在沙暴前找遮蔽**。
- **內力引導(總)**:內力輕走足底,但更重要的是**認路**——沙丘的走勢、風的方向。
- **弱點**:離開沙地則平庸;無水不能久。

**走脊**〔設定〕
- 姿勢:沿沙丘脊線走,步幅小,雙足交替。
- 發力:不蹬,輕踏。
- 內力引導:內力分布足底。
- 由來:沙漠行路的標準。
- 狀態:設定。

**避暴**〔設定〕
- 姿勢:見風沙將起,尋背風處的廢牆或岩壁,伏身蒙面。
- 發力:無。
- 內力引導:守息,不運功。
- 由來:沙暴時的生存法。
- 狀態:設定。P2-096 追兵與沙暴(第四天沙暴起,男主躲在廢牆後啃著最後一塊餅)可用。

## 五、追逃學:路線比速度重要

> 輕功戲的重點是**路線**:路線被看懂,就被追上。

| 要點 | 做法 | 破法 |
|---|---|---|
| 選路 | 走追兵過不去的路:窄巷、屋脊、排水道、水邊 | 追兵分兩路堵出口 |
| 留記號 | 沿途做只有同伴看得懂的記號(例:針記,P1-081 女主逃跑時沿途用針留記號,男主循針記追來) | 記號被追兵看出即成陷阱 |
| 引開 | 製造另一條假路線,讓追兵分兵(例:P3-082 柳煙易容成女主,跑過屋頂,把追兵引向城北) | 追兵不上當,或分兵不夠 |
| 借障 | 人潮、馬車、牲口、水渠 | 追兵有騎、有犬 |
| 時間 | 夜、霧、雨、人多的集日 | 追兵熟地形 |
| 示弱 | 假裝力竭,誘追兵進入死巷 | 追兵不貪 |

- **輕功對馬**:短距離巷弄,輕功占優;長距離開闊地,馬占優。
- **輕功對弓弩**:開闊處輕功必死,所以輕功戲要有遮蔽。
- **揹人**:折半(第二節);必須有一次「放下」的取捨,這是人物戲的點。
- **寫法**:先寫為什麼走這條路,再寫走得多快。

## 六、潛入學

> 潛入與 [易容與潛行](../易容與潛行.md) 相互補:易容管臉,輕功管路。

| 步驟 | 要點 |
|---|---|
| 觀察 | 守衛交接、更夫、犬、燈 |
| 進路 | 屋頂、後牆、排水道、井口 |
| 落腳 | 瓦要輕、梁要穩、地要乾 |
| 退路 | 先找出口,再進去 |
| 失誤 | 最常見的是瓦片鬆動、犬吠、燈亮、同伴失足 |

- 寫法:潛入戲寫**一個失誤**,不寫全程完美。完美的潛入沒有戲。
- 已出場:P1-014 夜探血月壇(男主潛入石室);P1-033 夜入水寨縱火;P1-079 女主躲進東宮舊址;P1-081 皇城追逃。

## 七、破輕功

| 被克者 | 克制者 | 理由 |
|---|---|---|
| 一切輕功 | 預判路線 | 路線被看懂 |
| 一切輕功 | 暗器、弓弩 | 空中與落點無法躲 |
| 一切輕功 | 堵路與設局 | 輕功需要空間 |
| 輕盈型 | 風大、雨濕 | 失足與縮短縱距 |
| 星位型 | 無星之夜 | 依賴天象 |
| 夜行型 | 白日 | 白日減效 |
| 林中型 | 平地 | 離開林地 |
| 水上型 | 離水 | 離水不顯 |
| 履雪、沙行 | 離開特定地形 | 平庸 |
| 潛伏型 | 燈、犬 | 低伏潛行怕光與嗅 |
| 輕功對高階 | 通玄以上 | 氣息被聽見、路線被看穿 |

## 十、寫作提醒

1. **路線比速度重要。** 先寫「為什麼走這條」,再寫「走得多快」。
2. **三不寫:** 不寫凌空飛行、不寫踏水而行無借物、不寫一躍數十丈。這些是演義寫法。
3. **落地是代價。** 瓦響、腿麻、氣喘、衣角被勾住,小失誤比大技更有真實感。
4. **輕功不單獨決勝。** 追逃戲的結局由地形與設局決定。
5. **每個人的輕功不同。** 柳煙的「繞」、月影步的「隱」、雲梯縱的「抓」,各有語感,不要寫成同一種。
6. **補天之後。** 修為散盡的男女主不再有輕功;扛不動水、爬不上高牆是寫實,不是退步。
