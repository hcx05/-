# 術數與推演

> 術數是**用資訊推測趨勢**的武學:星象、水文、地形、局勢。它不是預言。《封天九章·觀星章》說「星者,天之文也,非天之命也」,本世界據此規定:術數只能推測**可能**,不能預知**必然**。型態:技藝型。傳承域:宗門(問天宗)、朝廷(觀星監)。思想源流:陰陽家。

## 一、分類

| 子類 | 說明 | 現實對應 |
|---|---|---|
| 星象推演 | 觀星辨位、判斷天時與天痕異動 | 古代天文曆法(觀星監傳統) |
| 奇門遁甲推演 | 以時、方位推演局勢與陣法 | 奇門遁甲 |
| 卜筮 | 易經卜卦,輔助決策 | 周易 |
| 風水與地形 | 勘察地形、水脈、風向 | 堪輿、軍事地形學 |
| 氣象與水文 | 預測風雨、水位、潮汐 | 古代氣象、漕運水文 |
| 觀人 | 從步態、聲色、舉止判斷人 | 相術的實用部分 |

## 三、規則

- **不得預知必然**:術數給的是機率與範圍,人物仍須自己選擇。
- 天痕異動可被觀測,但**不知原因**(誤讀與人為都可能):這使雙星預言的「天意」說法可以被人造。
- 術數需要資訊與時間;沒有觀測條件就無法推演。

## 四、場面與寫法

- 寫推演:一行行排除,最後讓一個變數浮出來。
- 寫「算錯」:術數的失誤是戲劇資源,不要寫成全知。
