# 音律與聲功

> 音律與聲功用聲音影響**人的神與節奏**:指揮、安神、擾心。它不是「一聲嘯就震死人」,而是以真實的音樂與軍中號令為根,加上本世界的神(精氣神之神)。型態:技藝型、集體型。與 [靈能](../靈能/README.md) 不同:聲功消耗的是人的氣息與專注,影響範圍有限。

## 一、分類

| 子類 | 說明 | 現實對應 |
|---|---|---|
| 軍中鼓角 | 鼓、角、鉦、旗語;指揮進退、鼓舞士氣 | 唐代軍樂與號令 |
| 琴簫笛 | 以樂音安神、擾神、傳訊 | 古琴、簫、笛 |
| 梵唄與誦經 | 佛門唱誦,穩定心神 | 佛教梵唄、念誦 |
| 嘯與呼吸 | 長嘯、喝止;以呼吸與共鳴傳遠 | 道家長嘯、武術呼喊 |
| 鐘磬 | 大鐘、磬,以低頻共鳴 | 寺鐘、編鐘 |

## 三、規則

- 聲功只能造成**疲勞或心魔式的輕微負面**(−1 至 −2 L,見 [戰力基準](../總綱/戰力基準.md)),且須對方定力不足、距離近。
- 高階者(通玄以上)幾乎不受影響。
- 軍中鼓角是**集體功能**:它讓一支軍隊同步行動,是軍陣加成的來源之一。
- 樂音無法殺人,但可以**讓人亂**。

## 四、場面與寫法

- 軍陣戰寫鼓點:鼓點變,陣形變。讀者聽得出戰場節奏。
- 琴戲寫「聽的人怎麼了」,不寫「琴的威力」。
- 梵唄、鐘聲是慈悲的聲音,與血月教的鈍重相對。
