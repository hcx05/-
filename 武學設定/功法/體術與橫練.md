# 體術與橫練

> 體術是**身體本身**的武學:站樁、耐力、抗擊打、關節與筋骨。它是所有武學的底層,也是軍旅與底層武人最常見的路徑。型態:階梯型、套路型。與 [內功心法](內功心法.md) 的差別:內功修氣的運行,體術修肉身的承受。

## 一、分類

| 子類 | 說明 | 現實對應 |
|---|---|---|
| 站樁 | 靜立固根,練腿力與呼吸 | 形意與軍中站樁 |
| 橫練 | 練皮肉筋骨,抗擊打 | 鐵布衫、鐵砂掌 |
| 耐力與負重 | 長途行軍、負重、飢寒耐受 | 軍中訓練 |
| 柔術與關節 | 柔軟與縮身,脫縛 | 傳統柔術、雜技 |
| 恢復與調養 | 傷後休養、飲食 | 傷科調養 |

## 三、規則

- 橫練與硬功被**點穴、毒與陣法**所克。
- 體術提供穩定的承受力,本身沒有爆發加成。
- 恢復力屬個人天賦,與 [男主天賦](../../角色/男主/天賦/天賦.md) 一致。

## 四、場面與寫法

- 寫硬功是**承受**:聲音、反震、姿勢不動。
- 寫修煉是時間:一年一年的站樁,比一場戰鬥更能讓人看見這個人。
