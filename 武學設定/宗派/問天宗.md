# 問天宗(仙門)

- **現實根基**:道家內丹 + 星象推演(觀星監的傳統) + 上古殘卷(本世界獨有)。
- **理念**:表面守護仙凡之隔,實則壟斷上古遺訣。
- **戰力地位**:宗主懷虛子通玄巔;借天痕可與佛門頂端**齊平**,不能超越。
- **核心功法**
  - 《觀星引氣訣》:引星辰之力入體,輔以周天運行。
  - 《紫微觀星訣》:不重攻擊,重觀照與推演。
  - 《踏星步》:源自道家步罡踏斗,結合星象位置移動。
  - 守天人遺訣(宗主獨有):能直接與天痕共鳴。
- **特色**:陣法、星象、推演;弟子擅長輔助與控場。
- **克制與弱點**:對慣於近身硬碰硬的敵人不佔優勢;依賴天象與準備。
- **代表人物**:懷虛子、其弟子(含女主的啟蒙)。

## 戰鬥風格
- **標誌**:像一張星圖:出手前先站位,夜間與開闊處最強;弟子擅長輔助與控場。
- **典型場面形制**:破陣與判讀。女主以星象與陣紋判讀小天痕(P1-061)。
- **寫作提醒**:依賴天象與準備,白日、陰雨、近身硬碰時不佔優。
- 八軸比較見 [流派對照](../總綱/流派對照.md);招式拆解見 [套路錄](../招式/套路錄.md)。

## 第三部補記
- **宗主與國師**:懷虛子以國師之名入南昭朝堂,並以「雙星預言」與殘卷經營多年;祭天大典被揭穿後,聯合錢謙、林棲鶴反擊,強開天痕,於昆侖天痕前被虛反噬而亡。
- **星引**:楚歸舟所用,引星辰之氣成線穿刺;一擊殺柳煙,後在山門之戰被柳長風了結。
- **瓦解**:宗主與大師兄先後身亡,謝清和在山道讓路,問天宗瓦解;殘存弟子分為守舊派與改革派(見[大宸與南昭](../../世界設定/世界觀/大宸與南昭.md))。
