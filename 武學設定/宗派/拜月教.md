# 拜月教(西域)

- **現實根基**:西域彎刀術、摔跤、波斯與中亞的月相信仰。
- **理念**:月有盈虧、人有明暗;並非純邪,外界誤解甚深。
- **戰力地位**:教主通玄。
- **核心功法**
  - 《逆月訣》:逆行經脈的速成內功;短期暴漲,後患無窮(男主曾借用的「逆脈」之源)。
  - 《彎月刀》:刀法,弧線凌厲。
  - 《月影步》:夜間輕功。
  - 古城遺跡知識(星盤線索)。
- **特色**:夜戰、速成、跨文化技術。
- **克制與弱點**:怕持久戰與醫者;逆月訣內傷累積。
- **代表人物**:阿史那月。

## 戰鬥風格
- **標誌**:像夜裡的彎月:弧線出刀,夜間才發揮;速決而後患。
- **典型場面形制**:夜戰與代價。逆月訣速成,事後內傷。
- **寫作提醒**:怕持久與醫者;第一部未出手,留待第二部西域古城。
- 八軸比較見 [流派對照](../總綱/流派對照.md);招式拆解見 [套路錄](../招式/套路錄.md)。

## 第二部補記
- **逆脈教學**:阿史那月在月牙泉宮教男主逆脈:三個月可抵三年,代價是經脈受損、壽數與後患(第三部修為大損)。
- **身分與立場**:拜月教被正道視為邪派,卻在山門命案中與濟世盟聯署作證,洗清男主污名;阿史那月不要求回報。
