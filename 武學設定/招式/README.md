# 招式

本資料夾記錄**具體的招式與套路**,補足 `功法/`(依類型整理的功法總錄)與 `宗派/`(宗派源流)之間缺少的一層:**這個功法打起來是什麼樣子、在哪個事件用過**。

| 檔案 | 內容 | 性質 |
|---|---|---|
| [套路錄](套路錄.md) | 各流派的功法、套路、單招拆解,含設計標記 | 設計(正本) |
| [第一部招式錄](第一部招式錄.md) | 第一部各事件實際出現的招式、體系與場面形制 | 出場紀錄 |
| [第二部招式錄](第二部招式錄.md) | 第二部各事件實際出現的招式、體系與場面形制(軍陣守城、護人不攻、代價) | 出場紀錄 |
| [第三部招式錄](第三部招式錄.md) | 第三部各事件實際出現的招式、體系與場面形制(疏而不堵、水戰與虛火、放下) | 出場紀錄 |

## 與其他層的分工

| 內容 | 正本 | 說明 |
|---|---|---|
| 角色當前戰力 L、學了什麼 | 角色 `成長/武學/{卷}.md` | 招式錄不重複寫 L |
| 宗派理念、源流、代表人物 | `宗派/` | 招式錄只拆解招式 |
| 功法的類型與適用 | `功法/` | 招式錄補充套路與單招 |
| 八軸差異與場面形制 | `總綱/體系差異化設計.md`、`總綱/流派對照.md` | 招式的設計依據 |
| 事件發生了什麼 | 各卷 `事件描述.md` | 招式錄的事件 ID 必須對應 |

## 狀態標記

見 [體系差異化設計](../總綱/體系差異化設計.md) 第八節:**已出場**(已用於事件)、**設定**(已設計、未用)、**待定**(只有方向)。

## 使用規則

1. 套路錄的「已出場」必須在對應卷的招式錄有事件 ID;「設定」被事件採用時,改為已出場並補登。
2. 各卷招式錄中每一列的**事件 ID 與出場者**必須與凍結紀錄一致(`工具/檢查.py` 會檢查);要讓角色在別的事件出手,走變更傳播。
3. 新增招式前先做 [差異化檢核](../總綱/體系差異化設計.md) 第六節的六個問題。
4. 正文不出現 L 值與等級;招式名只在關鍵場面點名。
