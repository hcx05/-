# 重點武學

> 本資料夾收的是**故事裡承載主角、關鍵事件或宗派門面的功法**,寫到降龍十八掌那種程度:**每一招有名、有姿勢、有功用**,不是只有三五個單字。其餘功法仍在 [門派武學細目](../門派武學/README.md) 的層級,不逐招展開。
> 名稱與狀態摘要見 [套路錄](../套路錄.md);各宗派的源流、理念見 [宗派](../../宗派/README.md);典籍原文見 [典籍](../../典籍/README.md)。

## 一、為什麼另立一層

門派武學細目對每個宗派的每項功法都寫了姿勢、發力、內力引導,但**招名多半是一到兩個字**(點、掃、沖、劈……),招數多半是三到五式。這對「宗派總覽」夠用,對「故事裡的招牌武學」不夠:讀者記得住的是「亢龍有悔」,記不住「劈」。

所以重點武學另立一層,補三件事:

1. **招名**:每招一個三到五字的名字,有出處或意象。
2. **招數**:有套路之名的,招數要夠(破陣十二式有十二式,羅漢拳有十八手);**以少招著稱者**(靖邊槍「少而重複」、歸墟九劍只有九劍)保留核心數目,但每式再分「用」或「變」,讓每個名字底下仍有可寫的東西。
3. **功用與破法**:每招寫它**拿來做什麼**、**什麼情況下失效**,不只寫它長什麼樣。

## 二、標準

| 項目 | 要求 |
|---|---|
| 招名長度 | 一套之中**超過一半**的招名為三至五字;一至兩字的名稱降為「簡稱」(口令、鄉下名、已出場的舊稱),不刪 |
| 層級 | **組(式)名**可以是一兩個字(衝、裂、沖、劈、起潮、回瀾),底下的**招**才是正名;例:衝組 → 尖楔入縫 |
| 招數 | 有數字之名的照數(十二式、十八手、九劍);沒有的,依功法性質寫足,不灌水 |
| 欄位 | 姿勢、發力、內力引導、功用、破法與限制、由來、狀態。變式、用法可用表格,但**每一項都要有名字、姿勢與功用** |
| 由來 | 分**現實**(經典、民俗、史傳,只寫有把握的)與**本世界**(自設,標「設定」) |
| 狀態 | **已出場**(附事件 ID,與各卷招式錄一致)/ **設定** / **待定**,見 [體系差異化設計](../../總綱/體系差異化設計.md) 第八節 |

## 三、與舊名的關係(名稱不改)

套路錄與各卷招式錄已用的名稱**一字不動**,它們現在是**簡稱**:

| 舊稱 | 現在的身分 | 例 |
|---|---|---|
| 靖邊軍單字招名 | **口令**:戰場上伍長只喊一個字,操典上另有四字正名 | 「楔!」是口令,正名是〈尖楔入縫〉 |
| 靖邊槍點掃挑釘格 | 軍中口語;秦七教孩子時另給鄉下名 | 點豆子、掃雪、挑糞、釘樁子 |
| 羅漢拳六式沖劈掛栽貫托 | 式(組)名;每式三勁,合為十八手,每手有正名 | 沖.整勁 → 怒目金剛 |
| 歸墟九劍的劍名 | 劍(組)名,**已出場的斷濤不變**;每劍分潮頭、潮腰、潮尾三變,每變有正名 | 斷濤 → 濤頭過頂、劈浪斬桅、濤落無聲 |
| 連星劍定連折環合 | 劍理五訣,是所有劍式的語法 | 樞璇一線屬「連」 |

## 四、正文怎麼用

沿用體系差異化設計第九節:**一場戲只點名一到兩招,其餘寫後果與反應**。本資料夾是設計依據與作者查表,不是臺詞表。三個細節:

1. **口令與正名分場合**:軍旅場面喊口令(單字),傳授、典禮、史傳才念正名。
2. **「變」「用」是作者的目錄**:正文裡沈滄溟可以只說「斷濤」,不必每次說出三變之名;但他若要教,可以說出來。
3. **不寫成招式清單**:一套招式的美,在於讀者看到其中一招時,隱約知道背後還有一整套。
