## 二、招式卡的欄位

| 欄位 | 寫什麼 |
|---|---|
| 姿勢 | 起手與定式:雙足、身形、手臂、兵器的位置與朝向。內功寫坐立臥姿 |
| 發力 | 力從身體哪裡起、經哪裡傳、在哪裡出;集體型寫整隊的節拍。內功不外發者寫「不外發」,改寫效用 |
| 內力引導 | 內力的起處、經路、歸處,以及吸呼配合。**經絡與穴位用傳統名稱與位置**;引導路線是小說設定,不是醫療或練功指導 |
| 由來 | 取名的緣故與典故。分兩種:**現實**(取自真實的拳種、兵書、典籍、史傳)與**本世界**(本專案自設,標「設定」) |
| 狀態 | 已出場(附事件 ID,與各卷招式錄一致)/ 設定 / 待定,規則見 [體系差異化設計](../../總綱/體系差異化設計.md) 第八節 |

## 三、約定

1. **名稱不改**:套路錄與各卷招式錄已用的招名、功法名一字不動;本資料夾只在其下補細節。已出場的招式,細節不得與事件描述矛盾。
2. **新增的標「設定」**:本資料夾新增的招式與功法,被事件採用前不凍結;被採用時,先在對應卷的招式錄補登,再把套路錄改為已出場。
3. **命名**:單招一至兩字,套路不超過五字(見體系差異化設計第七節);現實已有的名稱(易筋十二勢、八段錦、六字訣等)沿用現實名,不受字數限制。
4. **內力**:一律稱「內力」;靈能的消耗稱「神」;不使用術語表「避免寫法」欄的詞。
5. **戰力 L 不在此重複**:各人的 L 看角色 `成長/武學/{卷}.md`,等級規則看 [戰力基準](../../總綱/戰力基準.md)。
6. **毒與蠱**:只寫效果、症狀、解法與場面,不寫配方、劑量與可供現實操作的製法。
7. **正文不逐招羅列**:一場戲只點名一到兩個單招(體系差異化設計第九節);本資料夾是設計依據,不是臺詞表。

## 五、六派共通的設計脈絡

| 脈絡 | 內容 |
|---|---|
| 同源 | 《封天九章》的〈守心章〉化為靖邊軍的守心訣,〈觀星章〉與問天宗的觀星同根,〈疏導章〉傳入青城的針法而成疏導針法;三條支流都回到守天人 |
| 對剋 | 大雲寺的護人(金鐘罩)怕血月教的陰毒與暗算;青城的醫與大雲寺的純陽、禪定剋血月教;靖邊軍的集體剋單點,怕個人越階與下毒 |
| 反照 | 靖邊軍的「為群」、大雲寺的「護人」、青城的「救人」是同一種價值的三個面向;血月教的「以人為薪」是它們的反面 |
| 末代 | 補天之後靈氣散入人間,問天宗瓦解、守天人名分終結;靖邊軍、大雲寺、青城仍在;血月教在第三部沒有正面收束,其去向未定(見各檔「第三部之後」) |
