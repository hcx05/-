# 血月教武學細目

> 語感:腥、赤、鈍。宗派概要見 [血月教](../../宗派/血月教.md);名稱與狀態摘要見 [套路錄](../套路錄.md);約定見 [門派武學 README](README.md)。
> 現實根基:取自民間邪教傳說的邪術、血祭儀式,與毒、蠱的結合。
> 本派的總原則:**以人為薪**。邪門的本質是「誘惑與後果的時間差」——得先得到,失在後面;它在敘事上不是「壞人的功夫」,而是代價的極端形態(見 [邪門](../../功法/邪門.md))。寫血月教**寫恐怖,不寫華麗**:慢、鈍、腥、不確定。
> 規則:邪門速成短時至多 +3 L,事後必有重傷或內傷;共通弱點是內傷累積,怕醫者、佛門、純陽內功與持久戰。
> 說明:此檔只寫效果、症狀、解法與場面,不寫儀式的具體做法,也不寫配方、劑量與可供現實操作的製法。標「備案」者來自設定備案(舊十二章稿,DEC-075),尚未入現行正文。

## 二、血祭大法

- **由來**:
  - 現實:民間邪教傳說中的血祭,以活物獻祭祈福、求力。
  - 本世界:血月教的根本。名「血月」取月全食時的紅月——**把月與血連在一起**。與拜月教**無傳承關係**:拜月教教主厭惡血月教盜用「月」名(見 [拜月教](../../../勢力/拜月教.md)),拜月教的月相修持有正統內功寒月心經,逆月訣只是它的速成捷徑;血月教只取其名,不承其法。
  - 儀式在血月壇:廢祠改成祭壇,壁上繪血月紋,地下石室關押被擄的孩童(P1-014)。
- **三祭**(次第,越往後代價越重):
  - **牲祭**:以牲畜為薪,力微,代價小。
  - **徒祭**:以教眾自願獻出的氣血為薪,力中,教眾因此被綁在教裡。
  - **人祭**:以被擄之人的氣血為薪,力大,**內傷累積最重,道德代價最重**。P1-014 一名孩子來遲一步已被獻祭,是這一階的唯一明寫。
- **內力引導(總)**:不循常規周天,而是**把他人的氣血化為己用,逆衝經脈**——屬逆行型而非靜養型。得力時內力暴漲,事後經脈受損。
- **弱點**:怕醫者(青城解毒與疏導)、怕佛門(金鐘罩的禪定與護持)、怕純陽內功(專克陰毒邪功)、怕持久戰(內傷累積)。

**燃**〔設定〕
- 姿勢:單膝跪地或立定,抹己血於眉心,低頭。
- 發力:短時暴漲,**屬邪門速成,至多 +3 L**。
- 內力引導:血氣反灌丹田,逆衝督脈,上湧至頭。
- 由來:燃——以己血為燃料。
- 代價:事後重傷與內傷;不燃盡不止。
- 提醒:這一招的恐怖在「他知道會倒下卻不停」。

**借**〔設定〕
- 姿勢:祭者立於壇前,受祭者跪於壇下,以祭紋相連。
- 發力:儀式一成,力即灌入祭者。
- 內力引導:受祭者的氣血經祭紋→祭者丹田,逆衝。
- 由來:借——借他人的命。
- 提醒:**人祭的核心,寫恐怖不寫過程**。

**噬**〔設定〕
- 姿勢:戰場上,邊殺邊補。
- 發力:隨殺隨補,群殺時力量疊加。
- 內力引導:殺傷之際,傷者氣血被吸入,補己內力。
- 由來:噬——吞噬。
- 弱點:內傷累積更快,持久戰會自潰。

## 三、血蠱

- **由來**:
  - 現實:民間蠱毒傳說。
  - 本世界:血月教以血飼蠱,**與萬毒谷蠱術的差別在「以人為薪」**——萬毒谷的蠱不全為邪,血月教的血祭必為邪。與血祭大法一體,是它的長期形態。
- **規則**:此處不寫製法。
- **內力引導(總)**:蠱居於經脈,以血氣為食。

**飼**〔設定〕
- 以血氣養蠱,日久蠱大。
- 由來:飼養。

**種**〔設定〕
- 把蠱種入他人體內,使其受控。
- 由來:種蠱。

**喚**〔設定〕
- 以特定的信號喚起蠱的反應。
- 由來:呼喚。

- **解法**:青城以針與藥對症;萬毒谷可拆(蠱術同源,見 [毒與蠱](../../功法/毒與蠱.md));純陽內功遇之折損。

## 四、赤鴆毒

- **由來**:
  - 現實:鴆是傳說中的毒鳥,傳說以其羽浸酒可殺人(《左傳》《國語》等先秦典籍已有鴆酒之說,多為傳說)。
  - 本世界:赤鴆的標誌,**以內力運毒入掌指**,毒功與內功合一,血月教重暴烈與恐懼(萬毒谷則重生態與持久)。
- **症狀**:舌下浮現淡青毒痕,銀針一試即知(P2-093)。
- **解法**:青城辨毒、針封經脈;高階內功可逼出部分;純陽內功折損其毒;火。
- **規則**:只寫效果與解法,不寫配方與劑量。
- **內力引導(總)**:毒不是附在掌上,而是**化入內力之中**,出掌時內力帶毒。

**浸**〔設定〕
- 姿勢:日常修煉,靜坐。
- 發力:無。
- 內力引導:長期使內力與毒性相融。
- 由來:浸——浸潤。
- 提醒:寫修煉的代價:毒功的使用者自己也受損。

**透**〔設定〕
- 姿勢:掌或指觸及目標。
- 發力:一觸即收。
- 內力引導:內力帶毒,透入皮肉。
- 由來:透——透入。
- 提醒:需近身機會。

**散**〔設定〕
- 姿勢:袖手一揮。
- 發力:毒隨內力散於空氣。
- 內力引導:內力外放,毒氣擴散。
- 由來:散——散布。
- 提醒:遇風則弱,遇水則散;這是防範最易之處。

## 五、迷香

- **由來**:現實:迷香、藥煙,古代江湖小說中常見的迷藥。本世界:血月壇以迷香守壇,厲三更以迷香為其標誌技藝之一(P1-014、P2-079)。
- **規則**:只寫用途與對策,不寫配方。
- **內力引導(總)**:不用內力,靠藥性與空間。
- **對策**:掩口鼻、通風、解迷(P1-014 女主解開)。

**守**〔已出場:P1-014〕
- 守壇:點燃於密閉石室,擾亂闖入者。
- 用處:血月壇的迷香由女主解開。

**引**〔設定〕
- 引人入局:在對手必經之處點燃,令其遲鈍。

**圍**〔已出場:P2-079〕
- 圍殺前使用,令對手動作遲緩。
- 用處:P2-079 血月教邪功與迷香,火箭點燃山門,**退得很快,像任務已完成**——寫「這是掩護」的違和感。

## 六、追殺技(備案)

- **由來**:舊十二章稿設定(DEC-075 備案):序卷中以暗紅斗篷人現身——呼吸聲如砂紙磨喉、行動無聲,額頭有新月形血紋;使一對月牙鉤、鎖鏈月牙刀片,並有懸梁吊底之術。在蜀道棧道與漢中一帶四處打聽「北來的十四五歲少年」,懸賞五十兩。追殺令的來源在序卷不交代(PRO-045 為背景事件)。
- **內力引導(總)**:內力極輕,行動無聲;呼吸聲是代價(砂紙磨喉)。

**鉤**〔備案〕
- 姿勢:雙手各持一枚月牙鉤,鉤尖向外。
- 發力:鎖兵、勾腕,不硬接。
- 內力引導:內力貼臂,輕而急。
- 由來:月牙鉤——月與鉤;語感:彎。

**鏈**〔備案〕
- 姿勢:單手持鎖鏈,鏈端繫月牙刀片。
- 發力:拋出、回拉,出其不意。
- 內力引導:內力沿鏈送出,收時回。
- 由來:鎖鏈月牙——軟兵,需空間。
- 弱點:空間狹窄時施展不開。

**懸**〔備案〕
- 姿勢:倒懸於梁下,四肢蜷縮,不動。
- 發力:一擊。
- 內力引導:屏息,內力潛伏。
- 由來:懸梁吊底——潛伏突襲。

| 階 | 說明 |

- **標誌**:血月紋;紅斗篷;砂紙般的呼吸聲(備案)。

## 八、第三部之後

血月教在第三部沒有正面收束。補天之後靈氣散入人間,修行不再被少數人壟斷——血祭大法的前提(以他人氣血為薪)不依賴靈氣,所以不會因補天而失效。**定案(設定,不入骨幹)**:曹無咎被押回公審(P3-148)後,血月教失去內侍監的庇護,教眾星散,血月壇荒廢,零星殘黨轉入暗處,不再成「教」;收拾殘局的是天下盟九席與各派自行清理的江湖事,不是朝廷的軍令。
