# 境界與戰力天花板

## 一、七境(與大綱一致)
煉形 → 通脈 → 開府 → 凝神 → 化真 → 通玄 → 問天

每境分四小階:**初、中、上、巔**。具體的戰力等級數值(L1–L28)、加成上限與對戰判定,統一見 [戰力基準](戰力基準.md)。

## 三、戰力天花板規則(硬性設定)

1. **佛門最高宗師為世界個人戰力的頂端**。其他任何人——包括最強的反派、主角、仙門宗主——**最多與之齊平,不可超越**。
2. 「戰力」包含借力:借天痕、借四器、借陣法等外力提升後的個人表現,同樣不得高於佛門頂端。
3. 佛門最高戰力的人物:
   - **無相老僧**:大雲寺隱世祖師,居達摩洞,極少現世,**L25(問天初階)**,是世界天花板本身。
   - **慧淨方丈**:無相之徒,**L24(通玄巔)**,與無相僅差「問天」的最後一線。
4. 其他人的最高上限:
   - **懷虛子**:L24(通玄巔);借天痕與守天人遺訣峰值至 L25,僅能與佛門頂端**齊平**,不能壓過。
   - **沈滄溟、玄鏡真人、阿史那月、苗阿婆**:L22–L23(通玄中至上)。
   - **男女主**:補天前峰值在 L20–L21(化真巔至通玄初);補天後修為盡散。
5. **慧淨之死的處理**(第二部):他並非在實力上被超越,而是被**暗算**——懷虛子與血月教以血祭邪術與毒設局,趁他以金鐘罩護住眾僧、自身無法反擊時得手。戰力天花板規則因此不被破壞。
6. 補天陣為眾人合力與四器之力,不計入個人戰力。

## 四、境界不等於絕對勝負
- 軍陣、毒、點穴、陣法、地利、人數可越階制衡一至兩階。
- 越階制衡有成本:準備、代價、一次性消耗。
- 但**不可越過佛門頂端的線**:即使是群戰與器物,也無法讓個體超越佛門頂端的境界。
