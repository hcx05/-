# 境界與戰力天花板

## 一、七境(與大綱一致)
煉形 → 通脈 → 開府 → 凝神 → 化真 → 通玄 → 問天

每境分四小階:**初、中、上、巔**。

## 二、各體系對照

| 通用境界 | 道門(內丹) | 佛門(果位) | 說明 |
|---|---|---|---|
| 煉形 | 築基 | 資糧位 | 筋骨與基礎 |
| 通脈 | 煉精化氣 | 加行位 | 氣脈貫通 |
| 開府 | 小周天成 | 預流果 | 丹田自成循環 |
| 凝神 | 大周天成 | 一來果 | 神識外放 |
| 化真 | 煉氣化神 | 不還果 | 真意成形 |
| 通玄 | 煉神還虛 | 阿羅漢果 | 與天地共鳴 |
| 問天 | 煉虛合道 | 菩薩位 | 傳說極境 |

## 三、戰力天花板規則(硬性設定)

1. **佛門最高宗師為世界個人戰力的頂端**。其他任何人——包括最強的反派、主角、仙門宗主——**最多與之齊平,不可超越**。
2. 「戰力」包含借力:借天痕、借四器、借陣法等外力提升後的個人表現,同樣不得高於佛門頂端。
3. 佛門最高戰力的人物:
   - **無相老僧**:大雲寺隱世祖師,居達摩洞,極少現世,**境界為通玄巔至問天初階**,是天花板本身。
   - **慧淨方丈**:無相之徒,**通玄巔**,與無相之差僅在「問天」的最後一線。
4. 其他人的最高上限:
   - **懷虛子**:通玄巔;借天痕與守天人遺訣至巔峰,僅能與佛門頂端**齊平**,不能壓過。
   - **沈滄溟、玄鏡真人、阿史那月、苗阿婆**:通玄上階至中階。
   - **男女主**:補天前最高在化真巔至通玄初階;補天後修為盡散。
5. **慧淨之死的處理**(第二部):他並非在實力上被超越,而是被**暗算**——懷虛子與血月教以血祭邪術與毒設局,趁他以金鐘罩護住眾僧、自身無法反擊時得手。戰力天花板規則因此不被破壞。
6. 補天陣為眾人合力與四器之力,不計入個人戰力。

## 四、境界不等於絕對勝負
- 軍陣、毒、點穴、陣法、地利、人數可越階制衡一至兩階。
- 越階制衡有成本:準備、代價、一次性消耗。
- 但**不可越過佛門頂端的線**:即使是群戰與器物,也無法讓個體超越佛門頂端的境界。
