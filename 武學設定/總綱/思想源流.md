# 思想源流

> 武學不只有「宗派」一種來處。現實的中國傳統中,戰鬥、醫藥、機巧、法度、言語都有各自的思想源流(諸子百家)。本檔把這些源流對應到本世界的武學,使體系的**來歷**多樣:不只有佛道,也有儒、墨、法、兵、陰陽、醫、縱橫。
> 這是創作用的對應,不是學術定論;現實有的源流沿用現實,本世界只疊加天痕與靈氣。分類見 [武學分類總覽](武學分類總覽.md)。

## 一、十一個源流

|---|---|---|---|---|---|

| 道 | 內丹周天、符籙陣法、坐忘、導引 | 內丹十二訣、兩儀心法、[道術陣法](../功法/道術陣法.md)、[禪定與心法](../功法/禪定與心法.md) | 太初觀、問天宗、青城 | 調和與天命;順勢 | 爆發不足,依賴準備 |
| 佛 | 禪定、金鐘罩、護持、神通 | 大雲心經、金鐘罩、[佛門神通](../靈能/佛門神通.md) | 大雲寺 | 護人與不殺的重量 | 護人時不能反擊;怕陰毒與暗算 |
| 墨 | 機關、守城、非攻(守而不攻)、鑄造 | [機關與鑄造](../功法/機關與鑄造.md)、守城器械 | 匠作與行會、靖邊軍 | 以器代力;防守的智慧 | 需事前準備,被識破失效 |
| 法 | 律令、刑名、驗屍、擒拿、追捕 | [刑偵與驗屍](../功法/刑偵與驗屍.md)、擒拿手 | 朝廷(黑衣衛、刑部) | 證據與權力的衝突 | 受權力左右,士氣隨上意 |
| 兵 | 兵法、軍陣、騎兵、後勤 | [軍陣與兵法](../功法/軍陣與兵法.md)、[騎術與馬上功夫](../功法/騎術與馬上功夫.md) | 靖邊軍、燕北軍、玄朔 | 為群;紀律與犧牲 | 個人天花板低;怕被斬將 |

| 醫 | 針灸、本草、傷科、毒與蠱 | [醫術](../功法/醫術.md)、[毒與蠱](../功法/毒與蠱.md) | 青城、棲霞閣、萬毒谷 | 救與害的兩面 | 近戰爆發不足;怕硬功 |

| 農 | 本草栽培、救荒、屯田、水利 | 醫術之本草、軍陣之後勤、機關與鑄造之工程水利 | 民間、軍屯、濟世盟 | 糧與民心;戰爭的底座 | 需要時間與和平 |
| 雜 | 綜合各家、江湖行規、雜藝 | [江湖技藝](../功法/江湖技藝.md)、[易容與潛行](../功法/易容與潛行.md) | 市井江湖(逍遙宮、漕幫) | 煙火氣與生存智慧 | 無傳說,依賴人脈 |

## 二、使用方式

1. **每個重要人物至少有一個源流**,且通常不止一個:男主是兵(靖邊槍)加禪定的候選;女主是醫加陰陽;宋青崖是儒加法;柳煙是雜加縱橫;曹無咎是法的反面(權術)加陰柔功。
2. **源流之間有緊張**:儒的規矩 vs 兵的實用、法的證據 vs 權力的暗算、佛的不殺 vs 邪門的吞噬、墨的非攻 vs 兵的攻城。衝突比單純的強弱更有戲。
3. **不單純用戰力衡量**:許多源流(法、縱橫、農、雜)不提高 L,但能在戰鬥之外改變勝負。
4. **現實為本**:每個源流在現實中都有對應的典籍與技術(《孫子兵法》《洗冤集錄》《墨子》《黃帝內經》《周易》等),新增功法時先找現實對應。

## 三、與傳承域的關係

傳承域(誰在傳)與源流(思想從哪來)是兩個維度:

| 傳承域 | 常見源流 |
|---|---|
| 宗門 | 道、佛、醫、陰陽 |
| 軍旅 | 兵、墨(守城)、農(屯田) |
| 朝廷 | 法、兵、縱橫 |
| 世家 | 儒、兵 |
| 書院與官學 | 儒、法、陰陽 |
| 匠作與行會 | 墨、農、雜 |
| 草原與外族 | 兵、雜 |
| 市井江湖 | 雜、縱橫、醫 |
