# 戰力基準(通用戰力等級 L)

本檔是全專案統一的戰力尺。任何角色、宗派、戰鬥場景,皆以 **戰力等級 L(Level)** 標示,便於開發者橫向比較。

## 一、定義
- **L0**:未習武的成年壯漢,為基準。
- 每一個**小階**為 1 L。七境 × 四小階(初、中、上、巔)= **L1–L28**。
- 「L」描述**個人基礎戰力**。靈能、神器、陣法、群戰等外部加成另算,見第四節。
- 現實校準:L1–L4 大致為受過正規訓練的武人;L5 起已非普通武術可比。

| 境界 | 初 | 中 | 上 | 巔 | 描述 |
|---|---|---|---|---|---|
| 煉形 | L1 | L2 | L3 | L4 | 筋骨強健,內息初生。士卒、學徒 |
| 通脈 | L5 | L6 | L7 | L8 | 氣脈貫通。門派弟子、二流高手 |

| 通玄 | L21 | L22 | L23 | L24 | 與天地共鳴。天下級宗師 |
| 問天 | L25 | L26 | L27 | L28 | 傳說極境;**本世界實際上限為 L25** |

## 三、世界戰力天花板
- **L25** 為世界個人戰力上限,由佛門無相老僧(L25)佔據。
- 任何人(含借力、神器、靈能、陣法加成後)的**有效戰力不得高於 L25**。
- L26–L28 僅為理論等級,故事中不出現。
- 佛門最高宗師為頂端:其他人最多與之齊平(L25),不可超越。

## 四、加成與上限

有效戰力 L_eff = 基礎 L + 加成;加成分類與上限如下。

| 加成來源 | 單項上限 | 說明 |
|---|---|---|
| 靈能(仙術/妖術/佛門神通) | +1 L | 三體系合計不得超過 +1 L;短時,需消耗「神」 |
| 神器、名兵 | +1 L | 如斷天劍與共鳴者;需契合 |
| 陣法、地利、準備 | +2 L | 一次性,需事前布置 |
| 合擊(同階) | 2 人 +1 L;4 人以上 +2 L | 需配合默契,上限 +2 L |
| 邪門速成(逆月訣、血祭) | 最多 +3 L | 短時,事後內傷;持續時間短 |
| 負面:重傷 | −1 至 −3 L | 視傷勢 |
| 負面:疲勞、內傷、心魔 | −1 至 −2 L | 疊加但最多 −4 L |

**總則**:個人有效戰力在正常條件下,所有加成合計**不超過 +3 L**(邪門速成者除外,但事後有重傷代價);且不超過世界天花板 L25。

## 五、對戰判定準則

| 差距(高者 − 低者) | 結果傾向 |
|---|---|
| 0 | 勢均力敵,看技巧、心境、環境 |
| 1 | 高者略佔優,低者可憑策略逆轉 |
| 2 | 高者壓制,低者需地利、陣法或暗算 |
| 3 | 難以逆轉,需特殊條件 |
| 4(一整境) | 基本無勝算,除暗算、陣法、群戰外不可能 |
| ≥5 | 碾壓 |

補充:
- **暗算與設局**可使實際差距視為縮小 1–3 級,但消耗準備與代價,且對手警覺後失效。
- **毒、點穴、醫術**可克制比自己高 1–2 L 的對手,但需近身機會。
- 慧淨之死即為**設局暗算**的例子:L24 的慧淨被 L24 的懷虛子與血月教合作所傷,不是 L 被超越。

## 六、群戰與軍陣

| 規模 | 加成 |
|---|---|
| 10 名同級 | 約等同 +1 L 的單體 |
| 100 名同級 | 約等同 +2 L |
| 1,000 人的軍陣 | 可制衡 L16(凝神巔) |
| 10,000 人的大軍 | 可威脅 L20(化真巔),但難以困住 L21 以上(通玄)的單人 |

**不超過 L25**:即使萬軍,也無法讓個人突破世界天花板——軍陣是集體力量,非個人戰力。

## 八、開發者使用指南
1. 為每位角色、每個宗派、每個場景標示 L 範圍。
2. 設計戰鬥時,先看雙方基礎 L,再計入加成,最後以差距表判斷結果傾向。
3. 增加新角色時,先放入第七節表格,避免戰力膨脹。
4. 若需要「越級擊敗」的劇情,須在劇情中明確安排暗算、陣法、群戰或代價,不可只憑「悟性」。
