# 流派對照

> 依 [體系差異化設計](體系差異化設計.md) 的八軸,把本世界的宗派與武學傳承放在一張表上比較。宗派的源流、功法與人物仍以 [宗派](../宗派/README.md) 各檔為正本;本檔是橫向比較,不重複人物戰力。
> 戰力 L 的範圍只在 [宗派一覽](../宗派/README.md) 維護,本檔不寫。

## 二、克制網

沿用 [三源合流](三源合流.md) 的克制原則,具體到流派:

| 攻方 | 被誰克制 | 原因 |
|---|---|---|
| 剛猛外功(靖邊槍、大雲手) | 毒、點穴、陣法 | 硬功遇到不接觸的手段無處發力 |
| 點穴與醫術(青城、棲霞) | 金鐘罩類硬功 | 點穴難透 |
| 陣法與符籙(守天人、問天宗) | 軍陣突襲、快攻 | 需要準備時間 |
| 軍陣(靖邊軍) | 單點突破的高階劍術、毒 | 陣怕被越階者一擊斬將,也怕下毒 |
| 化解型(太初觀) | 突襲、不出力的暗算 | 無力可借 |
| 一劍型(釣鰲島) | 群戰、陣法 | 一擊不中即無後手 |
| 護人型(大雲寺金鐘罩) | 暗算、陰毒、血祭 | 護人時不能反擊;慧淨之死據此設定 |
| 速成邪門(逆月訣、血祭) | 持久戰、醫者、佛門 | 內傷累積;佛門以靜制 |
| 暗器與易容(逍遙宮) | 正面強攻、持久戰 | 脫身有餘,硬碰不足 |
| 毒蠱(萬毒谷) | 青城解毒、大雲寺金鐘罩 | 醫者拆解;硬功擋住傷口 |
| 朝廷合圍(黑衣衛) | 越階的單人 | 人數可困住同階以下的個人,困不住越階者(見戰力基準第六節) |

**強調**:克制是「傾向」,不是定論。設局暗算可使實際差距縮小 1–3 級(見 [戰力基準](戰力基準.md) 第五節),是敘事上翻盤的空間。
