# 體系差異化設計

> 大型作品的武學不是「招式越多越好」,而是讓讀者**一眼分得出誰是誰、這一戰為什麼和上一戰不同**。本檔定義武學體系的差異化規則;各宗派的具體數據見 [流派對照](流派對照.md),招式見 [招式](../招式/README.md)。
> 這些是創作啟發式,不是定律;改動走 [建檔架構與順序](../../設計規範/建檔架構與順序.md) 的變更傳播。

## 一、為什麼要差異化

1. **辨識度**:十三個宗派若都是「內力加劍法」,讀者記不住誰。每個宗派要有一個一句話能講完的**標誌**(打起來是什麼樣子、代價是什麼)。
2. **戰鬥不重複**:全書數十場戰鬥,若形制雷同(都是一對一、都比內力高低),會疲乏。差異來自體系,不來自「再強一點」。
3. **承載主題**:武學是人物價值觀的外顯——靖邊軍的「為群」、釣鰲島的「為一劍」、大雲寺的「不殺」、邪門的「以人為薪」。體系差異就是價值衝突的來源。
4. **控制膨脹**:差異化比升級更省——新的體系帶來新場面,不必靠提高 L。戰力上限已固定在 L25,新鮮感要靠形制,不靠數值。

## 二、七種體系型態(文學功能)

武學不只是「功夫」,各型態給讀者的樂趣不同。一個宗派通常有 2–3 型,但**主型態**要鮮明。

| 型態 | 本世界例 | 讀者得到的樂趣 | 典型場面 | 寫法重點 |
|---|---|---|---|---|
| 階梯型 | 守心訣、兩儀心法、大雲心經 | 成長感、瓶頸與突破 | 修煉、閉關、突破 | 寫「進境」與心境,不逐招 |
| 套路型 | 靖邊槍、大雲手、羅漢拳、伏魔棍 | 具體可見的打鬥 | 對決、合擊 | 寫距離、步位、兵器軌跡 |
| 意境型 | 滄溟劍意、太極化勁 | 風骨、人格、大師感 | 比武、點撥 | 寫旁觀者的反應與「意」,不逐招 |
| 技藝型 | 回春針、蠱術、奇門遁甲、千面易容 | 智取、看懂的快感 | 解毒、破陣、潛入、鑑別 | 寫「看懂」那一瞬,讓讀者與角色同步 |
| 集體型 | 雁行陣、八面鋒、三人合擊、補天陣 | 配合、犧牲、分工 | 守城、群戰、疏導 | 寫節拍與分工,個人戲分融進整體 |
| 代價型 | 逆月訣、血祭大法、戾氣爆發、星引 | 誘惑與後果的時間差 | 孤注一擲、事後清算 | 寫「得」與「失」,失要有時間延遲 |
| 奇遇器物型 | 斷天劍、封天九章、劍冢、補天四器 | 命運與關係的改變 | 試煉、認主、解讀典籍 | 寫關係變化,不只是能力獲得 |

**型態配比的警戒線**:任何一卷中,套路型場面不超過全部戰鬥場面的一半;技藝型、集體型、代價型至少各出現一次(第一部的盤點見 [流派對照](流派對照.md) 的場面形制表)。

## 三、八軸:每個體系都要回答的問題

| 軸 | 問什麼 | 為什麼要有 |
|---|---|---|
| 力源 | 力從哪裡來(筋骨、呼吸、星象、藥理、紀律、血、月) | 決定修煉方式與資源 |
| 運勁觀 | 核心哲學(以靜制動、借力、順勢、逆行、為群) | 決定招式的「味道」 |
| 時空 | 打起來的距離、節奏、地形偏好 | 決定場面調度 |
| 勝負觀 | 追求什麼結果(降服、化解、制壓、一劍、耗盡、殲滅) | 決定人物在戰鬥中的選擇 |
| 代價 | 限制與弱點 | 決定克制網與劇情反轉的機會 |
| 傳承 | 怎麼學、傳給誰(口訣、軍中、師徒、血脈、家傳) | 決定師徒戲與派系衝突 |
| 語感 | 描寫用的意象與動詞 | 讓讀者不看名字也分得出 |
| 敘事功能 | 在故事裡扮演什麼 | 避免體系只是背景 |

## 四、傳承域:六個不同的來處

只有宗派會讓世界像「門派遊戲」。大型作品要有不同**來處**的武學,彼此價值觀不同:

| 傳承域 | 本世界例 | 特徵 |
|---|---|---|
| 宗門 | 大雲寺、太初觀、問天宗、青城派、釣鰲島、棲霞閣 | 師徒、口訣、理念、典籍 |
| 軍旅 | 靖邊軍、燕北軍、玄朔軍 | 紀律、協同、簡明、為群;個人天花板低 |
| 朝廷 | 神策軍黑衣衛、內侍監 | 追蹤與突襲、陰柔功、權力附庸;不講門面 |
| 世家 | 宗室劍術、宋家家傳劍術 | 規矩、儀式化、養身為主;戰場外的實用度低 |
| 草原與外族 | 玄朔摔跤與騎射、西域彎刀(拜月教) | 以搏鬥與馬為本;文化差異而非「落後」 |
| 市井江湖 | 漕幫與鏢局、逍遙宮 | 實用、狹地、脫身;沒有傳說,有煙火氣 |

衝突的種子:軍旅 vs 宗門(為群 vs 為己)、朝廷 vs 江湖(權力 vs 規矩)、世家 vs 實戰(規矩劍輸給看一遍就破的女主,P1-108)。

## 五、場面形制:戰鬥不只有對決

| 形制 | 規則重點 | 與哪些體系相配 |
|---|---|---|
| 對決 | 一對一,看技巧、心境、環境 | 套路型、意境型 |
| 合擊 | 兩人以上,需默契,加成見 [戰力基準](戰力基準.md) | 集體型 |
| 狹地戰 | 地利壓過個人差距 | 靖邊軍、漕幫、逍遙宮 |
| 破招 | 看一遍就破,考驗天分,不是力量 | 女主的天賦 |
| 試探過招 | 高者壓低者,目的不在勝負 | 袁破虜與男主 |
| 比武 | 規則、觀眾、名聲 | 問劍台 |
| 試煉 | 以關係與選擇通關,不是戰勝 | 劍冢、奇遇器物型 |
| 潰敗與爆發 | 弱者遇強者,以代價逃出 | 代價型 |
| 追逃 | 地形、路線、機關、記號 | 技藝型、輕功 |
| 解毒競賽 | 醫與毒的拆解,看誰先看懂 | 青城派 vs 萬毒谷、血月教 |
| 破陣 | 找出陣眼與節拍 | 奇門遁甲、守天人 |
| 軍陣戰 | 規模壓過個人,見戰力基準 | 靖邊軍 |
| 護人戰 | 不能反擊的守勢 | 大雲寺金鐘罩(慧淨之死伏筆) |
| 夜戰與毒戰 | 資訊不對等、延遲生效 | 拜月教、萬毒谷 |
| 點撥 | 高者以一招示意,不分勝負 | 意境型 |
| 切磋 | 輕鬆的比試,重在人物關係與天分展示 | 任何體系 |
| 化解(不出手) | 高者以調和或氣勢止住衝突 | 太初觀、釣鰲島 |
| 分工潛入 | 正面拖住、潛入、解迷香各司其職 | 集體型、技藝型 |
| 不動刀兵 | 不靠武力解決問題,各用所長 | 技藝型 |

第一部各形制的出場與缺口見 [流派對照](流派對照.md) 第三節。

## 六、新增功法的差異化檢核

新增一部功法、套路或宗派前,逐項回答;答不出就不新增:

1. 與既有功法**最像的是誰**?
2. 兩者在八軸中**有幾軸不同**?少於 4 軸,改為既有功法的支派或變體,不另立。
3. 它帶來哪一種**新的場面形制**或**新的價值衝突**?
4. 它的**代價**是什麼?沒有代價的功法不新增(避免強度膨脹)。
5. 把招式名換成「甲式、乙式」,讀者還分得出它的風格嗎?(語感測試)
6. 現實根基是什麼?對照 [武學設定 README](../README.md) 的「現實為本」原則。

## 七、命名與分層

武學名稱分三層,避免名稱氾濫:

| 層 | 例 | 規則 |
|---|---|---|
| 功法 | 靖邊槍、大雲手、兩儀心法 | 來自典籍或宗派傳承;內功稱「訣、經、心法」,外功稱「手、拳、掌、步」,兵器稱「槍、劍、刀」加「法」可省 |
| 套路 | 破陣十二式、歸墟九劍、太極十三勢 | 數字加「式、劍、勢」;一個套路是一組可以連貫的單招 |
| 單招 | 靖邊槍「點」、彎刀「滿月」 | 一到兩字為宜;只在關鍵場面點名,不為每一招取名 |

規則:
- 現實有的招式與拳種(太極十三勢、羅漢拳、八卦掌)沿用現實名,不另改。
- 本世界獨有的名稱,取字要符合該派語感(見 [流派對照](流派對照.md) 的語感欄):釣鰲島用潮汐、拜月教用月相、靖邊軍用軍中動詞(點、掃、挑、釘)、青城用醫理(截、引、回、封)。
- 單招名不超過 2 字,套路名不超過 5 字。
- 內力一律稱「內力」,不另造別稱(見術語表);靈能的消耗稱「神」。

## 八、狀態標記

[招式](../招式/README.md) 與功法總錄用以下標記,避免把「設定」誤當成「已寫入故事」:

| 標記 | 意義 | 動用規則 |
|---|---|---|
| 已出場 | 已出現在某卷事件或紀錄中 | 改動走變更傳播 |
| 設定 | 已設計、尚未用於任何事件 | 事件使用時改為已出場並登記事件 ID |
| 待定 | 只有方向,名稱與細節未定 | 使用前先補完設定 |

## 九、戰鬥描寫的三不

1. **不逐招羅列**:一場戲只點名一到兩個單招,其餘寫後果與反應。
2. **不用數值當情節**:L 是設計尺,正文不出現。差距用「接不住、擋不下、看不清」呈現。
3. **勝負要有過程的原因**:即使 L 差距決定結果,敗者要在某一點上做對了一件事(見男主夜宴 P1-076:輸,但看見了高承嗣認得他的槍路)。
