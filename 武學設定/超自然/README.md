# 超自然體系總則

本世界有三套超自然體系:**仙術**(道家)、**妖術**(民間方術與志怪)、**佛門神通**(佛教)。三者皆取材自真實的宗教與民俗傳統,**定位為武學的加成,不是獨立的戰力來源**。

## 一、總原則
1. **武學為本**:境界與戰力仍由武學七境決定;超自然只在武學之上「加一層」,不能獨立決勝。
2. **加成有上限**:任何超自然加成,最多讓施用者在**短時間內**提升**約半個小階到一個小階**的表現,或在特定領域(感知、療癒、迷惑、防護)提供輔助。
3. **有代價**:耗神、耗氣、耗壽、需準備、需特定條件,不能連用。
4. **不得越過天花板**:不論哪一體系,疊加後任何人仍不能超越佛門最高宗師(見 `總綱/境界與戰力天花板.md`)。
5. **末法限制**:靈氣稀薄,超自然效果比傳說中弱得多;僅在天痕附近、靈氣倒灌(第三部)等場景才短暫增強,但仍受上限約束。

## 二、三體系比較

| 項目 | 仙術 | 妖術 | 佛門神通 |
|---|---|---|---|
| 現實根基 | 道教內丹、符籙、方術 | 民間方術、巫蠱、志怪傳說、薩滿 | 佛教六神通、禪定、真言 |
| 加成領域 | 感應、陣法、符、延壽 | 幻術、迷惑、借獸力、詛咒 | 感知、護體、安神、療癒 |
| 對戰力的影響 | 中(輔助與控場) | 低(偏奇襲與干擾) | 中(防護與感知最強) |
| 主要代價 | 耗神、耗壽、需準備 | 反噬、損陰德、短效 | 修行深度、不殺戒的限制 |
| 克制 | 快攻、純陽硬功 | 佛門、純陽內功、醫者 | 暗算、陰毒、血祭 |
| 主要宗派 | 問天宗、太初觀、守天人 | 萬毒谷、血月教、民間術士 | 大雲寺 |

## 三、與武學的結合方式
- **仙術 + 武學**:陣法與符使團戰更穩,內丹修行讓內功更純。
- **妖術 + 武學**:幻術與迷惑創造破綻,配合近戰一擊;不能正面硬拼。
- **佛門神通 + 武學**:天眼通類的感知強化戰鬥判斷,金鐘罩類的護體更穩,但攻擊加成極少。
