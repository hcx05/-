# 靈能細目

> 仙術、佛門神通、妖術三套體系的法門,逐項寫到「起手、耗神、運作、旁人所見、限制與破法、由來」。總則與硬規則見 [靈能總則](../README.md)(FACT-002 至 FACT-005);本資料夾補的是**每一項法門用起來是什麼樣子,以及讀者從外面看見什麼**。
> 武學的對應工作在 [門派武學](../../招式/門派武學/README.md);兩邊的分界是:**武學修的是氣與身,靈能耗的是神**。

| 佛門神通 | [佛門神通](佛門神通.md) | 禪定九階、六神通逐項、護持的神面、真言與梵唄、超度、戒律 | 慧淨、無相老僧 |
| 妖術 | [妖術](妖術.md) | 虛實三層、幻術、迷神、口技、詛咒與厭勝、請獸、請神、方士百態、破法 | 無具名使用者(見該檔第一節) |

## 二、卡片欄位

| 欄位 | 寫什麼 |
|---|---|
| 起手 | 姿態、儀式、準備;靈能多半有「前置」,這一欄就是它的前置 |
| 耗神 | 輕 / 中 / 重 / 極,分級見下節 |
| 運作 | 世界內實際發生什麼。用世界內的說法,不用玄奧語 |
| 旁人所見 | 場面上看到、聽到、感到什麼。**寫正文時優先取這一欄**,不直接取「運作」 |
| 限制與破法 | 什麼條件下失效;誰、用什麼可以破 |
| 由來 | 分兩種:**現實**(取自真實的經典、民俗、史傳)與**本世界**(自設,標「設定」) |
| 狀態 | 已出場(附事件 ID,與事件描述一致)/ 設定 / 待定 |

## 三、神:量、耗、復

> 這一節是 FACT-003(靈能消耗「神」;神耗盡,該場戰鬥 −1 L)的展開。刻度只是**寫作時的對照尺,不進正文**;正文寫的是「還撐得住」「眼前發白」「耳邊嗡的一聲」。

### 來歷

《封天九章·定神章》:「神者,氣之帥也。帥動則三軍皆搖,帥靜則萬物自寧。夫神之耗也,甚於氣之耗。氣竭可養,神竭難復。故凡行術者,必量其神;神有餘,而後術可用。」守天人的「量神」(三息內視神的盈縮)就是這一章的招式,見 [守天人](../../招式/門派武學/守天人.md)。〈戒章〉再補一句:「修之過,則神耗;神耗則壽損。」

兩條合起來就是靈能的全部經濟學:**神是帥,不是柴;耗過頭,先損神,再損壽。**

### 神量

靈能須達對應武學境界才能施展(靈能總則第二節),所以神量從通脈起算。

| 境界 | 神量(點) | 一句話 |
|---|---|---|
| 煉形 | — | 不能用靈能 |
| 通脈 | 4 | 一天能穩穩用兩三次小事 |
| 開府 | 8 | 一場小戰,或一張符 |
| 凝神 | 14 | 一場中戰,或一次小陣 |
| 化真 | 22 | 一場大戰裡可用兩次重術 |
| 通玄 | 32 | 一個人撐得起一整座山門的神面 |

**心性修正**(靈能總則寫神量「隨境界與心性而定」):

| 狀態 | 修正 |
|---|---|
| 心定:守心訣、禪定、坐忘、抄經的長期修持者 | ×1.25(進位) |
| 心亂:執念、戾氣、恐懼、新喪、酒後 | ×0.75 |
| 重傷或久病 | ×0.5 |
| 虛火之中(第三部) | 視同心亂 |

這條使兩個同境界的人神量不同:一輩子修禪的人,神量大過同境界的人;被執念纏住的人,神量小過同境界的人。**它是解釋,不是判決**——別拿來替任何人在正文裡算帳。

### 耗神

| 級 | 點數 | 尺度 | 例 |
|---|---|---|---|
| 輕 | 1 | 一息之內 | 天耳初聽、障眼一瞬、一句真言、傳訊符的啟用 |
| 中 | 3 | 一炷香之內 | 一次存思、畫一張符、一段觀星推演、一次短暫的迷神 |
| 重 | 8 | 一場戰鬥的全程,或一次大術 | 觀星借力、請獸力附身、護體增強 |
| 極 | 不用點數 | 以壽元換 | 高階延壽、強行久撐;見〈戒章〉 |

**符是預存的神**:畫符時耗的是畫符者的神,用符時不再耗。這是仙術「需準備、不能臨場」的來由(見 [仙術](仙術.md) 第五節)。

### 恢復

| 方式 | 回復 |
|---|---|
| 一夜安睡 | 回一半(進位) |
| 連兩夜安睡 | 回滿 |
| 禪定、坐忘、數息一個時辰 | 回四分之一 |
| 安神藥(青城) | 回四分之一;連服三日即不再有效 |
| 有人守夜、哼歌、點一炷安神香 | 當夜睡得安穩,一夜回滿 |

最後一條是有意為之:**神是「心安」的東西,不是力氣**。溫素問的搖籃曲(序卷)、慧淨煮的那碗麵(P2-147),在這個尺度上都是真正的補神。

### 神竭之後

| 層 | 狀態 | 後果 |
|---|---|---|
| 神竭 | 神點歸零還硬撐 | 該場戰鬥 −1 L(FACT-003);靈能停用 |
| 神傷 | 神竭後數日 | 頭痛、耳鳴、眼前發白、反應遲鈍;神量減半,不另扣 L |
| 神損 | 一月內神竭三次以上 | 折壽(〈戒章〉「神耗則壽損」);且神量長期降一階 |

## 四、靈氣環境

靈能的效果與靈氣濃淡有關(靈能總則第五條「末法限制」)。**上限不隨環境改變**——環境只改變耗神與穩定度。

| 環境 | 何處 | 影響 |
|---|---|---|
| 常態(末法) | 人間多數地方 | 本資料夾所有刻度以此為準 |
| 福地 | 昆侖、青城、東海歸墟、雲夢澤 | 恢復快一倍;耗神 −25%(最少 1) |
| 天痕近旁 | 昆侖天痕、雁回關地底小天痕 | 感應類(觀星借力、與天痕共鳴)效果增強;但天痕擴大時靈氣紊亂,施術易失控 |
| 靈氣外溢(虛火期) | 第三部 P3-088 之後 | 效果可短暫達上限;虛火擾亂內力,也使神量視同心亂 |
| 補天之後 | 靈氣散入人間 | 各處略近福地,但沒有集中之處;無人能成仙(世界設定·天裂與末法) |

## 五、虛實三層

三套靈能不是都要寫成真的。**越不玄的地方,越像真的**——這是本世界的寫法。

| 層 | 含意 | 例 | 寫法 |
|---|---|---|---|
| 假 | 技藝與心理可完整解釋 | 障眼法、口技、迷香、對不知情者無效的詛咒 | 讓讀者事後恍然:原來如此 |
| 半 | 有少量神的成分,主要仍是人的感知與環境 | 存思穩心、天眼通辨氣機、符護身擋下第一擊 | 寫「人感覺到」,不寫「發生了」 |
| 真 | 超出常理 | 天痕感應、守天人遺陣自行運轉、觀星借力的 +1 L | 少、短、有代價 |

**一個場面只留一個「真」。**

## 六、加成歸屬

三體系合計 +1 L 是**一個池子**;陣法、神器、合擊各有各的池子(見 [戰力基準](../../總綱/戰力基準.md) 第四節)。常見的混淆在這裡釐清:

| 事項 | 歸屬 | 說明 |
|---|---|---|
| 觀星借力 | 靈能 +1 L | 仙術,化真以上;同一場只取靈能中最高一項 |
| 請獸力附身 | 靈能 +1 L | 妖術,化真;有反噬 |
| 護體增強 | 靈能 +1 L(防禦) | 佛門,化真以上 |
| 天眼通、他心通等感知 | 判斷力,場面上用「看穿破綻」表現 | 若要折成 L,仍算靈能 +1 L 的同一池 |
| 布陣、符陣聯動 | 陣法 +2 L | 仙術只負責**讓陣成立**(陣眼上的神),不另加 +1 |
| 金鐘罩本體、內丹、一指禪 | 武學,不是靈能 | 見 [大雲寺](../../招式/門派武學/大雲寺.md)、[太初觀](../../招式/門派武學/太初觀.md) |
| 禪定、坐忘、數息 | 修神的方法,不是靈能 | 見 [禪定與心法](../../功法/禪定與心法.md) |
| 障眼法、口技、迷香、易容 | 技藝,不耗神(或只耗體力) | 不計入任何加成 |
| 蠱 | 技藝(與毒並列),不是靈能 | 見 [毒與蠱](../../功法/毒與蠱.md) |

## 九、第三部之後

- **佛門神通**:禪定與金鐘罩不靠靈氣,大雲寺的路不因靈氣散入人間而斷。
- **仙術**:觀星借力與天痕感應依賴天象與天痕,天痕收攏後失去用處;辟穀、胎息、存思、符籙是人的技藝,留得下來。不再有人能成仙。
- **妖術**:民間方術本來就不靠靈氣,騙子與半吊子照舊,真有本事的更少。

## 十一、現實對照提醒

三套體系取材自真實的宗教與民俗。佛教的神通在經典中是修行的副產品,佛陀並不鼓勵炫耀;道教的存思、內丹、符籙是歷代修行者的實修傳統;民間的巫、方術與志怪是長期並存的民俗。本資料夾以尊重的方式融入虛構世界,**只寫世界內的效果與場面,不提供現實可操作的方術、丹藥、咒語教學**;外丹只寫症狀與後果,詛咒只寫心理與社會效果,氣的引導不是醫療或練功指導。
