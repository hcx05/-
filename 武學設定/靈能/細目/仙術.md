# 仙術細目(道家)

> 語感:星、符、丹、息。體系定位與層級表見 [仙術](../仙術.md);刻度與規則見 [靈能細目 README](README.md);約定與欄位同該檔。
> 現實根基:道教的內丹、辟穀、服氣、存思、符籙、步罡踏斗(禹步)、奇門遁甲、尸解傳說、外丹。
> 本體系的總原則:**把修行推到極致的輔助術,不是法術**。標誌是「像一個準備充分的人:事前做足,臨場只是啟動」。仙術不能直接殺傷,也不能臨場速成——它的戲在**準備**與**代價**,不在施放。
> 這一體系的底色來自《封天九章》:真正的仙人早已離去,留下的是殘卷與法門;而天上無仙(世界設定·天裂與末法),所以仙術最深處通向的不是長生,是「虛」。

## 二、內丹與神

- **由來**:
  - 現實:內丹術把人身當爐鼎,以「煉精化氣、煉氣化神、煉神還虛」為次第;東漢魏伯陽《周易參同契》是丹道話語的源頭,北宋張伯端《悟真篇》是內丹成熟的代表。
  - 本世界:太初觀的〈內丹十二訣〉是這條路的**內功面**(築基、煉精化氣、煉氣化神、煉神還虛,第四組末法無人完成),見 [太初觀](../../招式/門派武學/太初觀.md) 第四節。本檔只談它的**神面**。
- **神面的要點**:
  - 煉精化氣是修氣(內力的來處);**煉氣化神**才是修神——神量的上限在這一關。
  - 所以「仙術須達對應武學境界」不是任意規定:境界高,神才養得出來。
  - 還虛、合道是傳說,末法無人達成;能達成者,在世界真相裡也已通向「虛」。
- **旁人所見**:修內丹的人,老得慢、睡得少、不容易慌。**沒有別的**。

## 三、辟穀、服氣、胎息

> 這是仙術最入門、最不玄的一組。三者都不耗多少神,效果微弱,但**能在極端處境下救命**:斷糧、被圍、潛伏。

### 辟穀〔設定〕

- 起手:日常漸減食量,多飲水,晨起日下調息。
- 耗神:輕(每日)。
- 運作:食量減到平日約三成,數日不虛。通脈即可。
- 旁人所見:面色清,腹中少聲,不饞。
- 限制與破法:超過七日傷身;重活與戰鬥時無效;不是絕食。
- 由來:現實:《莊子·逍遙遊》寫藐姑射山的神人「不食五穀,吸風飲露」;《史記·留侯世家》寫張良晚年「乃學辟穀,道引輕身」。本世界:通脈級的入門功課。
- 用處:圍城、逃亡、荒原行軍;**不得用來寫「不吃飯的仙人」**。

### 服氣〔設定〕

- 起手:日出前面東而立,緩吐緩納,不語。
- 耗神:無(是補神)。
- 運作:一個時辰調息養神,回神四分之一(與禪定同尺,見 [細目 README](README.md) 恢復表)。
- 旁人所見:一個人在晨霧裡站著,衣擺不動。
- 由來:現實:道教「服氣」「行氣」,戰國《行氣玉佩銘》即有行氣的文字記載;「餐霞」是它的詩意說法。

### 胎息〔設定〕

- 起手:靜臥或靜坐,吐納漸細,至若有若無。
- 耗神:輕。
- 運作:呼吸細到旁人幾乎察覺不到,閉息可達平常數倍。
- 旁人所見:胸腹不起伏,脈搏微弱。
- 限制與破法:需多年練習;貼身探脈可以察覺;**與萬毒谷的蠱息(共生)、守天人的歸藏訣(內收)不同**——胎息是呼吸本身的功夫。
- 由來:現實:《抱朴子·釋滯》:「得胎息者,能不以鼻口噓吸,如在胞胎之中。」
- 用處:潛伏、水下、避毒煙。與守天人的封息(備案)相鄰,見第十節。

## 四、存思觀想

- **由來**:現實:上清派的「存思」,是想像日月、北斗、身中諸神的形象以通神、安神;《黃庭經》講的五臟諸神即屬此類。本世界:穩神的功夫,**開府級**。
- **共通**:存思穩的是神,不是氣。穩神後,對迷神、幻術的抵抗上升。

### 存日月〔設定〕

- 起手:晨存日、夜存月,閉目,想其形在眉間。
- 耗神:中。
- 運作:一炷香內心神穩定,對妖術的迷神、幻術抵抗上升(見 [妖術](妖術.md))。
- 旁人所見:靜坐,眉間舒展。
- 由來:現實:上清派存思日月入口、入身。

### 存北斗〔設定〕

- 起手:夜,面北,想七星各在身上一處。
- 耗神:中。
- 運作:觀星借力與步罡的**前置**:先把星位存於心,再接天上的星。
- 旁人所見:一個人抬頭看天,看很久。
- 由來:現實:上清派存思北斗七星。本世界:與問天宗〈觀星引氣訣〉同根,但**那是修氣,這是穩神**,見 [問天宗](../../招式/門派武學/問天宗.md) 第二節。

### 存身神〔設定〕

- 起手:靜坐,意守胸中一處。
- 耗神:輕。
- 運作:恐懼或疼痛時穩住心跳,不使神散。
- 旁人所見:一個人在危急時,臉色變得很平。
- 由來:現實:《黃庭經》以五臟為諸神所居,存思即守之。

## 五、符籙

- **由來**:
  - 現實:東漢天師道以符水治病,符籙自此成為道教的核心實修之一。《抱朴子》的〈登涉〉〈遐覽〉記有入山辟邪之符與大量符書之名。符的圖形有結構,常分**符頭**(敕令)、**符膽**(中心)、**符腳**(收尾)。
  - 本世界:符籙是仙術裡最能**被看見**的一項,也是最不玄的一項。
- **符的本質(設定)**:**符是預存的神**。畫符時耗的是畫符者的神,符成之後,符上存著那一份神;用符時不再另耗。這就是仙術「需準備、不能臨場」的由來:畫一張符要先有神,要先有時間,符也只能用一次。

### 畫符五步〔設定〕

| 步 | 內容 |
|---|---|
| 淨 | 沐手漱口,靜心;古法用黃紙、特定的墨,取特定的時辰 |
| 定 | 凝神三息,量神(見 [守天人](../../招式/門派武學/守天人.md) 第二章定神) |
| 書 | 一筆而成,不回筆;符頭、符膽、符腳依序 |
| 敕 | 落最後一筆時,把神注入;畫符者在此刻最疲 |
| 收 | 焚、佩、貼,三者擇一 |

- 耗神:隨符的大小,輕至中。畫完一張符,畫符者當日不宜再耗神。
- 破法(共通):受潮、遇血污、符紙被毀;持符者心亂(符與持符者的神要「對得上」);被天眼通看出節點;畫符前被打斷。

### 傳訊符〔設定〕

- 起手:兩張符同墨同時辰畫成,各執一張。
- 耗神:輕(啟用時)。
- 運作:一張被焚,另一張在數十里內微熱;**傳的是「有事」,不是內容**(福地可遠一倍)。
- 旁人所見:懷裡的符紙忽然發燙。
- 狀態:青城、太初觀的簡單符籙,見 [道術陣法](../../功法/道術陣法.md)。

### 安神符〔設定〕

- 起手:置於枕邊或床頭。
- 耗神:中(畫符時)。
- 運作:持符者當夜睡得安穩,等於**替他守了一夜**(恢復表中「有人守夜」一條)。
- 旁人所見:孩子睡熟了,不哭。
- 階段:通脈即可。

### 避蟲符〔設定〕

- 階段:通脈。效果弱,可驅蚊蟲,對萬毒谷的蠱無效(蠱屬技藝,見 [毒與蠱](../../功法/毒與蠱.md))。

### 護身符〔設定〕

- 起手:隨身佩帶,貼身。
- 耗神:中(畫符時)。
- 運作:**擋下一擊小攻擊**(散招、暗器一類);符上的神在受擊時一次散盡。
- 旁人所見:胸口的符紙一震、發燙,邊緣焦黑,或化為灰。
- 限制與破法:一次即廢;擋不了高出畫符者數階者的認真一擊;遇血污失效;**不增加 L**。
- 階段:開府。

### 鎮邪符〔設定〕

- 起手:貼於門楣或枕下。
- 耗神:中。
- 運作:對**詛咒與魘鎮**特別有效——因為這類術本來就靠心理,符給受術者一個「有人護著我」的錨。
- 旁人所見:噩夢漸少,人漸漸安下來。
- 用處:與妖術的詛咒互為鏡子,見 [妖術](妖術.md) 第六節。

## 六、步罡踏斗

- **由來**:
  - 現實:「罡」指北斗斗柄,「步罡」是依北斗、九星或八卦方位行步,常配咒與存思;「禹步」是其源頭,傳說大禹治水,足疾而行,後世道士以「三步九跡」為禹步的標準步式。
  - 本世界:問天宗的〈踏星步〉是**武學身法**(為了移動與劍路,見 [問天宗](../../招式/門派武學/問天宗.md) 第四節);步罡是它的**靈能面**——不為移動,為了**站在星位上存思**。
- **分工**:踏星步求快求準;步罡求慢求定。同一個人兩樣都會,但用法不同。

### 七星步〔設定〕

- 起手:地上畫或擺七個位,依斗魁到斗柄次序行步,每步停一息。
- 耗神:中。
- 運作:走完一遍,存北斗於身。此後一炷香內身法稍輕、判斷稍穩(輔助,不計 L)。
- 旁人所見:一個人在地上緩慢地走格子。
- 限制與破法:需一盞茶工夫,不可打斷;星位須標準;陰雨不佳。

### 禹步〔設定〕

- 起手:入險地之前,三步九跡。
- 耗神:輕。
- 運作:實際效用是**定心**與**穩步**,屬「半」層(見 [細目 README](README.md) 第五節)——入瘴、入古墓、入遺陣前,先把腳步與呼吸齊一。
- 旁人所見:一個人在洞口站了站,走了幾步,才進去。
- 由來:現實:道教的禹步。

## 七、奇門與陣

- **由來**:現實:奇門遁甲以「三奇(乙丙丁)、六儀(戊己庚辛壬癸)」布於九宮,配「八門」「九星」「八神」,推演時、方位與吉凶;傳說起於黃帝與蚩尤之戰,九天玄女授兵符,後世附會於姜太公、張良、諸葛亮。諸葛亮的「八陣圖」遺跡(杜甫:「江流石不轉」)是它最有名的民間記憶。
- **八門**〔現實名,沿用〕:

| 門 | 吉凶 | 本世界的寫法 |
|---|---|---|
| 休 | 吉 | 休整、可退之處 |
| 生 | 吉 | 生路,破陣者所求 |
| 開 | 吉 | 開闊,可通行 |
| 景 | 中 | 景象、幻象,迷心之處 |
| 傷 | 凶 | 傷人之處 |
| 杜 | 凶 | 堵塞之處 |
| 死 | 凶 | 死地 |
| 驚 | 凶 | 驚擾心神之處 |

- **陣的構成(設定)**:地形 + 標記 + 節點 + **一顆穩定的心**。布陣三要素是「心、方、時」(《封天九章·布陣章》)。陣眼是節點的中心;破陣就是找陣眼、對節拍。
- **加成歸屬**:陣法的加成算「陣法、地利、準備 +2 L」,**不算靈能**。仙術在陣裡的貢獻是**讓陣成立**:陣眼上要有人的神撐著。
- **耗神**:小型陣一炷香,中;大陣全程,重。
- **弱點**:怕快攻與軍陣突襲;久恃則人懈(《封天九章》:「陣成而不可久恃」)。

### 小陣〔設定〕

| 陣 | 構成 | 效果 |
|---|---|---|
| 九宮小陣 | 九處標記,施術者居中宮 | 困敵一時;與問天宗的九宮陣(移、鎖、困)同源 |
| 八卦陣 | 八方加中,環形布置 | 困而不殺;太初觀常用 |
| 五行陣 | 金木水火土五處,相生相剋 | 以相剋之物破之 |

### 守天人的遺陣

遺陣是仙術裡**最「真」的一項**,也是唯一**不靠現世人耗神**的一項:陣自己在運轉。

| 陣 | 通關之鑰 | 狀態 |
|---|---|---|
| 劍冢幻象陣 | 守心訣穩住雪夜與火光,再過彼此信任一關 | 已出場(P1-057、P1-058) |
| 小天痕陣紋 | 女主判讀 | 已出場(P1-061) |
| 沉沙遺陣 | 心神、陣法、選擇三關;逆脈的節奏與星圖相合 | 已出場(P2-110、P2-111) |
| 護山大陣(隱村) | 迷陣與封門並用 | 設定 |

- **提醒**:遺陣的關卡考的是心與選擇,不是比內力、比神量。**破遺陣的戲,寫人,不寫陣。**

## 八、觀星借力

> 化真級仙術,也是仙術裡**唯一一項「真的加成」**。

- **起手**:夜,見星,開闊;先存北斗,再依星位行步,最後定一星為所借。需一盞茶到一炷香的準備。
- **耗神**:重(8 點)。一場戰鬥最多一次。
- **運作**:以神為橋,讓自身與星位「對上」。短時間內判斷更穩、出手更準、內力運轉更順,約 **+1 L**。
- **旁人所見**:施術者在戰前站定,仰面看天,看的時間比看人長。開打後他的動作不快,但每一步都在該在的位置。
- **限制與破法**:
  - 陰雨、無星之夜、密室、地底,效果打折或全失。
  - 準備時被打斷,借不成。
  - 快攻:他還沒站定,人已經到了。
  - 事後神量不足,該場戰鬥 −1 L(神竭規則)。
- **由來**:
  - 現實:中國古代以天象驗人事,有「分野」之說,《史記·天官書》為其集大成。
  - 本世界:《封天九章·觀星章》規定「星者,天之文也,非天之命也。人可從之,不可惑之」。借力是**借勢**,不是**受命**——這正是問天宗與守天人分歧之處:問天宗把「應」當成「命」,守天人說「應者,感也,非定也」。
- **使用者**:懷虛子(角色檔:仙術高階,觀星借力、符陣聯動)。他 L24,借天痕與守天人遺訣的峰值為 L25,與世界上限齊平,不超越。
- **與武學的分界**:問天宗的連星劍、星引是**武學**(見 [問天宗](../../招式/門派武學/問天宗.md));觀星借力是**靈能**。同一場戰鬥,兩者的加成只取其高,不相加。

## 九、與天痕共鳴

- **階段**:通玄。
- **耗神**:重,或極(耗壽)。
- **運作(設定)**:
  - **感應**:通玄者能感到天痕的擴縮,如同感到遠處的一次呼吸。只是「聽」,**不能控制**。
  - **挪壽**:所謂「簡易療癒、延壽」,**不是添壽,是挪壽**——以自己的壽元換他人的,且折損大於所得。這與女主的禁術星引(以自身元氣救人)、傳說中的換命同類,代價是壽數與道義。
- **旁人所見**:通玄者在天痕近旁忽然皺眉,說「它在動」;或一個人救了另一個人,自己白了一把頭髮。
- **限制**:星命者(破軍、紫微)與天痕的共鳴是**命格**,仙術的感應是**修為**,兩者不同,不要混寫。
- **使用者**:白眉老祖(守天人遺法)、懷虛子(借天痕)。**不詳寫方法**(典籍不提升戰力上限,見 [問天宗](../../招式/門派武學/問天宗.md) 第八節)。
- **白眉老祖**:角色檔作約 108 歲,第三部 P3-146 靜靜坐化。可視為守天人遺法養生延年的結果(角色檔未明寫,屬解讀,不入正文)。

## 十、尸解與長生

- **由來**:現實:《抱朴子·論仙》引仙經說,仙有三等:上士舉形昇虛為天仙,中士遊於名山為地仙,下士先死後蛻為尸解仙。
- **本世界**:天上無仙,強開天門的人被虛吞噬(世界設定·天裂與末法)。所以:
  - **天仙**:不存在。
  - **地仙**:長壽的隱者(白眉老祖是一例)。
  - **尸解**:實際上是**假死脫身**。守天人的封息(備案:封閉氣血外顯,可令人假死,見 [守天人](../../招式/門派武學/守天人.md))與此同類;溫素問以假死脫身(角色檔,手法未寫)。
- **寫法**:世人說「某某尸解了」,多半是死遁。懷虛子要的不是長生,是接回雲裳——他把仙術走到了盡頭,看見的是門後無生無死、無往無返(P3-135)。

## 十一、外丹

- **由來**:現實:外丹是以礦物金石煉丹服食,《抱朴子·金丹》為其代表。唐代多位皇帝因服食金石丹藥而病、亡,是外丹最有名的後果。
- **本世界**:末法下多被棄用。短期亢奮,長期毒傷。
- **規則**:此處**只寫症狀與後果,不寫配方與製法**。
- **使用者**:景和帝。角色檔記他「晚年迷信丹道,終日與方士為伴」,戰力 L2(煉形中,服丹導致體虛)。太子曾公開反對朝廷迷信丹道與宦官專權(PRO-020),可見丹道在朝中已是政治問題,不只是一人的癖好。
- **症狀(設定)**:先是神旺、少睡、多疑,繼而體虛、面色晦暗、易怒、倦怠,最後是神與身雙損。**不增加任何 L,只減**。
- **寫法**:外丹是仙術的反面——它向外求,向快求;《封天九章》是向內守。

## 十二、《封天九章》與仙術

> 九章不是「仙術教材」,是「守」的文獻。這裡只列它們與仙術的關係。九章全文見 [封天九章](../../典籍/封天九章.md),招式與修法見 [封天九章修法目錄](../../招式/重點武學/封天九章.md)(逐訣、耗神、前置)與 [守天人](../../招式/門派武學/守天人.md)。

| 章 | 與仙術的關係 |
|---|---|
| 一 守心章 | 修神的地基;任何仙術須先過此章 |
| 二 定神章 | 神量與「量神」;靈能消耗稱「神」即由此而來 |
| 三 觀星章 | 觀星借力的依據與限制:人可從之,不可惑之 |
| 四 布陣章 | 陣的三要素:心、方、時 |
| 五 鎮器章 | 四器不是仙術,是守的東西;無德而持器,器反噬之 |
| 六 疏導章 | 方向,不是力量:通其流,而後歸其所 |
| 七 禁章 | 門不可開,亦不可盡閉;居中 |
| 八 戒章 | 修之過則神耗,神耗則壽損 |
| 九 □章 | 缺;僅存「歸」字 |

**次序不可越級**:先守心,再定神,方可觀星;未過前章而修後章者,必損神。

## 十四、寫作提醒

- **寫準備,不寫施放**:一個人在雪夜裡把七個位擺好,比他「施法」有力得多。
- **寫手與紙**:畫符的手、紙邊、墨未乾,比符的效果更該被看見。
- **寫代價**:畫完一張符的人,要坐下來,喝口水。
- **寫失效**:陰雨、受潮、被打斷,是最好用的情節轉折。
- **不要寫成法術**:仙術不能殺人,不能飛,不能凌空取物。

## 十五、第三部之後

靈氣散入人間,天痕收攏。觀星借力與天痕共鳴失去了憑依;辟穀、胎息、存思、符籙是人的技藝,留得下來。**不再有人能成仙**,也不再有人能壟斷仙術。問天宗瓦解,守天人名分終結(白眉老祖坐化,P3-146)。符籙與安神的老功夫,會在民間以「求個平安」的樣子繼續。
