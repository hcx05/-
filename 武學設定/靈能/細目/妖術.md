# 妖術細目(民間方術與志怪)

> 語感:煙、影、毛、香。體系定位與層級表見 [妖術](../妖術.md);刻度與規則見 [靈能細目 README](README.md);約定與欄位同該檔。
> 現實根基:幻戲(眩人)與方術、巫蠱、厭勝與魘鎮、薩滿式請神、東北「五大家仙」信仰、志怪筆記。
> 本體系的總原則:**妖術是最弱的靈能:九成是技藝,一成是神;它的價值在轉折,不在戰力**。標誌是「像夜路上的一聲貓叫:你不知道是什麼,所以怕」。妖術**不能與宗師正面抗衡**,**世界無真正變形**(FACT-005)。
> 這一體系**沒有具名使用者**(角色檔無人以妖術為專長)。這不是缺口——妖術本來就是零散術士的體系,適合一次性的江湖奇人、市井騙子、邊地巫者。

## 二、虛實:妖術的真與假

> 這一節是整個體系的寫法。**妖術越像假的,越像真的。**

| 層 | 含意 | 例 |
|---|---|---|
| 假 | 技藝與心理可完整解釋 | 障眼法、口技、迷香、對不知情者無效的詛咒 |
| 半 | 有少量神的成分,主要是人的感知與環境 | 迷神、共感、噩夢、幻境 |
| 真 | 超出常理 | 請獸力附身的 +1 L |

- **全體系唯一的「真」是請獸力附身**;其餘都能被「世界內的合理解釋」完全替代。
- **寫法**:先讓人怕,再讓人懂。第一次出現時留白,第二次或事後揭開手法;或始終不揭,只讓人知道「這個人不好惹」。
- **一個場面只留一個「真」**。

## 三、幻術

- **由來**:
  - 現實:古稱「幻」「眩」「幻戲」。《史記·大宛列傳》記安息以黎軒善眩人獻於漢,是西域幻人入漢的記載;《列子·周穆王》有西極化人;《後漢書·方術列傳》載左慈、費長房等方術之士。
  - 本世界:幻術大半是**障眼法**——引視線、遮死角、借光與煙。真正需要神的,只在幻境一項。

### 障眼法〔設定〕

- 起手:袖、掌、光、煙、布,任取其一;說話分散注意。
- 耗神:無或輕。
- 運作:利用視覺盲區與注意力,讓人**看錯一瞬**。
- 旁人所見:「那人明明在這兒」;一個物件消失、換位、多出一個。
- 限制與破法:**識破即破**;不看手而看人的重心;閉眼;清水潑面;強光;風。
- 由來:眩人與幻戲的傳統。
- 用處:逃脫、偷換、潛入、離間。

### 迷神〔設定〕

- 起手:香、聲、目光三選一至三,配合緩慢重複的語調。
- 耗神:輕至中。
- 運作:人的神與**藥**的合用:香藥使人鬆懈,語調與眼神使人跟隨。受術者**短暫恍惚數息**,對不上時間,聽不清複雜指令;對高境者與定力強者無效。
- 旁人所見:一個人忽然站住,眼神渙散,說話慢了半拍。
- 限制與破法:
  - 疼痛(咬舌、掐)、風、掩鼻、清水。
  - 守心訣、禪定、純陽內功、梵唄。
  - 醫者解香:女主在血月壇解迷香(P1-014)。
- **迷香與迷神的分界**:迷香是**藥**,屬技藝(見 [血月教](../../招式/門派武學/血月教.md) 第五節,已出場);迷神是**人**,屬妖術。兩者合用才強,各自單用都弱。
- 由來:現實:《水滸傳》等所寫的蒙汗藥、迷香一類。**只寫效果,不寫成分**。

### 幻境〔設定〕

- 階段:化真。範圍小——一間屋、一個院。
- 起手:布置煙、香、聲響、光影;施術者居中,凝神。
- 耗神:重(維持期間持續占神)。
- 運作:疊合地形、煙霧、聲響、光影與香,再以神定其「像」。**不造不存在之物,只讓人把存在之物看成別的**。
- 旁人所見:一個院子,走來走去走不出;人在原地繞;同伴的臉忽然陌生。
- 限制與破法:
  - 找**不合理處**:影子的方向、聲音的來處、腳下的泥。
  - 找施術者(施術者必在範圍內,神被占滿,不能動)。
  - 火與風。
  - 梵唄與真言。
- **與迷魂陣的分界**:萬毒谷的迷魂陣是地形與瘴氣的技藝(見 [萬毒谷](../../招式/門派武學/萬毒谷.md) 第七節);幻境是人的神加上布置。
- 狀態:設定。

## 四、口技、變聲與易容

> 這一組都**不耗神**,屬技藝,放在這裡是為了劃清與妖術的界線。

- **口技**:
  - 現實:《史記·孟嘗君列傳》中的「雞鳴狗盜」——食客學雞鳴,騙開函谷關;清·林嗣環有〈口技〉一文。
  - 本世界:模仿聲音。逍遙宮的變聲與口技見 [易容與潛行](../../功法/易容與潛行.md)。
- **易容**:靠細節,不靠面具;熟人與識人者難以騙過。
- **變形**:**世界無真正變形**(FACT-005)。判別:

| 現象 | 實為 | 歸屬 |
|---|---|---|
| 一個人換了張臉 | 易容 | 技藝(逍遙宮) |
| 人影化獸、獸化人 | 幻覺 | 妖術(幻境) |
| 老人忽然變少年 | 兩個人,或易容 | 技藝 |
| 妖怪現身 | 異獸,或偽裝 | 世界設定 |

- **提醒**:柳煙在 P3-083 頂著女主的臉,臨終說「這張臉,借我用一下」——那是**易容**,不是妖術,也不是變形。

## 五、請獸

- **由來**:
  - 現實:東北民間的「五大家仙」信仰——胡(狐)、黃(黃鼠狼)、白(刺蝟)、柳(蛇)、灰(鼠);薩滿與出馬弟子以「請仙家」附體。志怪筆記如《搜神記》《聊齋志異》多寫狐魅蛇精。
  - 本世界:末法時代真正的精怪極少,異獸(巨蟒、靈狐、雪狼王)偶爾出沒於靈氣濃厚之地(世界設定·天裂與末法)。請獸是**人與異獸共生的特殊本領**,不是召喚。
- **共通限制**:離獸無效;獸的壽命短於人;異獸稀少,末法下尤其。獸若死,術者受重創。

### 馴〔設定〕

- 階段:開府。
- 起手:長年相處,餵食,說話。
- 耗神:無(技藝)。
- 運作:獸認人,聽令,傳信,看家,跟蹤。與黑衣衛的犬鷹追蹤相通(見 [宗派以外的傳承](../../招式/門派武學/宗派以外的傳承.md) 第四節)。
- 旁人所見:一隻鷹落在一個普通人的肩上,不怕他。

### 共感〔設定〕

- 階段:凝神。
- 起手:閉目靜坐,獸在近處。
- 耗神:中。
- 運作:**借獸的感官**——嗅覺、夜視、聽覺。距離數里。獸受傷,術者亦痛。
- 旁人所見:術者閉目坐著,他的獸立在高處,一動不動。
- 限制與破法:獸被驚走、被殺,則斷;術者自己被打擾,則斷。

### 附〔設定〕

- 階段:化真。
- 起手:儀式性的靜坐與面對;術者與獸額頭相對,雙方情緒同步。
- 耗神:重。
- 運作:**請獸力附身**——短期爆發,借狼的撲、狐的閃、蛇的纏,約 **+1 L**。全體系唯一的「真」。
- 旁人所見:動作忽然不像人——低、快、不顧後退,喉間有低聲。
- 限制與破法:
  - 反噬:損傷心神,獸性上身,事後數日暴躁易怒;使用過頻,有失控之虞。
  - 獸死則術破。
  - 對佛門與定力強者無效。
- 由來:現實:薩滿式請神附體。
- 狀態:設定。**不得與宗師正面抗衡**:+1 L 補不了差距,只能製造一次奇襲。

## 六、詛咒與厭勝

- **由來**:
  - 現實:**厭勝**(壓勝)以物壓邪,亦可害人;**魘鎮**以偶人、咒文害人。漢武帝征和二年(公元前 91 年)的**巫蠱之禍**是它在歷史上最慘烈的一次——近臣江充以巫蠱構陷,太子劉據兵敗自殺,牽連甚廣。
  - 本世界:太子被誣謀逆(PRO-022)與此**形狀相近**:皇帝多疑,近臣構陷,太子被誣。**案情不涉巫蠱,僅作類比**,不得改動。
- **本世界的機制(設定)**:**詛咒要被知道才有效**。
  1. 媒介:需對方的毛髮或貼身物(中階)。
  2. 施術者耗神(中)。
  3. 作用:對**知情且心虛**者最強——噩夢、失眠、疑神疑鬼、覺得運勢變壞。對**不知情者**幾乎無效;對定力強者無效。
  4. 長效詛咒(通玄):靠**持續的恐懼**餵養,需有人不斷提醒受術者;損陰德、折壽。
- **所以詛咒是「恐懼的工程」**,最致命的用法常是**指控**:說「他被人下了咒」「他是個咒人的」,比咒本身更能害人。
- **規則**:此處**只寫心理與社會效果,不寫儀式與方法**。

### 噩夢〔設定〕

- 階段:凝神。
- 耗神:中。
- 運作:受術者連夜噩夢,知情更重。
- 旁人所見:眼下發青,疑神疑鬼,不敢睡。
- 破法:說開;燒物;醫者安神;鎮邪符(見 [仙術](仙術.md) 第五節);持誦(見 [佛門神通](佛門神通.md) 第六節);睡一個有人守著的安穩覺(見 [細目 README](README.md) 恢復表)。

### 魘鎮〔設定〕

- 階段:凝神至化真。
- 耗神:中。
- 運作:效果同噩夢,但**多一層指控的力量**。
- 破法:找出並公開那件物事,當眾拆穿。

### 厭勝〔設定〕

- 用途:防身、鎮宅、壓邪。
- 運作:一半是物,一半是**人有個依靠的感覺**。
- 狀態:民俗層,不計加成。

## 七、薩滿式請神

- **由來**:
  - 現實:薩滿(通古斯語)是東北亞、北亞、中亞的巫者,以擊鼓、搖鈴、舞蹈入迷狂以通神。
  - 本世界:邊地巫者的功夫。**請神求的是「勇」,請獸求的是「力」**。
- 階段:各階。
- 耗神:中。
- 起手:擊鼓、搖鈴、舞蹈,至迷狂。
- 運作:短時**不怕痛、不退**,類似戰前動員;**不加 L**。
- 旁人所見:一個人隨鼓點越跳越快,眼神渙散,然後忽然站定。
- 限制與破法:迷狂過度則失控;事後虛脫;被打斷鼓點則散。
- 狀態:設定。玄朔是否有薩滿傳統,**待定**(玄朔檔未寫)。

## 八、方士百態

- **由來**:現實:方士是秦漢以來求仙煉丹之士,《史記·封禪書》中的李少君、欒大都是其人,騙子居多。本世界沿用:「江湖術士魚龍混雜」(世界設定·文化與生活)。

| 類 | 比例 | 本事 |
|---|---|---|
| 騙子 | 大多 | 障眼法、話術、藥 |
| 半吊子 | 多 | 存思、符的皮毛,加障眼法 |
| 真有本事者 | 極少 | 見本檔各節 |
| 宮廷方士 | 景和帝周圍 | 外丹與吉凶話術;**影響大於本事**(見 [仙術](仙術.md) 第十一節) |
| 巫醫 | 邊地 | 薩滿加草藥 |
| 看相卜算 | 市井 | 觀人(見 [術數與推演](../../功法/術數與推演.md)) |

- **轉折功能**:妖術的用處是**偽裝、誤導、潛入、離間**。可用的場面形狀(設定備選,不入骨幹,只供日後選用):
  1. 街頭「神仙」騙錢,正好成為某人脫身的掩護。
  2. 村裡「鬧鬼」,實為障眼法、口技、迷香的人為組合,等待被拆穿。
  3. 某人「被下了咒」,其實是被人告知後才病,醫者說開了就好。

## 十一、反噬與代價

- **反噬**:使用過頻損傷心神,甚至失控(神傷、神損,見 [細目 README](README.md) 第三節)。
- **損陰德**:民間認為詛咒等術招致報應,世人對妖術師多有成見——**這個成見本身就是代價**。
- **由來**:現實:《西京雜記》的**東海黃公**——少時能制蛇御虎,佩赤刀;年老又嗜酒,術不靈;秦末有白虎見於東海,黃公持赤刀往厭之,術不行,為虎所殺。**術靈時是奇人,術不靈時是笑話,也是屍體。**

---

## 十二、寫作提醒

- **先讓人怕,再讓人懂**:第一次出現時留白,第二次揭開手法。
- **幻術的戲在破綻**:不合理處、遲疑的人、咬舌的疼。
- **不寫成能與宗師正面抗衡**:妖術使用者能活下來,靠的是跑得快。
- **不寫真變形**:世界無真正變形。
- **不寫成有教學價值的方術**:此處只寫效果,不寫方法。
- **詛咒的重量在人群裡**:一句「他被咒了」,比咒更殺人。

## 十三、第三部之後

民間方術本來就不靠靈氣,騙子與半吊子照舊;真正有請獸本領者,隨異獸稀少而更少。靈氣散入人間之後,**異獸出沒於靈氣濃厚之地**的前提消失,請獸這一支更難維繫(設定)。妖術留下的,是**市井裡的老故事**:鬧鬼的宅子、會說話的狐狸、被下了咒又被人說開的病人。
