# 代價帳

> 記錄**誰在哪個事件付出了什麼、能不能挽回**。這是劇情的「成本面」:能力與勝利看得到,代價才讓取捨有重量。劇情若長期只有收穫、沒有不可逆的損失,讀者感受到的就是平淡(量測見 [劇情基準](../設計規範/劇情基準.md) 的 J 組,工具為 `python3 工具/代價帳.py`)。
>
> 狀態:**草案**。目前只收「事件描述或角色狀態明文寫到的損失」,逐項標了依據;沒有明文的不推測。收錄範圍以男女主與近身同伴為主,事件標籤帶「死亡」「悲劇」而尚無帳目的事件,由 `代價帳.py` 列為「待補候選」。

## 欄位

| 欄位 | 說明 |
|---|---|
| 事件 | 事件 ID,須存在於時間線 |
| 承擔者 | 角色名(男主、女主或角色檔名) |
| 類別 | 生命、亡故、身體、關係、處境、能力、地位、良心、取捨(定義見下) |
| 損失 | 一句話,只寫事件描述或狀態檔寫到的 |
| 可逆性 | 不可逆、部分、可逆 |
| 依據 | 損失的出處;若承擔者不在事件的出場者中,須寫「不在場」 |

## 類別

| 類別 | 意義 |
|---|---|
| 生命 | 承擔者自己死去或瀕死 |
| 亡故 | 身邊的人(親人、師友、部屬)死去 |
| 身體 | 受傷、中毒、殘疾;多半可逆,但會影響後續行動 |
| 關係 | 分離、信任受損、決裂 |
| 處境 | 失去居所、自由、庇護 |
| 能力 | 修為、武功、星命的損失 |
| 地位 | 名譽、兵權、身分的損失 |
| 良心 | 因自己的行動或選擇傷了人,並為此背負 |
| 取捨 | 被迫在兩者之間選一,放掉另一邊 |

可逆性:**不可逆**是事後無法回到原狀(死亡、修為盡失);**部分**是日後能補救一部分;**可逆**是之後有明確事件恢復。

## 維護

- 新增或修改劇情事件後,於此補記該事件的明文損失;損失須能在事件描述或狀態檔找到出處。
- 事件被刪改或換 ID 時同步改本表;`python3 工具/檢查.py` 會檢查事件 ID、類別與可逆性。
- 本表不是評分表:帳目多不代表劇情好,只用來看「代價的分布與空窗」。
