# 讀者知情

> 這張表記錄「讀者」何時得知每個秘密, 與 [秘密知情矩陣](秘密知情矩陣.md)(只記角色)互補: 矩陣回答「誰在哪個時點知道」, 本表回答「讀者比男女主早知道還是晚知道」。欄位定義見下。
> 狀態: 草案, 由事件描述, 章節大綱與 [伏筆登記簿](伏筆登記簿.md) 推定, 供 `工具/體驗模擬.py` 讀取。每格只填一個事件 ID(最早者), 且該事件在時間線的章節欄必須有章號(「第 N 章」或「第 N 章(提及)」); 背景事件讀者看不到, 不入表。章序為序卷 < 第一部 < 第二部 < 第三部, 再比卷內序號。

## 欄位

- **SEC / 秘密**: 同秘密知情矩陣的 ID 與名稱, 依 SEC 編號排列。
- **讀者首見暗示**: 讀者最早可能感到「這裡有個沒說破的事」的事件 ID。以讀者視角判斷(看到事件裡發生了什麼), 不是作者在伏筆登記簿的標籤。確實沒有暗示, 直接揭曉者填 `—`。須不晚於讀者確知。
- **讀者確知**: 讀者在故事裡第一次明確得知該秘密真相的事件 ID。
- **男主得知 / 女主得知**: 該角色第一次完整得知真相的事件 ID; 至死未得知填 `—`。「疑」或「部分知」不算, 起疑的時點寫在依據欄。讀者確知早於男主或女主得知, 就是戲劇反諷(讀者知道, 角色不知道)。
- **依據**: 各欄的證據; 事件描述沒有明說, 屬推定者, 在該句前標「(推定)」。

## 使用備註

- 讀者確知早於男主或女主得知的列(戲劇反諷): SEC-001, SEC-003, SEC-004, SEC-005, SEC-006, SEC-008, SEC-009, SEC-010, SEC-011, SEC-014, SEC-015, SEC-016, SEC-018。讀者與男女主同時得知: SEC-002, SEC-007, SEC-012, SEC-013, SEC-017, SEC-019。沒有讀者晚於角色的列, 但有角色早在背景事件(讀者看不到)就知道、表內只能取第一個有章號的事件者: SEC-011(女主於 PRO-043 起知)。
- 同一事件被多格引用時(例如 P3-003, P3-038, P3-138), 是因為這些場次一次交代了多個秘密, 不是複製。
- 帶「(推定)」的格子, 日後有章節正文或編輯決定時, 以正文為準, 改這張表的同時不必動知情矩陣, 除非矩陣的時點本身有誤。
