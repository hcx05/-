# 角色

男女主的設定獨立於劇情大綱,可個別調整。大綱只決定「發生什麼事」,這裡決定「他們是誰、會什麼、在那一刻知道什麼、對誰有什麼感情」。

- [男主_陸懷川](男主_陸懷川/)(暫定名)
- [女主_溫知微](女主_溫知微/)(暫定名)
- [主要角色](主要角色/):其他第一主要角色的初始設定(24 位,含序卷出場角色)

每位主角的資料夾結構:
- `個性/`:核心個性、行為習慣、弱點、價值觀變化方向
- `天賦/`:先天能力與星命;不含「當前階段會什麼」
- `成長/`:按大綱階段記錄**記憶、武學、感情**(感情再依對象分資料夾);見 [成長/README](男主_陸懷川/成長/README.md)

修改原則:個性/天賦若改動,需回頭檢查成長各階段是否仍一致。
