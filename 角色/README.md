# 角色

男女主的設定獨立於劇情大綱,可個別調整。大綱只決定「發生什麼事」,這裡決定「他們是誰、會什麼、在那一刻知道什麼、對誰有什麼感情」。

- [男主](男主/)(暫定名見資料夾內 README)
- [女主](女主/)(暫定名見資料夾內 README)
- [主要角色](主要角色/):其他第一主要角色的初始設定(24 位,含序卷出場角色)

每位主角的資料夾結構:
- `個性/初始個性.md`:第一部開篇時點的個性基準(不隨劇情改寫)
- `天賦/`:先天能力與星命;不含「當前階段會什麼」
- `成長/`:按大綱階段記錄**記憶、武學、感情**(感情再依對象分資料夾)與**個性轉變**(`成長/個性/{卷}.md`);見 [成長/README](男主/成長/README.md)

修改原則:個性/天賦若改動,需回頭檢查成長各階段是否仍一致。

## 共通規則
- 路徑使用代號(`男主/`、`女主/`),角色暫定名只寫在各自 README。
- 每位配角的 `設定/` 依卷分檔;該卷有出場才建檔。
- 紀錄(記憶、武學、感情)開頭標示「相關事件」,引用 `故事線/` 的事件 ID(如 `PRO-023`)。
- 感情資料夾:配角只替有互動的對象建檔;男女主預建完整名單並以總表標示接觸狀態。
- 組織與群體見 `勢力/`。
