# 主要角色

男女主之外的第一主要角色。每位角色一個資料夾:

- `設定/`:依卷分檔(`序卷.md`、`第一部.md`……),每檔記錄該卷時點的基本資料、背景與來歷、能力;不含後續劇情
- `成長/`:按卷記錄**記憶、武學、感情**(序卷出場者已有序卷紀錄,其餘留空)

規則:
- 該卷有出場的角色才建立該卷的設定檔。
- 感情資料夾只替「有互動的對象」建檔。
