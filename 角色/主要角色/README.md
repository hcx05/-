# 主要角色

- `初始設定.md`:基本資料、背景與來歷、初始能力(時點於檔案開頭標示:第一部開篇或序卷時期;不含後續劇情)
- `序卷時期設定.md`:僅有第一部開篇設定的序卷出場角色另附
- `成長/`:序卷出場者已有序卷紀錄(記憶、武學、感情),其餘留空
