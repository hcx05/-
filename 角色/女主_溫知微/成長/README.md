# 成長資料夾說明

按劇情大綱的階段切分,每個階段是一份「快照」:**該階段開始時**的狀態,與階段內發生的變化。

檔案:
- `序卷.md`:2 個階段
- `第一部.md`:6 個階段(對應大綱一~六)
- `第二部.md`:7 個階段(對應大綱一~七)
- `第三部.md`:8 個階段(對應大綱一~八)

每個階段固定欄位:
- **對應大綱**:大綱中的哪一篇
- **約幾歲**
- **所處**:所在地與身邊的人
- **知道**:此刻掌握的資訊
- **不知道/誤信**:尚未知道或相信錯誤的事(避免寫作時提前揭露)
- **技能**:此刻會的武學、能力與程度
- **感情**:對特定人物/事物在這個階段的態度
- **心境與目標**:當前想做什麼、最在意什麼
- **本階段變化**:階段結束前改變了什麼(下一階段的起點)
