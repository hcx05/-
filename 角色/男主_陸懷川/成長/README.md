# 成長資料夾說明

按劇情大綱的階段切分,分三個面向記錄角色在**各階段**的狀態。每個檔案內以階段為小標,內容目前待填。

```
成長/
├── 記憶/      知道什麼、不知道/誤信什麼(依 序卷、第一~三部 分檔)
├── 武學/      會什麼武學、境界、悟性與進境(依 序卷、第一~三部 分檔)
├── 感情/      對不同對象的感情(每個對象一個資料夾,內依 序卷、第一~三部 分檔)
│   └── {對象}/
└── _待遷移/   舊版整合式階段紀錄,待分類遷入上面三類後刪除
```

階段清單(與大綱一致):序卷 2、第一部 6、第二部 7、第三部 8,共 23 個。

感情對象:女主、阿古、秦七、父母、宋青崖、胡不歸、柳煙、沈滄溟、晏長庚、懷虛子、高承嗣、溫素問。需要新增對象時,在 `感情/` 下新增資料夾並複製四個分檔。
