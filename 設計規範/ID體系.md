## 規則
1. **ID 不重編**:刪除物件時,ID 標為「停用」,不回收給別的物件。
2. **改名不改 ID**:名稱可變,引用以 ID 為準。
3. **新增接續編號**:不補洞、不重排。
4. **ID 位置**:
   - 角色設定檔的引言區:`> ID:CHR-xxx`;男女主在各自 README。
   - 勢力檔、場景建模檔:第一個項目 `- **ID**:ORG-xxx` / `LOC-xxx`。
5. **跨檔引用**:正文可用名稱,但紀錄類檔案(狀態、登記簿、事件)優先附 ID。
6. 檢查腳本會驗證 ID 的唯一性與檔案對應。
