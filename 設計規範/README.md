# 設計規範

專案的「規則層」:讓續寫時不偏掉、不矛盾。

| 文件 | 用途 |
|---|---|
| [事實登錄](事實登錄.md) | 硬規則(FACT-xxx),續寫不得違反 |
| [設計決定記錄](設計決定記錄.md) | 為什麼這樣設計(DEC-xxx),要改須先登記 |
| [術語表](術語表.md) | 統一用詞,並列出禁用寫法(由檢查腳本掃描) |
| [ID體系](ID體系.md) | 各類物件的 ID 前綴與規則 |
| [ID對照](ID對照.md) | 角色(CHR)、勢力(ORG)、場景(LOC)的 ID 登記 |
| [單一來源](單一來源.md) | 每類資料的正本與衍生,衝突時的處理順序 |
