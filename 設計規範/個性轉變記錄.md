# 個性轉變記錄

角色的個性會隨時間推移而改變:對世界的看法、對人的看法、價值觀與行為。為了讓續寫時知道「這個人現在是什麼樣子、為什麼變成這樣」,採用「初始個性 + 轉變日誌」兩層記錄。

## 兩層結構
| 層 | 位置 | 內容 | 能否修改 |
|---|---|---|---|
| 初始個性 | 男女主:`個性/初始個性.md`;配角:`設定/{卷}.md` 的「初始個性(本卷開篇時點)」 | 該時點的個性基準 | 不隨劇情改寫 |
| 轉變日誌 | `成長/個性/{卷}.md` | 每一次轉變:觸發事件、之前 → 之後 | 只增不改(新的轉變新增一條) |
| 當前個性 | `狀態/{卷}結束/角色狀態.md` 的「當前個性」欄 | 該卷結束時的關鍵詞 | 每卷結束更新 |

**當前個性 = 初始個性 + 累積的轉變日誌**。

## 什麼算「轉變」
符合下列至少一項才記錄,小情緒起伏不記:
1. 對世界的看法改變(例:從信任朝廷到不信任)。
2. 對特定人或一類人的看法改變(例:對師父從全然信任到起疑)。
3. 價值觀或底線改變。
4. 行為模式明顯改變(例:從愛求助到獨自扛)。

## 記錄規則
1. 每條轉變必須有**觸發事件**(事件 ID),且該角色必須是該事件的出場者。
2. 一條只記一個核心差異,用「之前 → 之後」表達。
3. 不重寫初始個性;轉變只新增。
4. 表現證據只寫「劇情中如何體現」的一句話,不寫對白與場景。
5. 標明可逆性:可逆(之後可能回復)、不可逆、待定。
6. 沒有轉變的角色不建檔,不補空檔。
7. 每卷結束,更新狀態表的「當前個性」。

## 轉變條目模板
```
## 轉變 N · {名稱}
- **觸發事件**:PRO-xxx
- **時間**:相對時間或年齡
- **對世界的看法**:之前 → 之後
- **對人的看法**:之前 → 之後(對象)
- **價值觀與行為**:之前 → 之後
- **個性特質**:新增 / 強化 / 弱化 / 消失:…
- **表現證據**:一句話
- **可逆性**:可逆 / 不可逆 / 待定
```
檔尾加「卷末個性摘要」一行。

## 與其他記錄的關係
- 記憶(知道什麼)與個性(是什麼樣的人)分開記;事件造成個性轉變時,兩邊各寫一條,並引用同一個事件 ID。
- 感情(對特定人的態度)記關係;個性記整體傾向。對特定人的看法轉變同時記在兩處時,以感情檔為細節、以個性檔為概括。
