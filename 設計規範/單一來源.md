# 單一來源

同一份資訊只有一處是「正本」,其他處為衍生。需要修改時改正本,衍生處同步或由檢查腳本比對。

| 資料類型 | 正本 | 衍生(需一致) |
|---|---|---|
| 戰力 L(各時點) | 角色 `設定/{卷}.md` 的「初始能力」 | `成長/武學/{卷}.md`、`狀態/{卷}結束/角色狀態.md`、`戰力基準.md` 人物表 |
| 年齡 | `故事線/{卷}/年齡表.md` | 各角色設定檔、`角色狀態.md` |
| 生死與位置 | `狀態/{卷}結束/角色狀態.md` | 事件描述的出場角色、成長紀錄 |
| 個性 | 初始個性 + `成長/個性/{卷}.md` 轉變日誌 | 狀態表「當前個性」欄 |
| 誰知道什麼 | `狀態/秘密知情矩陣.md` | 各角色 `成長/記憶/{卷}.md` |
| 伏筆 | `狀態/伏筆登記簿.md` | 事件描述、典籍 |
| 事件(時間、順序) | `故事線/{卷}/時間線.md` | 事件描述、各紀錄的「相關事件」 |
| 事件內容與出場者 | `故事線/{卷}/事件描述.md` | 成長紀錄、角色出場 |
| 地理與距離 | `世界設定/場景設定/世界地圖.md` | 世界觀地理、場景建模 |
| 組織資料 | `勢力/{名}.md` | 狀態表、事件描述 |
| 硬規則 | [事實登錄](事實登錄.md) | 所有設定文件 |
| 名稱與術語 | [術語表](術語表.md) | 所有文件 |
| 事件標籤、感情線 | `故事線/{卷}/時間線.md`(詞表:[標籤表](標籤表.md)) | `故事線/{卷}/節奏檢視.md`(自動產生) |
| 角色暫定名 | 男女主 README | 無(其他處用代號) |

## 衝突時的處理順序
1. 先查事實登錄與設計決定記錄,看有無明文規定。
2. 以上表正本為準。
3. 修改正本後,依表中衍生欄逐項更新,再執行 `工具/檢查.py`。
