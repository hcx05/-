# 標籤表(事件標籤與感情線)

## 用途
標籤是**規劃用**的工具:開發新劇情時,**先填標籤,再寫事件內容**。它讓開發者從兩個視角各自規劃節奏,再合併成故事:

| 視角 | 欄位 | 要回答的問題 |
|---|---|---|
| 事件視角 | 事件標籤 | 這個事件在整體節奏中扮演什麼調性?前後是否有緩衝與鋪墊? |
| 男女主視角 | 感情線 | 兩人的關係在這一刻處於什麼狀態?是否合理銜接上一個與下一個? |

兩個欄位寫在時間線的**事件名稱之前**,規劃時可以只填標籤、事件名稱先留「待定」,先把節奏排好。標籤的分布與弧線可用 `python3 工具/標籤檢視.py` 產出節奏檢視。

## 事件標籤
一個事件一至兩個標籤。

| 標籤 | 意義 | 類型 |
|---|---|---|
| 敘事 | 交代背景、過渡 | 緩衝 |
| 傳說 | 神話與古老傳聞 | 緩衝 |
| 設定 | 世界規則的建立 | 緩衝 |
| 日常 | 平靜生活 | 緩衝 |
| 成長 | 能力或心境的變化 | 緩衝 |
| 溫情 | 親情、友情、愛情的暖意 | 緩衝 |
| 相遇 | 人物首次相會 | 緩衝 |
| 冒險 | 探索與遠行 | 推進 |
| 誓約 | 立誓、約定 | 推進 |
| 權謀 | 朝堂、勢力的算計 | 推進 |
| 合謀 | 秘密串通、設局 | 推進 |
| 衝突 | 對立與爭執 | 推進 |
| 伏筆 | 為後續埋下線索 | 推進 |
| 懸念 | 留下疑問與期待 | 推進 |
| 宿命 | 命運與預言的牽引 | 推進 |
| 離別 | 分離 | 推進 |
| 揭露 | 真相或身世被揭開 | 重 |
| 驚魂 | 緊張、危急、追殺 | 重 |
| 悲劇 | 失去與哀傷 | 重 |
| 死亡 | 角色死亡 | 重 |
| 戰爭 | 大規模戰鬥 | 重 |

類型說明:
- **緩衝**:讓讀者喘息、累積感情的事件。
- **推進**:推動情節或埋設線索的事件。
- **重**:情緒或衝擊強烈的事件。

## 感情線
僅記錄**男女主之間**的關係狀態,格式為「狀態 + 一個表情」,例如 `初遇 😳`;該事件與兩人感情無關時填 `-`。表情由開發者依該事件的情緒自行選擇。

| 狀態 | 意義 |
|---|---|
| 初遇 | 第一次見面 |
| 暗生情愫 | 開始在意 |
| 日常 | 相處平穩 |
| 矛盾 | 出現分歧 |
| 爭執 | 明確衝突 |
| 和好 | 釋懷、修復 |
| 理解 | 彼此看懂 |
| 分離 | 被迫或主動分開 |
| 思念 | 遠方牽掛 |
| 重逢 | 再度相見 |
| 情定 | 確立心意 |

## 規劃步驟(先標籤、後內容)
1. 先列出本卷預計的事件槽位(順序與章節),事件名稱可暫填「待定」。
2. **事件視角**:為每個槽位填事件標籤,檢查節奏(見下)。
3. **男女主視角**:為兩人同場的槽位填感情線,檢查弧線(見下)。
4. 合併檢視:同一個事件上,事件標籤與感情線是否互相支撐(例如「悲劇」事件配「思念」或「理解」是否合理)。
5. 通過後才撰寫事件名稱與描述;內容若與標籤不符,先改標籤再改內容,不要讓兩者脫節。

## 節奏準則(建議,非硬性)

### 事件視角
- 連續出現「重」類標籤不超過 2 個,之後需要至少 1 個「緩衝」類。
- 每個「伏筆」「懸念」標籤,須在 [伏筆登記簿](../狀態/伏筆登記簿.md) 登記回收計畫。
- 每章結尾事件建議帶「懸念」「宿命」「離別」「溫情」之一,形成章間牽引。
- 一卷之中「緩衝」類事件不應少於三成,避免全程高壓。

### 男女主視角
- 狀態轉移建議路徑:初遇 → 日常/矛盾 → 暗生情愫 → 日常 → 矛盾 → 爭執 → 分離 → 思念 → 重逢 → 和好 → 理解 → 情定。
- 相鄰兩個有感情線的事件,狀態不宜跳躍過大(例如「初遇」直接到「情定」,中間需有鋪墊)。
- 「爭執」「分離」之後須有「和好」「理解」或「重逢」收束。
- 同行章節必有感情線;群像、單人線章節可填 `-`。
