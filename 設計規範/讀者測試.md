# 讀者模擬測試

劇情「好不好看」沒有可直接量的指標。這份規範用**另一個沒看過設定的 session 扮演第一次閱讀者**,量兩件有操作定義的事,當作「好看」的代理指標:

| 指標 | 問題 | 測法 |
|---|---|---|
| I1 可預測度 | 這段劇情是不是套路?讀者能不能猜到接下來發生什麼 | 預測測試 |
| I2 轉折鋪墊 | 轉折是不是憑空冒出?前文有沒有公平的線索 | 線索測試 |
| I3 伏筆可感度 | 作者登記的伏筆,讀者有沒有感覺到「這裡有事」 | 預測測試的附帶題 |

它們不能證明劇情好看,只能抓兩類毛病:**太套路**(I1 過高)與**沒鋪墊**(I2 突兀)。是否驚豔、是否動人,仍要真人讀者回答(見末節)。

## 為什麼這樣設計

- 擔任作者的 session 看過整份設定,無法回到「不知道後文」的位置。所以測試者必須是**全新的 session,只拿一份限知的包**。
- 預測題把「可預測」變成可計分的東西:被一個熟悉武俠類型的讀者猜中的,一般讀者也多半猜得到。
- 線索題把「有沒有鋪墊」變成可檢驗的東西:好的轉折是事前猜不到、事後能指出線索;猜不到又找不到線索,就是憑空添加。

## 角色分工

| 角色 | 誰 | 看到什麼 |
|---|---|---|
| 作者 | 目前這個 session(或任何看過設定的 session) | 全部;**不得兼任測試者或評分者** |
| 測試者 | 全新的 session | 只有 `讀者測試包.py 預測`(或 `線索`)輸出的那一份包 |
| 評分者 | 另一個全新的 session | 測試者的輸出,加上 `讀者測試包.py 答案` 的輸出 |

## 流程

1. `python3 工具/讀者測試包.py 取樣` 列出切點與轉折事件(確定性,可重現)。
2. 預測測試:
   1. `python3 工具/讀者測試包.py 預測 第二部 12 --out 預測包.md`(檔案放專案之外或暫存區);
   2. 開一個全新的 session,只貼這份包,取得它的輸出;
   3. `python3 工具/讀者測試包.py 答案 第二部 12 --out 答案.md`;
   4. 開另一個全新的 session,貼預測輸出與答案,依下一節的規則評分。
3. 線索測試:`python3 工具/讀者測試包.py 線索 P2-141 --out 線索包.md`,交給全新的 session;重要轉折建議用兩個獨立的 session 各做一次,意見不同時取較嚴的結論。
4. 結果記入 [讀者測試記錄](讀者測試記錄.md)。
5. `python3 工具/讀者測試包.py 掃描` 不需要 LLM,先看哪些轉折在登記簿裡毫無對應伏筆,優先做線索測試。

## 評分規則(預測測試)

預測的每個事件對照實際發生的事件:

| 判定 | 分數 | 條件 |
|---|---|---|
| 命中 | 1 | 誰、做了什麼、結果的實質都對 |
| 部分 | 0.5 | 方向對,但結果或關鍵細節不同(例如猜到有人殺出,猜錯是誰) |
| 未中 | 0 | 其他 |

- **I1 可預測度** = 分數總和 ÷ K。同一卷多個切點取平均。
- **高信心命中數**:測試者標「高」且命中的事件個數。高信心又命中,是最典型的套路徵兆。
- **局面預測**:下一章結尾的局面,命中、部分或未中,只記錄。
- **I3 伏筆可感度** = 測試者列出的「懸著的問題」中,與答案包「讀者應已感知的伏筆」實質對應的條數 ÷ 該表條數。另外記**未登記的懸問**(讀者懸著、登記簿沒有的):可能是自然生出的好懸念,也可能是漏洞,須人工判斷。
- 「最想跳過的段落」只記錄章號與原因。

線索測試的結論(公平、勉強、突兀)直接記錄。**I2** = 公平的轉折數 ÷ 測過的轉折數。

## 解讀(專案自訂,尚未校準)

沒有外部作品的數據可對照,下列門檻只是起點,隨真人讀者結果修正:

| 現象 | 解讀 | 行動 |
|---|---|---|
| 某卷 I1 平均 ≥ 0.67 | 偏套路 | 看被高信心命中的事件,做[選項對照](選項對照.md),找出更不可預測又合理的走法 |
| 某卷 I1 平均 ≤ 0.1 且同段線索測試多為突兀 | 可能是無動機轉向 | 補鋪墊或調整轉折位置 |
| I1 在 0.2 至 0.6 之間 | 暫視為正常 | 無 |
| 線索測試結論為「突兀」 | 轉折缺鋪墊 | 依其「補強位置」加一筆既有事件,走變更傳播 |
| I3 偏低(伏筆登記了,讀者沒感覺) | 伏筆太隱形 | 在切點前後加一個呼應點(與長距伏筆保活同一件事) |

## 這個測試的偏差

1. **測試者與作者是同一類模型**,盲點相近;它猜得中的,一般讀者未必猜得中,反之亦然。
2. **事件名稱是設計者寫的**,比讀者實際讀到的資訊多,「命中」的證據力偏弱,「落空而事後合理」的證據力較強。
3. **只測情節走向**,沒有測文字、聲口、節奏感與情緒。
4. **類型的必然節拍會被算成可預測**(例如主角必然活下來),需要人工分辨哪些是必然、哪些是套路。
5. **單次樣本小**,單一切點的分數沒有意義;看每卷的平均與趨勢。

## 校準:真人讀者

同一份預測包也可以交給真人做,真人的預測、懸問與「想跳過」的回答比 LLM 更有價值。累積幾位真人的結果後,用它們修正上面的門檻,並判斷 LLM 測試者的偏差方向。這一步需要使用者安排,工具無法代做。
