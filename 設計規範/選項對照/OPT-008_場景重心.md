# OPT-008 場景重心

- **起因**:使用者要求故事重心放在江湖、武林與宗門,宮城與塞外要減少(DEC-100)。逐事件看場景欄,第二部「宮城朝堂 + 塞外」占 34.2%,第三部 26.4%,第一部 19.3%;第二部的江湖市井宗門只占 16%,青城、棲霞閣、太初觀、漕幫在整卷幾乎不見
- **涉及事件**:P2-053、P2-054、P2-055、P2-064、P2-146、P2-094、P2-110、P2-111、P3-050、P3-051、P3-081、P1-084、P1-104、P2-155、P2-154、P2-157、P2-156
- **日期**:2026-10-28

## 方案 A:換場景,並補四個宗門事件
- **做法**:(1)把描述本來就寫宅邸、醫帳、書房、街巷的事件,場景欄從「臨江行在」「長寧朝堂與坊市」改為實際舞台(新建宋府、宗室舊邸、濟世盟營地、臨江國師府、臨江濟世盟醫館、臨江街巷與渡口),共 45 個事件換場景;(2)第二部新增 P2-155(漕幫渡人)、P2-154(青城下山)、P2-157(棲霞閣離閣)、P2-156(太初觀兩封信),接上既有下游事件;(3)新增 `工具/場景重心.py` 與 [場景重心](../場景重心.md),定上限
- **主角付出的代價**:無新增
- **可預測度**:高。事件的人物、時間、因果與結果都不動,只是舞台寫準確;新增事件各接上既有伏筆
- **後續分支**:宮城朝堂 + 塞外:第一部 19.3% → 10.1%、第二部 34.2% → 25.3%、第三部 26.4% → 15.3%;第二部江湖市井宗門 16% → 29%。新增事件讓第二部宗門在前半卷就有面孔(漕幫、青城、棲霞閣、太初觀)
- **變更範圍**:45 個事件的場景欄(事件描述、凍結、章綱的場景行);4 個新事件(時間線與序號重排、事件描述、凍結、章綱、男女主與溫伯仁、蘇映霜、玄鏡真人的記憶檔);第 23 章字數 1.6 → 2.0 萬;8 個新場景建模與 ID 登記;P2-073 描述一處用語

## 方案 B:大量降為提及,不補事件
- **做法**:把宮城與塞外的次要事件(P2-039、P2-052、P2-094、P2-096、P2-109、P1-099、P1-100、P3-106 等約十個)改為「提及」,事件 ID、出場者不動,以人物一兩句話交代(OPT-004 的手法放大)
- **主角付出的代價**:無新增
- **可預測度**:中。降掉的多是章的支點,章的重心會空
- **後續分支**:宮城朝堂 + 塞外比例會降 2 至 3 個百分點,但不增加任何江湖內容;受影響的章(第 15、19、43 章等)要重寫演法
- **變更範圍**:約十個事件的章節欄與各章綱;對江湖占比沒有幫助

## 方案 C:把西域線與南昭線搬進中原宗門
- **做法**:星盤改藏在中原宗門遺陣,逆脈改由中原門派傳授,南昭朝堂線併入天下盟的前身;第二部第 34–40 章與第 19–27 章大幅改寫
- **主角付出的代價**:主角的受苦地點改變,但代價不變
- **可預測度**:低。改動最大,風險也最大
- **後續分支**:星盤的守護者(西海古國遺族)、沉沙古城、拜月教與阿依、米十三等全要改;第三部 P3-116、P3-117 的西行與第 3 部補天陣用星盤的碑文都受影響
- **變更範圍**:世界設定(四器分布)、多個勢力與場景、第二部三分之一的事件、第三部相關事件

## 結論
- **選擇**:A
- **理由**:A 不動任何事件的實質,卻把舞台寫準確、補上第二部缺少的宗門面孔,三個卷的指標都達標;B 動到章的支點而對江湖占比沒有幫助;C 動到世界設定與三分之一的卷,風險遠大於收益。第二部仍是戰爭卷(邊關軍旅 45%),要再往江湖移,需另立一輪,不在本次(見場景重心第五節)
- **DEC**:DEC-101
