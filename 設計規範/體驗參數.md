## 記憶保留

保留機率 R = exp(-(距離) / S),S = S0 × (1 + β × 此前的呼應次數)。距離以章計,從最近一次設置或呼應算起。

| 參數 | 值 | 說明 |
|---|---|---|
| S0 | 40 | 一條沒有呼應的伏筆,記憶的時間常數(章)。敏感度分析取 20、40、80 |
| β | 0.5 | 每多一次呼應,時間常數增加的比例 |
| 低保留門檻 | 0.3 | 回收時 R 低於此值,視為「回收可能落空」 |
| 角色 S0 | 30 | 角色重返時的時間常數(章);出場越多次越不易忘,同樣乘 (1 + β × 此前出場次數) |

## 事件索引轉換負荷

相鄰演出事件逐對比較。時間資料的解析度是月,所以時間轉換以月計。

| 項目 | 權重 | 說明 |
|---|---|---|
| 時間跳躍 ≥ 3 個月 | 1 | 向後跳 |
| 時間跳躍 ≥ 12 個月 | 1 | 與上一列累加 |
| 時間倒退 | 1.5 | 回到更早的時間 |
| 空間轉換 | 0.5 | 兩事件場景集合不相交(任一邊無場景資料則不計) |
| 主角轉換 | 1 | 男主、女主在場的組合不同 |
| 配角更替 | 0.5 | × (1 − 出場角色的 Jaccard 相似度) |
| 新角色首次登場 | 0.4 | 每人 |
| 新場景首次出現 | 0.2 | 每處 |
| 新伏筆設置 | 0.3 | 每條 |

意圖轉換與因果斷裂目前沒有資料欄位(事件契約只覆蓋重類事件),未計入;見 [體驗量化研究](體驗量化研究.md) X4。

## 損失衝擊

衝擊 = 類別基礎值 × 依附度 × 可逆性係數。依附度見下方公式;承擔者是男主、女主時依附度為 1。

| 類別 | 基礎值 |
|---|---|
| 生命 | 1 |
| 亡故 | 1 |
| 良心 | 0.8 |
| 能力 | 0.8 |
| 處境 | 0.6 |
| 取捨 | 0.6 |
| 關係 | 0.5 |
| 地位 | 0.5 |
| 身體 | 0.4 |

| 可逆性 | 係數 |
|---|---|
| 不可逆 | 1 |
| 部分 | 0.5 |
| 可逆 | 0.15 |

| 參數 | 值 | 說明 |
|---|---|---|
| 依附速率 k | 0.25 | att = 1 − exp(−k × 加權同場數) |
| 溫情加權 | 1.5 | 溫情、日常、幽默、誓約、成長標籤的同場事件加權 |
| 未具名受害者依附度 | 0.4 | 損失的對象沒有具名角色時(例如被擄孩子)的暫定依附度 |
| 高衝擊門檻 θ | 0.5 | 某章損失衝擊總和 ≥ θ 才算「有損失的章」;敏感度分析取 0.3、0.5、0.8 |

## 讀者模擬器

逐章推進的讀者狀態模型。以下每個參數是一個範圍,蒙地卡羅抽樣時在範圍內均勻抽取(固定種子,可重現)。引擎公式見 `工具/體驗模擬.py` 的 `simulate`。

| 參數 | 下限 | 上限 | 說明 |
|---|---|---|---|
| 好奇權重 | 0.5 | 1.5 | 好奇 = 1 − exp(−有效開放問題數 / q0) 的權重 |
| q0 | 8 | 24 | 好奇的飽和尺度(全書平均同時有 14 條左右未解問題,所以尺度取這個量級) |
| 喚起權重 | 0.5 | 1.5 | 喚起對投入的貢獻(單調遞增的 S 形,中點為甜蜜點) |
| 喚起甜蜜點 | 0.3 | 0.6 | 喚起 S 形的中點(0 到 1) |
| 疲勞起點 | 0.6 | 0.8 | 章喚起高於此值的部分累積疲勞 |
| 無聊起點 | 0.3 | 0.5 | 章喚起低於此值的部分累積無聊 |
| 對比比重 | 0.4 | 0.8 | 喚起貢獻中,「相對已適應水準的對比」所占比例;其餘看絕對強度 |
| 喚起帶寬 | 0.15 | 0.35 | S 形的陡度 |
| 損失權重 | 0.3 | 1.2 | 損失衝擊對投入的貢獻 |
| 負荷權重 | 0.3 | 1.2 | 超過負荷基準的部分,對投入的扣分 |
| 疲勞權重 | 0.3 | 1.2 | 持續高喚起累積的疲勞扣分 |
| 無聊權重 | 0.3 | 1.2 | 持續低喚起累積的無聊扣分 |
| 疲勞衰減 | 0.6 | 0.9 | 每章保留的比例 |
| 適應速率 | 0.7 | 0.95 | 讀者對喚起水準的適應(指數平均):越大適應越慢。喚起貢獻的一半看相對適應水準的對比 |
| 基礎流失 | 0.003 | 0.012 | 每章基礎放棄機率 |
| 流失敏感度 | 1.5 | 4 | 投入低於基準時,放棄機率上升的陡度 |

穩健判定:蒙地卡羅抽樣的**絕大多數(≥ 80%)**參數組合下,某章投入落在全書最低 10%,才列為「穩健的低谷」。
